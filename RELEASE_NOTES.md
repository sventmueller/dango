## File tree
- Several rows of the file tree can be selected with ⇧-click and ⌘-click, and the context menu on one of them acts on
  all of them: "Copy Path" and "Copy Relative Path" copy one path per line, "Show in Finder" selects them together in
  the Finder, and "Move to Trash" moves them all. "Rename…" and the commands that open a single file are not offered
  then; the menu on a row outside the selection acts on that row alone.
