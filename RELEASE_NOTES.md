## Help
- The Help menu leads to the project on GitHub: "Report a Problem…" opens the issue form with the version of Dango,
  the macOS version and the kind of Mac already filled in, "Suggest a Feature…" starts a new idea in the discussions,
  and "Dango on GitHub" opens the repository.

## Editor and terminal
- Editors and terminals start at 13 points, like the sidebar, the tab bars and the AI tab; a size you have set
  yourself stays.
- The line numbers also count the empty line after the last line break and the only line of an empty document,
  beside the cursor.

## AI
- The output button of a background process no longer opens an empty file while the process has printed nothing; it
  says that nothing has been printed yet, or nothing at all once the process has ended. A second click shows the
  current output instead of the earlier copy, and the button now also shows the output of a Codex terminal, where it
  did nothing before.

## Markdown
- Pictures in the Markdown preview show about three times as fast: they are scaled down with vector
  instructions, and pictures on iCloud Drive, an external disk or a network share load several at a time instead of
  one after the other.
