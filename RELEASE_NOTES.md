## Toolbar
- New order from the right: New Terminal, New AI Thread and New Browser Tab in one group, left of it Split Right, Split Down and the input field switch, then Open Quickly and Activity.
- The input field switch turns the field of the terminal in front on or off and shows in the accent colour while the field is on; without a terminal in front it is greyed.
- With only one agent installed, New AI Thread opens it with one click; otherwise the click shows the agents in a menu. Holding the button always shows the menu.
- The settings button sits lower at the bottom of the sidebar.

## Terminal
- Without the input field, the command you type gets the same colours as in the field: command, subcommands, options, variables and operators, and a dashed red underline under a command the shell cannot run. Colours your shell sets itself stay.
- Without the input field, the suggestion list opens by itself as you type a word. Return runs the line and Tab or → take the grey suggestion; once you move the selection with ↑ or ↓, they take the selected entry. Escape closes the list for that word, and Settings › Terminal turns it off.
