## メモリ
- 長いエージェントセッションに必要なメモリが大幅に減りました:
  - 過去のセッションを開くと、そのトランスクリプトを1行ずつ読み込みます。100 MBのトランスクリプトを持つセッションのピークは、65 MBではなく約20 MBになりました。
  - 完了したツール呼び出しは、そのカードに表示される内容だけを保持します。出力の最初の400行は保持しますが、カードがフィールドを表示した後は生の入力を保持しなくなりました。“さらにN行”は引き続きすべての行を数えます。
  - 30秒間表示されていないAIタブはカードを解放し、再び表示されたときに、元の位置で表示範囲内のカードを構築します。
  - タブを閉じたときや過去のセッションを開いたとき、Dangoは解放したメモリをmacOSに返します。
- リストが更新のたびにメモリ上で大きくなることがなくなりました。macOS 27では、開閉できる行を持つリストを更新するたびに開閉用三角ボタンが残り続け、更新のたびに各行の一部も少しずつ残っていました:
  - CI、コンテナ、Software Factory、テスト、デバッグ、Git、検索の各リストと呼び出し階層は、矢印を独自に描画します。
  - 表示されていないリストは更新されなくなり、表示されたときに遅れを取り戻します。
  - セッション、CI、Software Factory、コンテナの各リストは変更のない行を保持し、Gitは状態が変わったファイルの行だけを更新します。
- 閉じたウインドウのパネルは、ウインドウとともに解放されます。

## AIタブ
- `make > build.log 2>&1`のように出力を自らファイルに書き込むバックグラウンドコマンドでは、CLIに出力がまったくない場合、“出力を表示”でそのファイルが表示されます。
