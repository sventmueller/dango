## AIタブ
- 正常に終了したフックや実行中のフックは、タイムラインに表示されなくなりました。応答ごとの折りたたまれた行としても表示されません。失敗したフックは引き続き表示されます。

## ターミナル
- 負荷の高いMacがプログラムの出力を遅れて読み込んだ場合でも、ターミナルはプログラムが終了したことを検知し、その最後の数行を残します。

## Markdown
- WordやWebページからペーストした、バッククォート（`` ` ``）を含む数式は、コードにならずに数式のままになります。
- 太字や斜体のテキスト内のイメージは、Wordに書き出しても太字や斜体のままになります。
- 空の表セルが50万個を超えるファイルは、数秒の時間と数ギガバイトのメモリを費やす代わりに、表をテキストとして表示します。
