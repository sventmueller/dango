## セキュリティ
- エージェントの応答、プラン、レポート、Markdownプレビュー、PDF内のリンクを1回クリックしただけでアプリが開くことはなくなりました。Webアドレスはブラウザタブで、プロジェクト内のファイルはエディタタブで開きます。それ以外のもの、たとえばほかの場所にあるファイル、ネットワーク共有、ほかのアプリのリンクは、開く前に確認し、リンク先を表示します。
- エージェントやMCPサーバが渡すサインインとRemote Controlのアドレスは、Webアドレスの場合にのみ開きます。
- ホームフォルダ、デスクトップ、書類、ダウンロード、ボリュームのルートなど、1つのプロジェクトよりはるかに多くのものを含むフォルダは、全体として信頼できなくなりました。プロジェクトごとに信頼してください。信頼の確認では、その中のフォルダにも信頼が適用されることが示されるようになりました。
- CIのトークンとサインイン情報が、プレーンなhttpでこのMac以外のサーバに送られることはありません。リモートが`http://`で始まるリポジトリには、httpsで問い合わせます。
- gitleaksがない場合、編集の予測は、コードをこのMac外のプロバイダに送る前に、確認せずに送信することを選ぶまで待つようになりました。プロジェクト独自のgitleaks設定でチェックがオフになることはなくなりました。
- 内蔵エージェントが、書き込みが承認された後に現れるリンクを通じてプロジェクト外に書き込むよう誘導されることはなくなりました。また、ほかにハードリンクがあるファイルは、リンクを通じて書き込まれるのではなく、独立したファイルになります。
- 言語サーバの補完でエディタが応答しなくなることはなくなりました。また、言語サーバによるリンクされたファイルの名称変更と削除は、リンク先ではなくリンク自体に対して行われます。
- プロンプトに添付した画像は、ほかの場所と同様に、サンドボックス化されたデコードサービスでデコードされます。
- ターミナル内のプログラムがクリップボードを置き換えられるのは、そのターミナルが前面にある間だけになり、ターミナルはそのことを表示します。
- rust-analyzerは、その時点の最新版ではなく、チェックサムで固定されたリリースからインストールされます。

## 検索とナビゲーション
- “クイックオープン”は、一致するファイルがないときにそのことを表示し、ファイルとプロジェクトのシンボルのどちらを検索しているかを示します。
- プロジェクトのシンボルに、ファイルを開いていなくてもTypeScriptとJavaScriptが含まれるようになりました。プロジェクト内の完全一致と、作業中の言語のものが先に表示され、ライブラリやインストール済みパッケージのシンボルには印が付きます。
- “表示” › “検索”で、検索フィールドにフォーカスが移るようになりました。

## エディタ
- Markdownファイルがプレビューを横に表示して開いたときもエディタがフォーカスを保つので、“フォーマット”メニューをすぐに使えます。サイドバーにフォーカスがあるときもエディタのコマンドが使えます。
- 行末やその下のボックスに表示される提案に、Tabで受け入れられることが示されるようになりました。
- タブの一覧で同じ名前のタブが区別されるようになりました。たとえば、ファイルとブラウザに表示したそのプレビューです。
- “表示”メニューに、Dangoのタブでは使わないmacOS標準の“タブバーを隠す”が表示されなくなりました。

## 言語とデバッグ
- JSONサーバがファイルをチェックするようになり、basedpyrightやsourcekit-lspのように起動後に診断を登録するサーバの診断も表示されるようになりました。
- HomebrewのPythonのようにpipがPythonへのインストールを拒否する場合、デバッガはプロジェクトの仮想環境にdebugpyをインストールすることを提案します。
