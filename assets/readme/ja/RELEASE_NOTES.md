## ヘルプ
- “ヘルプ”メニューからGitHubのプロジェクトに移動できます。“問題を報告…”は、Dangoのバージョン、macOSのバージョン、Macの種類が入力済みの報告フォームを開き、“機能を提案…”はディスカッションで新しいアイデアを開始し、“GitHubのDango”はリポジトリを開きます。

## エディタとターミナル
- エディタとターミナルは、サイドバー、タブバー、AIタブと同じく13ポイントで始まります。自分で設定したサイズはそのまま維持されます。
- 行番号に、最後の改行の後の空の行と、空の書類の唯一の行も、カーソルの横に表示されるようになりました。

## AI
- バックグラウンドプロセスの出力ボタンは、プロセスがまだ何も出力していない間に空のファイルを開かなくなりました。代わりに、まだ出力がないこと、またはプロセスの終了後には出力がなかったことを伝えます。2回目のクリックでは以前のコピーではなく現在の出力が表示され、これまで何もしなかったCodexのターミナルでも、ボタンで出力を表示できるようになりました。
