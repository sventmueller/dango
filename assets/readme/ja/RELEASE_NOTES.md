## 速度
- ビルド、テスト、シェルなど、エージェントが起動するものは、macOSのバックグラウンド状態ではなく最も低い優先度で実行されるようになりました。引き続きDangoが最優先で、エージェントはそれが起動するものより優先されますが、そのビルドは再び高性能コアとディスクの最大速度を使えるようになりました。バックグラウンド状態では、ほかに何もしていないMacでもスループットが約10分の1に落ちていました。

## エージェント
- AIタブのドットは、そのセッションのバックグラウンドコマンドがまだ実行中の間は緑のままになり、セッションが終了したという通知は、そのバックグラウンド作業も終わってから届くようになりました。
