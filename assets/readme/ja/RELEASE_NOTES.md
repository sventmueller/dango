## フォントサイズ
- 新しい設定“サイドバーとタブのフォントサイズ”で、サイドバー、そのアイコン、タブバーを10〜18ポイントに設定できます。サイドバーの各パネル、左側のアイコンバー、ウインドウのタブタイトル、各ペインのタブバーが、テキスト、アイコン、行、その間隔まで同じ比率で拡大・縮小します。開いているウインドウにもすぐに反映されます。
- エディタとターミナルのフォントサイズが、開いているエディタにもMarkdownのスタイルや行番号を含めてすぐに反映されるようになり、Markdownのプレビューも同じ比率で拡大・縮小します。
- AIタブのヘッダが、タイムライン、メッセージフィールド、ステータス行と同じく、AIタブのフォントサイズに従うようになりました。
