Dangoの最初のリリースです。Dangoは、コーディングエージェントと一緒に作業するためのネイティブなmacOSエディタです。エディタ、ターミナル、ブラウザ、Git、CI、デバッガ、AIスレッド、作業指示のためのSoftware Factoryが、フォルダごとに1つのウインドウにまとまります。アプリはAppKit上でRustで書かれており、WebKitはブラウザタブでのみ使われます。インターフェイスは35言語に対応しています。

## 動作環境
- macOS 14以降、Appleシリコン搭載またはIntel搭載のMac。
- AIスレッドには、選択したエージェントが必要です。Claudeにはサインイン済みの`claude`コマンドが必要です。CodexにはNode.jsが必要で、求めに応じてアプリが固定バージョンのパッケージをインストールします。AntigravityとOpenCodeは、手元の`agy`または`opencode`か、固定バージョンのダウンロードを使います。内蔵エージェントにはAPIキー、またはこのMac上のOllamaかLM Studioが必要です。
- 言語サーバとデバッグアダプタは、求めに応じてインストールされます。goplsと`dlv`にはGoが必要です。TypeScript、Python、JSON、YAML、CSS、HTML、ESLint、シェルの各サーバとJavaScriptデバッガにはNode.jsが必要です。clangd、sourcekit-lsp、`lldb-dap`はXcode Command Line Toolsに含まれています。
- 編集の予測には、GitHub Copilotのサブスクリプション（無料プランでも可）か、OllamaまたはLM Studioのfill-in-the-middleモデルが必要です。

## ウインドウ
- ファイル、ターミナル、ブラウザのページ、AIスレッド、差分、プレビューは、どれもフォルダのウインドウのmacOSタブになります。タブバーの末尾にある“+”と⌘Tで、新規ファイル、ターミナル、ブラウザ、インストール済みの各エージェントを開けます。エージェントは専用のGitワークツリーでも開けます。
- サイドバーは“ファイル”、“検索”、“エージェント”、“Git”、“デバッグ”、“CI”、“テスト”、“コンテナ”、“Software Factory”を切り替えます。使わないものは右クリックで非表示にできます。ツールバーには、編集した場所をたどる戻る／進む（⌃-と⌃⇧-）、ブランチ、“クイックオープン”、“アクティビティ”の概要があります。
- ウインドウはXcodeと同じように左右または上下のペインに分割でき、好きなだけ入れ子にできます。各ペインは専用のタブバーで複数の書類を重ねて保持します。“横に開く”で、2つ目の書類を1つ目の横に表示します。
- 再起動やクラッシュのあとも、各ウインドウはタブとペインとともに復元され、未保存のテキストがあるエディタはそのテキストごと復元されます。
- イメージ、オーディオ、ビデオ、フォント、Office書類はQuick Lookでタブに開き、PDFはPDFKitで開きます。

## エディタ
- シンタックスカラー、行番号、最後のコミットに対する変更マーク、検索と置換、“クイックオープン”（⌘P）、プロジェクト検索（⇧⌘F）。数千行におよぶファイルでも、カラーとMarkdownのスタイルが入力を妨げることなく追従します。
- 自動インデント、`.editorconfig`に従ったタブまたはスペース、括弧のペア、コメントの切り替え、折りたたみ、行へ移動、空白文字の表示、行の折り返し、ミニマップ、外側のスコープの見出しの固定表示。
- 複数のキャレット: ⌥クリック、⌥ドラッグで列を選択、⌘Dで次の出現箇所。
- **Vimモード:** “エディタ”メニューでオンにでき、ノーマル・挿入・ビジュアルの各モード、モーションとオペレータ、レジスタ、マーク、マクロ、検索、Exコマンドに対応します。メッセージはインターフェイスの言語で表示されます。
- HTML、CSS、JSXの補完でEmmetの省略記法を使えます。必要なら、保存時にESLintの問題を修正します。
- ファイルのエンコーディング、バイトオーダーマーク、改行コードは保持されます。ディスク上で変更されたファイルは、エディタに未保存のテキストがなければ再読み込みされます。未保存のテキストがある場合は、バーに差分とマージが表示されます。
- **編集の予測:** 入力中に提案がグレーで表示され、Tabキーで確定できます。提案は、設定での選択に応じてGitHub CopilotまたはOllamaかLM Studioのローカルモデルから届きます。ローカルモデルなら、コードはこのMacから出ません。

## 言語サーバ
Go、Rust、TypeScriptとJavaScript、Python、C、C++とObjective-C、Swift、シェルスクリプト、JSON、YAML、CSS、HTML、TOML、Markdown、Lua、TypeScriptサーバと並ぶESLint、さらに設定で追加した独自のサーバ。診断（行末にも表示）、ホバー、補完、シグネチャヘルプ、定義・型定義・実装へ移動、参照、呼び出し階層と型階層、名前の変更、フォーマット、セマンティックカラー、折りたたみ、アウトライン。行内に型とパラメータ名を表示。電球の奥にクイックフィックスとリファクタリング（⌥⌘A）。プロジェクトのシンボルは⌥⌘O、または“クイックオープン”で`#`。TypeScriptプロジェクト自身の`tsc`が言語サーバとして使える場合は、それを使います。

## デバッガ
ブレークポイント（条件付きも可）、ステップ実行、スレッドとそのコールスタック、インスペクタ（⌥⌘I）での変数とウォッチ式、プログラムの一時停止中にコードの横に表示される値、一時停止中のフレームで式を評価するデバッグコンソール。Rust、C、C++、Swiftは`lldb-dap`、Goは`dlv`、JavaScriptとTypeScriptはJavaScriptデバッガ、Pythonはdebugpyで動作します。プロジェクトの`.vscode/launch.json`も読み込みます。“デバッグ”メニューはXcodeのショートカットを使います。

## テストとコンテナ
- “テスト”パネルは、Rust、Go、Python、Jest、Vitest、Bunのプロジェクトのテストを最初の実行前から一覧表示します。1つのテスト、1つのファイル、またはすべてを実行し、各結果をリアルタイムで表示して、エディタのガターに印を付けます。
- “コンテナ”パネルは、Dockerのコンテナ、イメージ、ボリューム、Composeプロジェクトを一覧表示します。それらの起動、停止、削除ができ、ログを追いかけ、ターミナルタブでシェルを開きます。

## ターミナル
タブで開くターミナルは、ログインシェルの環境で動作し、Metalで描画されます。イメージをペーストまたはドロップすると、ターミナルで実行中のコーディングエージェントに渡されるか、保存したコピーのパスがペーストされます。⌘クリックでリンクやファイル名を開けます。ターミナルから起動した開発サーバは、ブラウザタブで開けます。

## Markdown
Markdownファイルは、横にプレビューを表示した状態で開きます（⇧⌘V）。数式、Mermaid・Graphviz・PlantUMLの図、フォルダ内のイメージも表示されます。“フォーマット”メニューで、太字、斜体、リンク、見出し、リスト、引用、コードブロックを設定できます。Wordやウェブページからペーストしたテキストは、Markdownとして取り込まれます。**ファイル › 書き出す**で、PDF、単一のHTMLファイル、Word書類に書き出せます。Splatがインストールされていれば、**ファイル › Splatで開く**で書類をSplatで開けます。

## ブラウザ
アドレスフィールド、戻る／進む、検索、確認付きのダウンロード、Web Inspectorを備えたブラウザタブ。

## Git
Gitパネルでは、ファイル単位またはハンク単位のステージと破棄、コミット、コミットしてプッシュまたは同期、ブランチ、スタッシュ、マージの競合、最近のコミットのグラフを扱えます。Blameは、カーソル行を最後に変更した人を表示するか、ファイル全体について列で表示します。ボタン1つでAIがコミットメッセージを書きます。差分が送信されるのは、gitleaksがシークレットを見つけなかった場合だけで、各コミットもシークレットがないか確認されます。AIスレッドは専用のGitワークツリーで作業でき、パネルにはその変更内容が表示されます。作業はマージまたはチェリーピックで取り込めます。

## CI
GitHub ActionsとGitLab CIに対応し、GitHub Enterprise Serverとセルフマネージド版GitLabも使えます。現在のブランチの実行、ジョブ、ログを表示。失敗したジョブ、単一のジョブ、または（GitHubでは）実行全体の再実行、手動ジョブの開始や待機中のデプロイの承認、新しいパイプラインや手動で開始できるワークフローの開始、キャンセルができます。オープン中のMerge RequestまたはPull RequestとIssueも同じパネルに一覧表示され、ブラウザタブで開けます。失敗したジョブのログは、外部からのテキストとして印を付けてエージェントに渡せます。トークンは、キーチェーン、`gh`または`glab`、ログインシェルの環境、または手動入力から取得します。

## AI
どのエージェントも、同じタイムラインを持つAIタブで動作します。応答、出力付きのツール呼び出し、権限の要求、質問、承認やコメントができるプラン、To-do、サブエージェント、バックグラウンドタスクが表示されます。タブのヘッダにある2つのボタンで、実行中のサブエージェントとバックグラウンドプロセスを一覧表示できます。アプリはプロンプトのたびにチェックポイントを作成し、変更はメッセージごとに確認して巻き戻せます。新しいスレッドは“手動”モードで始まり、破壊的なGitコマンドが恒久的に許可されることはありません。“アクティビティ”の概要には、実行中のすべてが一覧表示されます。タブの緑の点は作業中のセッション、赤の点は応答待ちのセッションを示し、ほかの作業をしている間にセッションが終了したり待機したりすると通知でお知らせします。タイムライン、メッセージフィールド、ステータス行の文字サイズは、設定でそれぞれ個別に指定できます。
- **Claude**は`claude`コマンドをそのまま使い、セッション、サブエージェント、バックグラウンドタスク、コンテキスト、使用量、スマートフォンからのRemote Controlに対応します。
- **Codex**はそのアプリサーバ、**OpenCode**はそのサーバを通じて、それぞれ独自のプロトコルで動作します。スレッド、エージェント自身での巻き戻し、CodexではRemote Controlにも対応します。
- **ACPエージェント:** Antigravity。求めに応じてACPレジストリからほかのエージェントも追加できます。インストールしたエージェントはテスト済みのバージョンに固定され、チェックサムで検証されます。
- **内蔵エージェント:** Anthropic、OpenAI、Google Gemini、OpenRouter、Ollama、LM Studio、およびOpenAIまたはAnthropicのAPIに対応したサーバ。ファイル、検索、コマンド、診断、ウェブリクエスト用のツールを備えています。キーはキーチェーンに保管されます。
- エージェント固有のコマンドは、どのエージェントでも同じように、タブ上のオーバーレイとして開きます。状況、書き出し、MCPサーバ、権限、フック、メモリ、構成、スキル、プラグイン、モデル、アカウント、フィードバックです。
- スレッドごとのサンドボックススイッチで、エージェントのコマンドにできることを制限できます（エージェントが対応している範囲で）。
- ターミナルの出力、ウェブページ、CIログなどの外部のテキストは、信頼されていないものとして印を付けてエージェントに渡されます。

## Software Factory
単発のプロンプトではなく、作業指示で進めます。作業指示は検収基準を備えた目標で、手で書くか、Issueから取り込みます。各作業指示は専用のGitワークツリーで、異なるベンダーのエージェントが決まったロールを担って計画、ビルド、チェックします。プランナーが仕様を書き、ビルダーが作業を行い、別のベンダーのレビュアーがすべての基準を確認します。ビルドやテストなど、プロジェクトのゲートコマンドはサンドボックスで実行され、見つかった問題はビルダーが修正します。
- 判断するのは2か所です。仕様を承認し、結果をエビデンスとともに、全体またはセクションごとに検収します。検収しない限り、何も取り込まれません。
- “Software Factory”のパネルとタブには、各作業指示の工程、コスト、何を待っているかが表示されます。作業指示のタブには、そのタイムライン、エビデンス、次のステップが表示され、実行中のセッションをAIタブで開けます。
- 作業指示ごとと1日ごとの予算、ターン数の上限、終了時・スリープ時・バッテリー残量低下時の一時停止、そしてあらゆる作用の前に書き込まれるログにより、作業指示は再起動後に再開されます。
- 選んだラベルの付いたIssueを作業指示として取り込めます。検収した作業指示は、クリックひとつで、元のIssueへのコメント付きのMerge Requestとして送り出せます。パス範囲が分かれている作業指示は並行して実行され、順番に取り込まれます。
- エージェントとベンダーごとの指標、初回通過率によるルーティング、繰り返し出る所見からの`AGENTS.md`と`CLAUDE.md`へのルール提案、プロジェクトのワークフローファイルによる定期的な作業指示。
- フォルダのワークフローファイル`.dango/factory.toml`には、ゲート、リスククラス、パス範囲が記述されます。変更されたゲートコマンドや制限を緩める変更は、確認するまで保留されます。

## 音声入力
Lowspeakの音声認識で、AIのメッセージフィールドとエディタに音声入力できます。マイクボタン、⌃⌥D、またはDangoがアクティブなアプリのときはfnキーで開始します。Lowspeakの設定とモデルを使います。オンラインの文字起こしにはOpenAIまたはGroqのキーが必要です。

## アップデート
アプリはSparkleで自動的にアップデートされます。2回目の起動時に、自動で確認してよいかを尋ねます。同意するまでは、一切リクエストを送信しません。**Dango › アップデートを確認…**で、すぐに確認できます。

## アクセシビリティ
サイドバー、タブ、AIタイムラインのカード、GitとCIの行、Software Factory、デバッガ、ターミナルのテキストにVoiceOver用の名前を付けています。`keybindings.json`で変更できるショートカットにより、すべてをキーボードで操作できます。“コントラストを上げる”と“視差効果を減らす”に対応しています。右から左に書く言語のインターフェイスでも、コード表示は左から右のままです。詳しくはACCESSIBILITY.mdをご覧ください。

## プライバシー
テレメトリ、解析、クラッシュレポートは一切ありません。アプリが接続するのは、ユーザが開始したものだけです。使用するエージェント、要求したダウンロード、サインインしたCIホスト、選択した場合のCopilotによる予測、選択した場合のオンライン文字起こし、開いたページ、そして許可したあとのアップデート確認です。キーとトークンはmacOSのキーチェーンに保管され、Software Factoryのエージェントがそれらを目にすることはありません。

## 既知の制限
- ブラウザ経由のCIへのサインインはオフになっています。`gh`、`glab`、トークン、または環境変数を使ってください。
- ターミナル、Git、言語サーバ、エージェントに引き継がれてしまうため、アプリはApp Sandboxなしで動作します。フォルダで設定されたものが実行されるのは、そのフォルダを信頼したあとです。AntigravityとOpenCodeには、アプリからオンにできるサンドボックスがありません。
- Codexのプロトコルには読み取りの制限がないため、Software FactoryではCodexのビルダーやレビュアーがワークツリーの外も読み取れます。書き込みはワークツリーの中に限られます。
- Claudeの使用量とコンテキストの内訳は、プロトコルのうち試験的とされている部分に依存しており、その部分がない場合は表示されません。会話の巻き戻しはClaude、Codex、OpenCodeで使えます。ほかのエージェントでは、コードだけが巻き戻されます。
- Gemini CLIは提供していません。Googleが個人アカウントでのサインインを終了し、Antigravityへの移行を案内しているためです。以前のGeminiスレッドは引き続き読めます。
