## ツールバー
- 右からの新しい並び：「新規ターミナル」「新規AIスレッド」「新規ブラウザタブ」を1つのグループにまとめ、その左に「右に分割」「下に分割」と入力フィールドのスイッチ、続いて「クイックオープン」と「アクティビティ」。
- 入力フィールドのスイッチは手前のターミナルのフィールドをオン/オフし、フィールドがオンの間はアクセントカラーで表示されます。手前にターミナルがないときは淡色表示になります。
- エージェントが1つだけインストールされている場合、「新規AIスレッド」は1回のクリックでそれを開きます。それ以外の場合はクリックでエージェントがメニューに表示されます。ボタンを長押しすると常にメニューが表示されます。
- 設定ボタンはサイドバーの下端の、より低い位置に移りました。

## ターミナル
- 入力フィールドなしでも、入力したコマンドにフィールドと同じ色が付きます。コマンド、サブコマンド、オプション、変数、演算子に色が付き、シェルが実行できないコマンドには赤い破線の下線が付きます。シェル自身が設定した色はそのまま残ります。
- 入力フィールドなしでも、単語を入力すると候補リストが自動的に開きます。Return で行を実行し、Tab または → で灰色の候補を受け入れます。↑ または ↓ で選択を移動した後は、選択した項目を受け入れます。Esc でその単語のリストを閉じ、「設定 › ターミナル」でオフにできます。
