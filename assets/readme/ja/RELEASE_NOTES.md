## AIタブ
- バックグラウンドコマンドの“出力を表示”は、その時点の出力のコピーではなく、コマンドの実行中に出力を追い続けるタブを開くようになりました。タブは出力の末尾で開き、新しい行が届いても、上にスクロールするまでは末尾に留まります。末尾までスクロールし直すと、再び出力を追います。すでに開いているタブで“出力を表示”を使うと、そのタブが末尾の位置で前面に表示されます。
  - `make > build.log 2>&1`のように出力を自らファイルに書き込むコマンドの場合、タブはそのファイルを、内容が増えるのに合わせて表示します。
  - コマンドが終了すると、タブには出力全体が表示されます。“エディタで開く”をクリックすると、その元になっているファイルが開きます。
  - タブは前面にある間だけ出力を読み込みます。
