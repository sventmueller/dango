## ターミナル
- ターミナルが、Dangoの姉妹アプリであるターミナルアプリTapaのものになり、Tapaが加える機能がすべて使えるようになりました。エージェントへのイメージのペースト、ブラウザタブでの開発サーバ、⌘クリックでエディタで開く機能など、これまでのDangoのターミナルにできたことはそのまま残ります。
- **表示 › 入力フィールドの表示/非表示**（ターミナルにフォーカスがあるときの⌘I）で、コマンドラインをテキストフィールドに変え、その上にフォルダとGitブランチを表示します。コマンドは部分ごとに色分けされ、シェルが実行できないコマンドには赤い破線の下線が付きます。
- 提案は、入力フィールドでも、入力フィールドなしでも、入力中にグレイで表示されます。履歴、700を超えるコマンドラインツールの仕様、そしてgitブランチ、`package.json`のスクリプト、make、just、cargoのターゲットなどのプロジェクトから提案します。→で提案を確定し、Tabで補完します。候補が複数ある場合はメニューが開き、入力すると絞り込まれます。提案がネットワークを使うことはありません。
- コマンドブロックでは、⌘↑と⌘↓でプロンプト間をジャンプし、**編集**メニューでコマンドの出力を選択、コピー、保存でき、ブックマークで行に印を付けられます。**コマンドをブロックとして表示**をオンにすると、バーが各ブロックを示し、失敗したコマンドには印が付き、ブロックの上のボタンにそのステータスと所要時間が表示されます。
- **ブロックをエージェントに送信**（“編集”メニューとターミナルのコンテキストメニュー）は、AIタブを開き、現在のブロックのコマンドラインと出力を“外部コンテンツ”として添付します。
- **検索**（ターミナルにフォーカスがあるときの⌘F）は、正規表現、大文字と小文字の区別、単語単位で履歴全体を検索します。スクロールバーには検索結果の位置が示されます。
- プログラムの通知（OSC 9とOSC 777）とベルは、ターミナルが見えていない間、そのタブに赤の点を付けます。ほかのアプリが前面にあるときは、通知はmacOSに送られます。プログラムが報告する進行状況（OSC 9;4）は、タブにはリングとして、Dockのアイコンにはバーとして表示されます。
- ダブルクリックでURL、パス、ハッシュをまとめて選択し、⌥ドラッグで矩形を選択します。**書式付きでコピー**は色とスタイルを保ち、**キーボードで選択**ではVimのキーで選択範囲を動かします。
- そのまま実行されてしまう複数行のペーストは、実行前に表示されます。**Dango › キーボード入力のセキュリティを保護**は、ターミナルに入力する内容をほかのアプリが読み取れないようにします。
- Webアドレス、`mailto:`、ファイル以外の種類のリンクは、ターミナルから開かなくなりました。

## 設定
- **設定 › ターミナル**では、新しいターミナルの入力フィールド、そのVimのキー、提案、コマンドの色分け、不明なコマンドの下線、コマンドブロック、選択範囲のすぐのコピー、複数行のペーストの事前表示、メタキーとしての⌥を切り替えます。メタキーとしての⌥は“一般”からここに移動しました。
