## 速度とメモリ
- エージェントが起動するものは、ビルド、テスト、シェル、MCPサーバなど言語を問わずすべて、macOSのバックグラウンド状態で実行されるようになりました。優先度は最も低く、ディスクとネットワークへのアクセスも抑えられます。エージェント自体は、Claudeのサブエージェントも含めて中程度の優先度で実行されます。エージェントがフル稼働していてもDangoが遅くなることはなくなりました。これはSoftware Factoryのエージェントにも当てはまります。
- 復元されたウインドウは、表示されているものだけを起動します。ほかのタブの後ろにあるAIタブは、前面に来たときやプロンプトを受け取ったときにCLIを起動し、ブラウザ、サイトプレビュー、ターミナルの各タブは、初めて表示されたときにページを読み込むかシェルを起動します。
- 時間のかかるプロジェクト検索で、実行中に結果全体を描き直すことがなくなりました。Software Factory、CIログ、“テスト”パネルは、表示されていない間は処理を減らします。テストとデバッグ構成はそのパネルが初めて表示されたときに読み込まれ、非表示の“CI”パネルと“コンテナ”パネルは表示されるまで何も読み込みません。
- 長いセッションで必要なメモリが減りました。完了した差分はカードに表示される行だけを保持し、回答済みの権限リクエストは入力を解放し、ターミナルのグリフキャッシュは際限なく大きくなることがなくなり、“ファイル”パネルと“Git”パネルはなくなった行を解放します。
- プログラム自体のサイズが約40%小さくなりました。

## ウインドウとメニュー
- ペインを閉じると、そのタブは閉じられずに前のペインへ、前のペインがなければ後ろのペインへ移動するようになりました。プレビューのペインと最後のペインだけは、タブと一緒に閉じます。
- “表示”メニューでは、パネルがサイドバーのアイコンと同じ順に並びます。
- “エージェントを管理…”は+メニューからなくなりました。“エージェント”パネルの“+ 新規セッション”の下には引き続きあります。
