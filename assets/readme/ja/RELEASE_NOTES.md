## AIタブ
- 3分間表示されていないAIタブは、セッションがアイドル状態の間、Claudeプロセスを終了します。会話と入力した内容はタブに残り、次のプロンプトでセッションが再開されます。Claudeが作業中のとき、プロンプトが待機中のとき、未回答の質問があるとき、サブエージェント、バックグラウンドタスク、コマンドのいずれかがまだ実行中のとき、またはRemote Controlがオンのときは、タブはプロセスを保持します。
- エージェントを終了すると、エージェントが独自のプロセスグループまたはセッションで起動したコマンドも終了します。以前は、これらのコマンドがエージェントの終了後も残ることがありました。
- タイムラインは、それまでのすべての行のインデックスを作成し直すのではなく、新しい項目を末尾に追加します。

## 速度
- 復元されたウインドウが速く開くようになりました。未保存の変更がないファイルタブは、前面に来たときに初めてファイルを読み込みます。
- パネルが非表示になっているプロジェクト検索は一時停止し、パネルが表示されると再開します。
- エディタのGit変更マーカーは、ファイルごとに一度に最大1つの比較しか実行しません。比較中の編集は1回の追加比較にまとめられ、ファイルのコミット済みのテキストはコミットが変わったときにだけ読み直されます。
- コードが折りたたまれたファイルのミニマップは、行ごとではなく、折りたたまれていない範囲ごとに1つの項目を保持します。
