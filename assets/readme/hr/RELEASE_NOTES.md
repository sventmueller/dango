## AI kartica
- `/resume` otvara pregled ranijih sesija agenta u ovoj mapi; odabrana sesija nastavlja se u vlastitoj kartici.
- Agenti i Copilot sada saznaju stvarnu verziju aplikacije Dango umjesto 0.0.0.

## Terminal
- Terminal radi na novom zaslonskom pogonu: iznova iscrtava samo promijenjene retke, a njegova povijest zauzima manje memorije dok program u njemu miruje.

## Kartice
- Kartica otvorena iz izbornika + ili pomoću ⌘T pojavljuje se na kraju trake kartica umjesto pokraj one sprijeda.
