# Dango

**ตัวแก้ไขแบบเนทีฟบน macOS สำหรับทำงานร่วมกับเอเจนต์เขียนโค้ด**

Dango รวมโค้ด เอเจนต์ที่แก้ไขโค้ดนั้น และทุกสิ่งรอบตัวไว้ในหน้าต่างเดียวต่อหนึ่งโฟลเดอร์ ได้แก่ ตัวแก้ไขพร้อมเซิร์ฟเวอร์ภาษาและการคาดการณ์ขณะพิมพ์ เทอร์มินัล เบราว์เซอร์ Git CI ดีบักเกอร์ และเธรด AI กับ Claude, Codex, Antigravity, OpenCode หรือเอเจนต์ที่มีอยู่ในแอป เอเจนต์ทุกตัวทำงานในไทม์ไลน์เดียวกัน ถามก่อนเปลี่ยนแปลงไฟล์หรือเรียกใช้คำสั่ง และเก็บจุดตรวจสอบไว้ก่อนทุก Prompt คุณจึงตรวจทานและกรอกลับสิ่งที่เอเจนต์ทำได้ทีละข้อความ สิ่งที่โฟลเดอร์กำหนดค่าไว้จะไม่ทำงานจนกว่าคุณจะเชื่อถือโฟลเดอร์นั้น และข้อความจากภายนอกจะส่งถึงเอเจนต์โดยทำเครื่องหมายว่าไม่น่าเชื่อถือ คุณป้อนตามคำบอกลงในตัวแก้ไขและช่องข้อความได้ และการรู้จำเสียงพูดสามารถทำงานบน Mac ของคุณเองได้ Dango เขียนด้วย Rust บนตัวควบคุม AppKit แท้ ไม่ใช้ Electron รองรับ 35 ภาษา และไม่มีการวัดและส่งข้อมูลทางไกล

## ภาพรวมความสามารถ

- **เอเจนต์ทุกตัวในไทม์ไลน์เดียว** Claude ผ่านคำสั่ง `claude` ของตัวเอง Codex, Antigravity และ OpenCode ผ่าน Agent Client Protocol เอเจนต์อื่นเพิ่มเติมจากรีจิสทรี ACP และเอเจนต์ที่มีอยู่ในแอปสำหรับ Anthropic, OpenAI, Google Gemini, OpenRouter, Ollama และ LM Studio คำตอบ การเรียกเครื่องมือ คำขอสิทธิ์ แผน สิ่งที่ต้องทำ เอเจนต์ย่อย และงานเบื้องหลัง มีหน้าตาเหมือนกันไม่ว่าเอเจนต์ตัวใดทำงานอยู่
- **ตรวจทานและกรอกลับ** ก่อนทุก Prompt Dango จะเก็บจุดตรวจสอบไว้ สิ่งที่เอเจนต์เปลี่ยนแปลงสามารถตรวจทานและกรอกลับได้ทีละข้อความ และเธรดสามารถทำงานใน Git Worktree ของตัวเอง แล้วส่งมอบงานด้วยการผสานหรือ Cherry-pick
- **หนึ่งหน้าต่างต่อหนึ่งโฟลเดอร์** ไฟล์ เทอร์มินัล หน้าเบราว์เซอร์ เธรด AI Diff และการแสดงตัวอย่าง เป็นแถบ macOS ของหน้าต่างนั้น แถบด้านข้างมี ไฟล์ ค้นหา เอเจนต์ Git การทดสอบ ดีบัก CI และ คอนเทนเนอร์
- **ตัวแก้ไขโค้ดตัวจริง** สีไวยากรณ์ เคอร์เซอร์หลายตัว การพับโค้ด `.editorconfig` เซิร์ฟเวอร์ภาษาสำหรับ 17 ภาษาพร้อมการเติมโค้ด ไปที่คำจำกัดความ การอ้างอิง การเปลี่ยนชื่อ แก้ไขด่วน และลำดับชั้น รวมถึงการคาดการณ์ขณะพิมพ์จาก GitHub Copilot หรือโมเดลในเครื่อง
- **มีดีบักเกอร์ Git และ CI ในตัว** เบรกพอยต์และการทำงานทีละขั้นสำหรับ Rust, C, C++, Swift, Go, JavaScript, TypeScript และ Python การ Stage ทีละส่วนที่เปลี่ยนแปลง Branch, Stash ความขัดแย้ง และกราฟ Commit การรัน Job และล็อกจาก GitHub Actions และ GitLab CI
- **ระมัดระวังกับโฟลเดอร์ของคุณ** โฟลเดอร์ที่คุณยังไม่ได้เชื่อถือจะไม่เริ่มสิ่งใดเลย ไม่มีกระบวนการ Git เซิร์ฟเวอร์ภาษา Hook หรือเอเจนต์ คำสั่ง Git ที่ทำลายข้อมูลจะไม่ได้รับอนุญาตแบบถาวรเลย และทุก Commit จะถูกตรวจหาข้อมูลลับ
- **การป้อนตามคำบอก** พูดลงในตัวแก้ไขและช่องข้อความ แบบออนไลน์ผ่าน OpenAI หรือ Groq หรือในเครื่องด้วย Whisper และ Parakeet
- **เนทีฟอย่างแท้จริง** หน้าต่าง แถบ เมนู และแถบเครื่องมือแบบ AppKit ใช้ TextKit 2 สำหรับตัวแก้ไข Metal สำหรับเทอร์มินัล และใช้ WebKit เฉพาะในแถบเบราว์เซอร์ โหมดมืด เพิ่มความต่างของสี และ VoiceOver ทำงานเหมือนในแอป Mac ทุกแอป
- **ในภาษาของคุณ** อินเทอร์เฟซมีให้ใน 35 ภาษา ได้แก่ อาหรับ คาตาลัน จีน (ตัวย่อ) จีน (ตัวเต็ม) โครเอเชีย เช็ก เดนมาร์ก ดัตช์ อังกฤษ ฟินแลนด์ ฝรั่งเศส เยอรมัน กรีก ฮีบรู ฮินดี ฮังการี อินโดนีเซีย อิตาลี ญี่ปุ่น เกาหลี มาเลย์ นอร์เวย์ โปแลนด์ โปรตุเกส (บราซิล) โปรตุเกส (โปรตุเกส) โรมาเนีย รัสเซีย สโลวัก สโลวีเนีย สเปน สวีเดน ไทย ตุรกี ยูเครน และเวียดนาม

## ความต้องการของระบบ

- macOS 14 Sonoma ขึ้นไป บน Apple Silicon หรือ Intel Dango พัฒนาและทดสอบบน macOS 27
- สำหรับเธรด AI ต้องมีเอเจนต์ที่คุณต้องการใช้ ดู [เอเจนต์ AI](#เอเจนต์-ai)
- สำหรับเซิร์ฟเวอร์ภาษาและอะแดปเตอร์ดีบัก ซึ่ง Dango จะติดตั้งให้เมื่อคุณขอ: Go สำหรับ gopls และ `dlv` Node.js สำหรับเซิร์ฟเวอร์ TypeScript, Python, JSON, YAML, CSS, HTML และเชลล์ รวมถึงดีบักเกอร์ JavaScript และ Xcode Command Line Tools สำหรับ clangd, sourcekit-lsp และ `lldb-dap` ส่วน rust-analyzer ดาวน์โหลดจากรุ่นเผยแพร่บน GitHub
- สำหรับการคาดการณ์ขณะพิมพ์ ต้องมีการสมัครใช้บริการ GitHub Copilot (แบบฟรีก็ได้) หรือโมเดล fill-in-the-middle ใน Ollama หรือ LM Studio

## การติดตั้ง

**จากดิสก์อิมเมจ** แต่ละรุ่นเป็นดิสก์อิมเมจ `Dango-<version>.dmg` ที่มีแอป Universal หนึ่งแอปสำหรับ Apple Silicon และ Intel ลงนามด้วย Developer ID และผ่านการรับรองโดย Apple เปิดไฟล์แล้วลาก Dango ไปวางบนโฟลเดอร์แอปพลิเคชัน Homebrew Cask จะติดตั้งอิมเมจเดียวกันนี้ ขณะนี้ยังไม่มีรุ่นใดเผยแพร่

**การอัปเดต** Dango ที่ติดตั้งจากดิสก์อิมเมจจะอัปเดตตัวเองผ่าน [Sparkle](https://sparkle-project.org) เมื่อเปิดครั้งที่สอง แอปจะถามว่าสามารถตรวจหาอัปเดตเองได้หรือไม่ และจะไม่ส่งคำขอใดๆ จนกว่าคุณจะยินยอม **Dango › ตรวจหารายการอัปเดต…** ตรวจหาทันที การอัปเดตลงนามด้วยคีย์ของแอปเอง ซึ่ง Sparkle จะตรวจสอบก่อนติดตั้งสิ่งใด แอปที่คุณบิลด์เองไม่มีตัวอัปเดต

**จากซอร์สโค้ด** ดู [การบิลด์จากซอร์สโค้ด](#การบิลด์จากซอร์สโค้ด) แล้วย้าย `target/release/Dango.app` ไปไว้ใน `/Applications`

**คำสั่งเทอร์มินัล** **Dango › ติดตั้งคำสั่ง “dango”…** เขียนสคริปต์ขนาดเล็กไว้ที่ `~/.local/bin/dango` โดยไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ ทั้งนี้ `~/.local/bin` ต้องอยู่ใน `PATH` ของคุณ จากนั้น `dango .` จะเปิดโฟลเดอร์ปัจจุบัน และ `dango file.rs` จะเปิดไฟล์ Dango จะไม่แทนที่ไฟล์ในตำแหน่งนั้นที่ตัวเองไม่ได้เขียนไว้

## เริ่มต้นใช้งาน

1. **เปิดโฟลเดอร์** ด้วย ⌘O หรือ `dango <folder>` ในครั้งแรก Dango จะถามว่าคุณเชื่อถือโฟลเดอร์นั้นหรือไม่ (ดู [ความเชื่อถือ](#ความเชื่อถือ))
2. **แถบด้านข้าง** สลับระหว่าง ไฟล์ (⌘1) ค้นหา (⌘2) เอเจนต์ (⌘3) Git (⌘4) การทดสอบ (⌘5) ดีบัก (⌘6) CI (⌘7) และ คอนเทนเนอร์ (⌘8) คลิกขวาเพื่อซ่อนส่วนที่คุณไม่ใช้ และ ⌃⌘S พับแถบด้านข้างเก็บ
3. **เอกสารทุกฉบับเป็นแถบ** ในหน้าต่างของโฟลเดอร์ ซึ่งเป็นแถบของ macOS เอง ปุ่ม “+” ที่ท้ายแถวแถบและ ⌘T มีตัวเลือกไฟล์ใหม่ เทอร์มินัล เบราว์เซอร์ และเอเจนต์ทุกตัวที่ติดตั้งไว้ รวมถึงใน Git Worktree ของตัวเอง การกดปุ่ม “+” ค้างไว้จะแสดงตัวเลือกเดียวกันเป็นเมนู
4. **เปิดอย่างรวดเร็ว** ด้วย ⌘P ค้นหาไฟล์ และค้นหาสัญลักษณ์ของโปรเจ็กต์เมื่อใช้ `#` ส่วน ⇧⌘F ค้นหาและแทนที่ในโปรเจ็กต์
5. **คุยกับเอเจนต์** ในแถบ AI ⌘Esc ย้ายโฟกัสแป้นพิมพ์ไปที่ช่องข้อความของเอเจนต์และกลับมา
6. **การตั้งค่า** ด้วย ⌘, มีแถบ ทั่วไป CI เอเจนต์ เอเจนต์ในตัว เซิร์ฟเวอร์ภาษา การป้อนตามคำบอก และการคาดการณ์

แถบเครื่องมือมีปุ่มย้อนกลับและไปข้างหน้าตามตำแหน่งที่คุณแก้ไข (⌃- และ ⌃⇧-) Branch เปิดอย่างรวดเร็ว และภาพรวมกิจกรรม ซึ่งแสดงทุกอย่างที่กำลังทำงาน **เปิดไว้ด้านข้าง** ในเมนูบริบทของไฟล์จะแสดงเอกสารที่สองข้างเอกสารแรก หลังจากเริ่มใหม่หรือแอปขัดข้อง ทุกหน้าต่างจะกลับมาพร้อมแถบของตัวเอง และตัวแก้ไขที่มีข้อความที่ยังไม่ได้บันทึกจะกลับมาพร้อมข้อความนั้น รูปภาพ เสียง วิดีโอ ฟอนต์ และเอกสาร Office เปิดในแถบผ่าน Quick Look ส่วน PDF เปิดผ่าน PDFKit

## เอเจนต์ AI

| เอเจนต์ | วิธีทำงาน | สิ่งที่ต้องมี |
|---|---|---|
| Claude | คำสั่ง `claude` ที่สื่อสารกันโดยตรงผ่านโปรโตคอล stream-json ของคำสั่งนั้น | ติดตั้ง `claude` และลงชื่อเข้าแล้ว Dango จะค้นหาใน `PATH` ของ Login Shell, `~/.local/bin`, `~/.claude/local`, `/opt/homebrew/bin` และ `/usr/local/bin` การลงชื่อเข้าทำได้ใน `claude` เท่านั้น |
| Codex | `codex-acp` ผ่าน Agent Client Protocol (ACP) | Node.js และ npm Dango จะติดตั้งแพ็กเกจเวอร์ชันที่กำหนดไว้ให้เมื่อคุณขอ |
| Antigravity | `agy acp` | `agy` ของคุณเองใน `PATH` หรือไฟล์ดาวน์โหลดเวอร์ชันที่กำหนดไว้ ซึ่งติดตั้งเมื่อคุณขอ |
| OpenCode | `opencode acp` | `opencode` ของคุณเองใน `PATH` หรือไฟล์ดาวน์โหลดเวอร์ชันที่กำหนดไว้ ซึ่งติดตั้งเมื่อคุณขอ |
| เอเจนต์ ACP อื่นๆ | จากรีจิสทรี ACP ซึ่งดึงข้อมูลเฉพาะเมื่อคุณขอ | สิ่งที่รายการในรีจิสทรีระบุ รายการที่ไม่มีเช็คซัมจะติดตั้งหลังจากคุณยืนยันแล้วเท่านั้น |
| เอเจนต์ในตัว | มีอยู่ในแอป พร้อมเครื่องมือสำหรับไฟล์ การค้นหา คำสั่ง การวินิจฉัย และคำขอเว็บ | คีย์ API สำหรับ Anthropic, OpenAI, Google Gemini หรือ OpenRouter ซึ่งเก็บไว้ในพวงกุญแจ หรือ Ollama หรือ LM Studio บน Mac เครื่องนี้โดยไม่ต้องใช้คีย์ หรือเซิร์ฟเวอร์ใดก็ได้ที่ใช้ API ของ OpenAI หรือ Anthropic |

**การตั้งค่า › เอเจนต์** แสดงว่า Mac เครื่องนี้มีเอเจนต์ใดบ้าง ติดตั้งเอเจนต์อื่นและการอัปเดตของเอเจนต์เหล่านั้น และเปิดรีจิสทรี ACP เอเจนต์ที่ Dango ติดตั้งจะถูกกำหนดไว้ที่เวอร์ชันที่ทดสอบแล้วและตรวจสอบกับเช็คซัมที่เผยแพร่ไว้ (npm integrity หรือ SHA-256) Dango ไม่เรียกใช้แพ็กเกจ `npx` ที่ไม่ได้ระบุเวอร์ชัน

### ไทม์ไลน์

เอเจนต์ทุกตัวทำงานในแถบ AI ที่มีไทม์ไลน์เดียวกัน ได้แก่ คำตอบ การเรียกเครื่องมือพร้อมผลลัพธ์ คำขอสิทธิ์ คำถาม แผนที่ให้อนุมัติและแสดงความคิดเห็น (⌥⌘K) สิ่งที่ต้องทำ เอเจนต์ย่อย และงานเบื้องหลัง ปุ่มสองปุ่มที่ส่วนหัวของแถบแสดงรายการเอเจนต์ย่อยและกระบวนการเบื้องหลังที่กำลังทำงาน กล่าวถึงไฟล์ `@terminal` หรือ `@browser` เพื่อส่งเนื้อหานั้นให้เอเจนต์ จุดสีเขียวบนแถบแสดงว่าเซสชันกำลังทำงาน จุดสีแดงแสดงว่าเซสชันกำลังรอคุณ และจะมีการแจ้งเตือนเมื่อเซสชันเสร็จหรือรอขณะที่คุณดูอย่างอื่นอยู่ สำหรับ Claude แถบสถานะจะแสดงบริบทและการใช้งาน

### สิทธิ์และโหมด

เธรดใหม่จะเริ่มในโหมด “ด้วยตนเอง” โดยเอเจนต์จะถามก่อนเปลี่ยนแปลงไฟล์หรือเรียกใช้คำสั่ง สำหรับคำสั่ง Git ที่ทำลายข้อมูล (`push --force`, `reset --hard`, `clean -fd`) Dango ไม่มีตัวเลือก “อนุญาตเสมอ” เอเจนต์ในตัวเก็บกฎ “อนุญาตเสมอ” แยกตามโปรเจ็กต์ แสดงรายการไว้ใน **การตั้งค่า › เอเจนต์ในตัว** และถามทุกครั้งสำหรับคำสั่ง Git ที่ทำลายข้อมูล ไม่ว่าจะเก็บกฎใดไว้ ส่วน Claude และเอเจนต์ ACP เก็บกฎเหล่านี้ไว้ในการกำหนดค่าของตัวเอง เมื่อใช้ “อนุญาตทั้งหมด” โดยไม่มีแซนด์บ็อกซ์ เธรดจะแสดงคำเตือนตลอดเวลา

### จุดตรวจสอบและ Worktree

ก่อนทุก Prompt Dango จะเก็บจุดตรวจสอบไว้เป็น Commit ภายใต้ `refs/ide-checkpoints/` ใน Repository ของโปรเจ็กต์ หรือในโฟลเดอร์ของตัวเองสำหรับโปรเจ็กต์ที่ไม่มี Git การ Push หรือ Fetch ตามปกติจะไม่นำจุดตรวจสอบเหล่านี้ไปด้วย สิ่งที่เอเจนต์เปลี่ยนแปลงสามารถตรวจทานและกรอกลับได้ทีละข้อความ เธรดสามารถทำงานใน Git Worktree ของตัวเอง แผง Git จะแสดงสิ่งที่เธรดเปลี่ยนแปลงและนำงานมาใช้ด้วยการผสานหรือ Cherry-pick

## ตัวแก้ไข

- **สีไวยากรณ์ หมายเลขบรรทัด และเครื่องหมายการเปลี่ยนแปลง** เทียบกับ Commit ล่าสุด ค้นหาและแทนที่ เปิดอย่างรวดเร็ว (⌘P) และการค้นหาในโปรเจ็กต์ (⇧⌘F)
- **การเยื้อง** เป็นไปตามไฟล์และ `.editorconfig`: แท็บหรือช่องว่าง การเยื้องอัตโนมัติ วงเล็บคู่
- **เคอร์เซอร์หลายตัว:** ⌥-คลิก ⌥-ลากเพื่อเลือกคอลัมน์ ⌃⇧↑ และ ⌃⇧↓ ⌘D สำหรับรายการถัดไปที่ตรงกัน
- **การพับโค้ด** (⌥⌘← และ ⌥⌘→ ใช้ร่วมกับ ⇧ เพื่อพับทั้งหมด) การสลับคอมเมนต์ (⌘/) ไปที่บรรทัด (⌃G) การแสดงช่องว่าง และการตัดบรรทัด (⌥Z)
- **ไฟล์คงการเข้ารหัสไว้ตามเดิม** รวมถึงเครื่องหมายลำดับไบต์และอักขระขึ้นบรรทัดใหม่ ไฟล์ที่ถูกเปลี่ยนบนดิสก์จะโหลดใหม่เมื่อตัวแก้ไขไม่มีข้อความที่ยังไม่ได้บันทึก มิฉะนั้นจะมีแถบเสนอให้ดูความแตกต่างและผสาน
- **การคาดการณ์ขณะพิมพ์** ขณะที่คุณพิมพ์ ข้อเสนอจะปรากฏเป็นสีเทา และกด Tab เพื่อรับ ข้อเสนอมาจาก GitHub Copilot หรือจากโมเดลในเครื่องใน Ollama หรือ LM Studio ตามที่เลือกไว้ใน **การตั้งค่า › การคาดการณ์** โมเดลในเครื่องจะเก็บโค้ดของคุณไว้บน Mac เครื่องนี้
- **มินิแมปและการเลื่อนแบบตรึง** (เมนูตัวแก้ไข): ภาพแคบๆ ของทั้งไฟล์ข้างข้อความ และบรรทัดหัวของบล็อกที่บรรทัดบนสุดอยู่ข้างใน ตรึงไว้เหนือบรรทัดนั้น
- **การวินิจฉัยที่ท้ายบรรทัด** (เมนูมุมมอง): ข้อความที่ร้ายแรงที่สุดของแต่ละบรรทัดหลังหยุดพิมพ์หนึ่งวินาที พร้อมสัญลักษณ์บอกระดับความรุนแรง
- **การแสดงตัวอย่างสดของหน้าเว็บแบบสแตติก:** ตัวแก้ไข › เปิดในแถบเบราว์เซอร์ ให้บริการหน้าเว็บของโฟลเดอร์ที่เชื่อถือจาก Dango เอง และโหลดแถบใหม่เมื่อบันทึกไฟล์
- **Prettier** จัดรูปแบบ JavaScript, TypeScript, CSS, HTML, Markdown และอื่นๆ ในที่ที่โปรเจ็กต์ตั้งค่าไว้ โดยใช้ `node_modules/.bin/prettier` ของโปรเจ็กต์เอง การตั้งค่า `formatter` เลือกตัวจัดรูปแบบสำหรับแต่ละภาษา
- **โหมด Vim** (ตัวแก้ไข › โหมด Vim): โหมด Normal, Insert, Visual และ Replace การระบุจำนวนครั้ง ตัวดำเนินการพร้อมการเคลื่อนที่และออบเจ็กต์ข้อความ `.` รีจิสเตอร์ มาร์ก และมาโคร `u` และ ⌃R ใช้การเลิกทำของตัวแก้ไข และการแทรกหนึ่งรอบนับเป็นหนึ่งขั้น `"+` และ `"*` คือคลิปบอร์ด การตั้งค่า `vimClipboard` ทำให้รีจิสเตอร์ที่ไม่มีชื่อเป็นคลิปบอร์ดด้วย `/`, `?`, `n`, `N`, `*`, `:s` และ `:%s` ค้นหาด้วยนิพจน์ปกติของ Rust ไม่ใช่รูปแบบของ Vim: ไม่มี `\v` และใช้ `\b` แทน `\<` และ `\>` คำสั่ง Ex ได้แก่ `:w`, `:q`, `:wq`, `:x`, `:noh` และ `:<line>` ในโหมด Normal ปุ่ม ⌃G จะเป็นของ Vim แทนคำสั่งไปที่บรรทัด
- **การเชื่อมข้อมูลการตั้งค่า** ผ่านโฟลเดอร์ใน iCloud Drive (**การตั้งค่า › ทั่วไป**): การตั้งค่าและปุ่มลัดของคุณจะตามคุณไปยัง Mac เครื่องอื่นของคุณ ส่วนพาธ ที่อยู่ในเครื่อง และความยินยอมจะอยู่บนแต่ละเครื่องแยกกัน

## เซิร์ฟเวอร์ภาษา

Go, Rust, TypeScript และ JavaScript, Python, C, C++ และ Objective-C, Swift, เชลล์สคริปต์, JSON, YAML, CSS, HTML, TOML, Markdown และ Lua รวมถึงเซิร์ฟเวอร์ของคุณเองจาก **การตั้งค่า › เซิร์ฟเวอร์ภาษา** Dango จะติดตั้งเซิร์ฟเวอร์เมื่อคุณขอ ลงในโฟลเดอร์เครื่องมือของตัวเอง และใช้ `tsc` ของโปรเจ็กต์ TypeScript เองเมื่อสามารถทำหน้าที่เป็นเซิร์ฟเวอร์ภาษาได้

สิ่งที่เซิร์ฟเวอร์ภาษามีให้: การวินิจฉัย (⌘' และ ⇧⌘' ย้ายไปมาระหว่างรายการ) ข้อมูลเมื่อวางเมาส์ (⌃⌘I) การเติมโค้ด (⌥Esc) ความช่วยเหลือเรื่อง Signature ไปที่คำจำกัดความ (⌃⌘J) คำจำกัดความของชนิดและการนำไปใช้ การอ้างอิง (⌃⇧⌘F) ลำดับชั้นการเรียกและลำดับชั้นของชนิด (⌃⇧⌘H) การเปลี่ยนชื่อ (⌃⌘E) การจัดรูปแบบ (⌥⇧F) สีตามความหมาย การพับโค้ด และโครงร่าง (⇧⌘O) ชนิดและชื่อพารามิเตอร์ภายในบรรทัด แก้ไขด่วนและการปรับโครงสร้างโค้ดหลังไอคอนหลอดไฟ (⌥⌘A) และสัญลักษณ์ของโปรเจ็กต์ด้วย ⌥⌘O

นอกจากเซิร์ฟเวอร์ของไฟล์เองแล้ว ESLint ยังตรวจ JavaScript และ TypeScript ของโปรเจ็กต์ที่ใช้ ESLint พร้อมการแก้ไขด่วนของตัวเอง และตัวย่อของ Emmet จะปรากฏในการเติมโค้ดสำหรับ HTML, CSS และ JSX Dango จะติดตั้งทั้งสองอย่างเมื่อคุณขอ และ **การตั้งค่า › ทั่วไป** แก้ไขปัญหาของ ESLint เมื่อบันทึกได้ถ้าคุณต้องการ

## การทดสอบ

แผงการทดสอบแสดงรายการการทดสอบของโฟลเดอร์ตามแพ็กเกจและไฟล์พร้อมสถานะ ได้แก่ `cargo test` หรือ cargo-nextest, Go, pytest, Vitest และ Jest สัญลักษณ์ข้างการทดสอบแต่ละรายการที่ขอบข้างเลขบรรทัดจะเรียกใช้การทดสอบนั้น ⌥-คลิกจะดีบักการทดสอบนั้น และ assert ที่ล้มเหลวจะทำเครื่องหมายที่บรรทัดของตัวเอง เมนูดีบักเรียกใช้การทดสอบที่เคอร์เซอร์ (⌃⌥⌘U) เรียกใช้การทดสอบล่าสุดอีกครั้ง (⌃⌥⌘G) หรือเรียกใช้ทั้งหมด และดีบักการทดสอบที่เคอร์เซอร์ การทดสอบทำงานเฉพาะในโฟลเดอร์ที่เชื่อถือ เพราะเป็นการเรียกใช้โค้ดของโปรเจ็กต์ `cargo test` จะแสดงรายการการทดสอบเมื่อคุณสั่งเท่านั้น เพราะการแสดงรายการต้องบิลด์โปรแกรมทดสอบทุกตัว

## ดีบักเกอร์

เบรกพอยต์ รวมถึงแบบมีเงื่อนไขและแบบล็อกพอยต์ การทำงานทีละขั้น เธรดของโปรแกรมพร้อมสแตกการเรียก ตัวแปรและนิพจน์ที่เฝ้าดูในตัวตรวจสอบ (⌥⌘I) ค่าที่แสดงข้างโค้ดขณะโปรแกรมหยุดชั่วคราว และคอนโซลดีบักที่ประเมินผลในเฟรมที่หยุดชั่วคราว

| ภาษา | อะแดปเตอร์ดีบัก |
|---|---|
| Rust, C, C++, Swift | `lldb-dap` จาก Xcode Command Line Tools |
| Go | `dlv` |
| JavaScript, TypeScript | ดีบักเกอร์ JavaScript บน Node.js |
| Python | debugpy |

แอปจะอ่าน `.vscode/launch.json` ของโปรเจ็กต์ เมนูดีบักใช้ปุ่มลัดแบบเดียวกับ Xcode: ⌘\\ ตั้งเบรกพอยต์ ⌘Y เปิดหรือปิดเบรกพอยต์ทั้งหมด ⌃⌘Y ดำเนินการต่อ F6, F7 และ F8 ก้าวข้าม ก้าวเข้า และก้าวออก ⌘. หยุด

## เทอร์มินัล

เทอร์มินัลในแถบ (⌃\`) พร้อมสภาพแวดล้อมของ Login Shell วาดด้วย Metal ⌘K ล้างหน้าจอ การวางหรือลากรูปภาพมาวางจะส่งรูปนั้นให้เอเจนต์เขียนโค้ดที่ทำงานอยู่ในเทอร์มินัล หรือวางพาธของสำเนาที่บันทึกไว้ ⌘-คลิกเพื่อเปิดลิงก์และชื่อไฟล์ เซิร์ฟเวอร์สำหรับพัฒนาที่เทอร์มินัลเริ่มไว้สามารถเปิดในแถบเบราว์เซอร์ได้

## เบราว์เซอร์

แถบเบราว์เซอร์พร้อมช่องที่อยู่ (⌘L) ย้อนกลับและไปข้างหน้า (⌘[ และ ⌘]) โหลดซ้ำ (⌘R) การค้นหา การดาวน์โหลดที่ถามก่อน และตัวตรวจสอบเว็บ `@browser` ส่งหน้าเว็บให้เอเจนต์ โดยทำเครื่องหมายว่าเป็นข้อความจากภายนอก

## Git

แผง Git ใช้ Stage และละทิ้งการเปลี่ยนแปลงของทั้งไฟล์หรือส่วนที่เปลี่ยนแปลงทีละส่วน ทำ Commit ทำ Commit แล้ว Push หรือซิงค์ สลับและสร้าง Branch เก็บ Stash แก้ไขความขัดแย้งในการผสาน และวาดกราฟของ Commit ล่าสุด Blame แสดงว่าใครแก้ไขบรรทัดที่เคอร์เซอร์อยู่เป็นคนสุดท้าย หรือแสดงเป็นคอลัมน์สำหรับทั้งไฟล์ ปุ่มหนึ่งเขียนข้อความ Commit ด้วย AI โดย Diff จะถูกส่งออกไปก็ต่อเมื่อ gitleaks ไม่พบข้อมูลลับในนั้น และทุก Commit ก็จะถูกตรวจหาข้อมูลลับด้วย

## CI

GitHub Actions และ GitLab CI รวมถึง GitHub Enterprise Server และ GitLab ที่โฮสต์เอง:

- การรัน Job และล็อกของ Branch ปัจจุบัน
- การรัน Job ที่ล้มเหลวใหม่ Job เดียว หรือการรันทั้งหมดบน GitHub การเริ่ม Job แบบแมนนวลหรืออนุมัติการปรับใช้ที่รออยู่ การเริ่ม Pipeline ใหม่หรือ Workflow ที่เริ่มเองได้ และการยกเลิก
- Pull Request หรือ Merge Request และ Issue ที่เปิดอยู่ ซึ่งเปิดในแถบเบราว์เซอร์
- ล็อกของ Job ที่ล้มเหลวที่ส่งให้เอเจนต์ โดยทำเครื่องหมายว่าเป็นข้อความจากภายนอก

โทเค็นมาจากพวงกุญแจ `gh` หรือ `glab` สภาพแวดล้อมของ Login Shell หรือโทเค็นที่คุณป้อนใน **การตั้งค่า › CI**

## คอนเทนเนอร์

แผงคอนเทนเนอร์แสดงโปรเจ็กต์ Compose ของ Docker พร้อมเซอร์วิส คอนเทนเนอร์เดี่ยว อิมเมจ และวอลุ่ม และติดตามเหตุการณ์ของ Docker ทันทีที่เกิดขึ้น ไฟล์ Compose ในโฟลเดอร์จะแสดงเป็นโปรเจ็กต์แม้ยังไม่มีคอนเทนเนอร์ของโปรเจ็กต์นั้นเลย คอนเทนเนอร์เริ่ม หยุด และเริ่มใหม่ได้ ล็อกและเชลล์ของคอนเทนเนอร์จะเปิดในแถบเทอร์มินัล และพอร์ตที่เผยแพร่จะเปิดในแถบเบราว์เซอร์ การลบคอนเทนเนอร์ อิมเมจ หรือวอลุ่ม และการล้างข้อมูลที่ไม่ได้ใช้ จะถามก่อนเสมอ คำสั่ง up, down และ pull ของ Compose ทำงานเฉพาะในโฟลเดอร์ที่เชื่อถือ เพราะ Compose จะบิลด์และเรียกใช้สิ่งที่โปรเจ็กต์อธิบายไว้ เมนูของแผงจะเลือกบริบท Docker ของหน้าต่างโดยไม่เปลี่ยนบริบทที่เชลล์ของคุณใช้ และคำสั่งเดียวกันนี้อยู่ในเมนูคอนเทนเนอร์ด้วย แผงนี้ต้องใช้บรรทัดคำสั่ง `docker` และ Docker 24.0.6 ขึ้นไป

## Markdown

- **การแสดงตัวอย่าง** ไฟล์ Markdown จะเปิดพร้อมการแสดงตัวอย่างอยู่ด้านข้าง **มุมมอง › แสดง/ซ่อนการแสดงตัวอย่างด้านข้าง** (⇧⌘V) ปิดและเปิดการแสดงตัวอย่าง และ **การตั้งค่า › ทั่วไป** ปิดการแสดงตัวอย่างอัตโนมัติได้ การแสดงตัวอย่างวาดสูตร ไดอะแกรม Mermaid, Graphviz และ PlantUML และรูปภาพในโฟลเดอร์ รูปภาพจากเว็บจะโหลดเฉพาะในโฟลเดอร์ที่เชื่อถือ หรือหลังจากคุณขอในการแสดงตัวอย่าง
- **เมนูรูปแบบ:** ตัวหนา (⌘B) ตัวเอียง (⌘I) ขีดทับ (⇧⌘X) โค้ด (⌥⇧⌘C) ลิงก์ (⇧⌘K) หัวเรื่อง 1–3 (⌥⌘1–⌥⌘3) รายการแบบจุดและแบบตัวเลข งาน คำพูดอ้างอิง และบล็อกโค้ด ทุกคำสั่งสลับเปิดปิดได้ กับส่วนที่เลือกหรือกับบรรทัด และนับเป็นการเลิกทำหนึ่งขั้น
- **การวาง** ข้อความจาก Word หรือหน้าเว็บจะกลายเป็น Markdown และรูปภาพจะกลายเป็นไฟล์ข้างเอกสาร ⌥⇧⌘V วางเป็นข้อความธรรมดา
- **ส่งออก** **ไฟล์ › ส่งออก** เขียนเป็น PDF ไฟล์ HTML ไฟล์เดียวที่มีรูปภาพอยู่ภายใน หรือเอกสาร Word รูปภาพจากเว็บจะรวมไปด้วยเฉพาะจากโฟลเดอร์ที่เชื่อถือ
- **เปิดใน Splat** เมื่อติดตั้ง [Splat](https://github.com/sventmueller/splat) ไว้ **ไฟล์ › เปิดใน Splat** และเมนูบริบทของรายการไฟล์และของแถบจะเปิดเอกสารในแอปนั้น หลังจากบันทึกเอกสารแล้ว

## การป้อนตามคำบอก

ป้อนตามคำบอกลงในช่องข้อความของแถบ AI หรือในตัวแก้ไข: ด้วยปุ่มไมโครโฟนที่นั่น **แก้ไข › เริ่มการป้อนตามคำบอก** (⌃⌥D) หรือปุ่ม fn (กดค้างไว้เพื่อบันทึก แตะสองครั้งเพื่อบันทึกต่อไป) การรู้จำเสียงพูดเป็นของ [Lowspeak](https://github.com/sventmueller/lowspeak) โดยไม่จำเป็นต้องติดตั้ง Lowspeak

- **การตั้งค่า › การป้อนตามคำบอก** กำหนดโหมดและโมเดล (ออนไลน์กับ OpenAI หรือ Groq ในเครื่องด้วย Whisper หรือ Parakeet) ภาษา การประมวลผลภายหลัง ไมโครโฟน และคำศัพท์ของคุณเอง
- **โมเดลในเครื่อง** ดาวน์โหลดจาก Hugging Face เมื่อคุณเลือก พร้อมแสดงความคืบหน้าและยกเลิกได้ โมเดลจะถูกเก็บในโฟลเดอร์ที่ Lowspeak ใช้ ทั้งสองแอปจึงใช้สิ่งที่อีกแอปดาวน์โหลดไว้ได้ โมเดลในเครื่องจะเก็บเสียงที่บันทึกไว้บน Mac เครื่องนี้
- **การถอดเสียงออนไลน์** ต้องใช้คีย์ของ OpenAI หรือ Groq ซึ่ง Dango เก็บไว้ในรายการพวงกุญแจของตัวเอง
- **จาก Lowspeak** หาก Lowspeak ตั้งค่าไว้ต่างจากค่าเริ่มต้น แถบการป้อนตามคำบอกจะเสนอหนึ่งครั้งให้นำการตั้งค่านั้นมาใช้ และนำคีย์มาใช้เมื่อคุณขอ macOS จะถามก่อนที่ Dango จะอ่านคีย์ (ให้เลือก “อนุญาต” ไม่ใช่ “อนุญาตเสมอ”)
- **สิทธิ์** macOS จะขอสิทธิ์ใช้ไมโครโฟนในการป้อนตามคำบอกครั้งแรก ปุ่ม fn ทำงานขณะที่ Dango เป็นแอปที่ใช้งานอยู่และ Lowspeak ไม่ได้ทำงาน ปุ่มนี้ต้องใช้สิทธิ์การช่วยการเข้าถึง ซึ่ง Dango จะขอหลังจากการป้อนตามคำบอกครั้งแรก ไม่ใช่ตอนเปิดแอป

## ความเชื่อถือ

โฟลเดอร์สามารถทำให้โปรแกรมทำงานทันทีที่มีบางสิ่งเริ่มในโฟลเดอร์นั้น เช่น Git Hook และการตั้งค่า Repository อย่าง `core.fsmonitor` เซิร์ฟเวอร์ภาษาจาก `node_modules` Hook ของเอเจนต์ และ `.mcp.json` ครั้งแรกที่คุณเปิดโฟลเดอร์ Dango จะถามว่าคุณเชื่อถือโฟลเดอร์นั้นหรือไม่

- **เชื่อถือ:** Git เซิร์ฟเวอร์ภาษา ดีบักเกอร์ เอเจนต์ และ CI ทำงานสำหรับโฟลเดอร์นี้และทุกอย่างที่อยู่ภายใน
- **จำกัด:** คุณอ่านและแก้ไขได้ เครื่องหมายการเปลี่ยนแปลงในตัวแก้ไขมาจากการอ่าน `.git` โดยตรง สิ่งที่โฟลเดอร์กำหนดค่าไว้จะไม่ถูกเริ่ม แผง Git, CI และ AI จะแจ้งเรื่องนี้และเสนอให้เชื่อถือโฟลเดอร์

ข้อความที่ไม่ได้มาจากคุณอาจมีคำสั่งที่มุ่งชักนำเอเจนต์ (Prompt Injection) ดังนั้นเอาต์พุตของเทอร์มินัล (`@terminal`) หน้าเบราว์เซอร์ (`@browser`) ล็อก CI ที่ส่งให้เอเจนต์ ไฟล์นอกโปรเจ็กต์ และข้อความยาวที่วางจากหน้าเว็บ จะถูกส่งไปพร้อมเครื่องหมาย: ชิปแสดงว่า “เนื้อหาจากภายนอก” และเอเจนต์จะได้รับข้อความพร้อมคำแจ้งว่าเป็นข้อมูลที่ไม่น่าเชื่อถือ ซึ่งต้องไม่ทำตามคำสั่งในนั้น หน้าเว็บของเอเจนต์ในตัวก็มาพร้อมคำแจ้งเดียวกัน ข้อความที่วางจะนับว่ามาจากหน้าเว็บเมื่อเบราว์เซอร์ระบุไว้ในคลิปบอร์ด อย่างที่ Safari, Chrome และ Firefox ทำ ข้อความจากที่อื่นและวลีสั้นๆ ไม่กี่คำยังคงนับเป็นของคุณเอง

## แซนด์บ็อกซ์

Dango เองทำงานโดยไม่มี App Sandbox เพราะทุกโปรแกรมที่แอปเริ่มจะสืบทอดไปด้วย ทำให้เทอร์มินัล Git เซิร์ฟเวอร์ภาษา และเอเจนต์ทำงานไม่ได้ แต่เธรด AI แต่ละเธรดจะมีสวิตช์แซนด์บ็อกซ์แทน ซึ่งปิดอยู่ตามค่าเริ่มต้น สิ่งที่สวิตช์จำกัดขึ้นอยู่กับเอเจนต์ และคำอธิบายเครื่องมือของสวิตช์จะบอกไว้:

| เอเจนต์ | เมื่อเปิดแซนด์บ็อกซ์ |
|---|---|
| Claude | คำสั่งเชลล์ทำงานในแซนด์บ็อกซ์ของ Claude เอง แต่เครื่องมือไฟล์และเว็บของ Claude ไม่อยู่ในแซนด์บ็อกซ์ |
| Codex | คำสั่งและการเปลี่ยนแปลงเขียนได้เฉพาะในโปรเจ็กต์ โดยไม่มีเครือข่าย |
| เอเจนต์ในตัว | ไฟล์ คำขอเว็บ และคำสั่งอยู่ภายในโปรเจ็กต์และโฟลเดอร์ที่อนุญาต โดยไม่มีเครือข่าย (`sandbox-exec`) |
| Antigravity, OpenCode | ไม่มีแซนด์บ็อกซ์ที่ Dango เปิดใช้ได้ |

## รูปลักษณ์และการช่วยการเข้าถึง

- **โหมดมืด** เป็นไปตามระบบ และรองรับ **เพิ่มความต่างของสี** และ **ลดการเคลื่อนไหว**
- **VoiceOver** อ่านชื่อแถบด้านข้าง แถบ การ์ดในไทม์ไลน์ AI แถว Git และ CI ดีบักเกอร์ และข้อความของเทอร์มินัล เบรกพอยต์ไม่เคยแยกแยะด้วยสีเพียงอย่างเดียว
- **แป้นพิมพ์** ทุกคำสั่งมีปุ่มลัด และเปลี่ยนได้ทั้งหมดใน `keybindings.json` ⌥⌘\` ย้ายไปยังแผงถัดไป
- **ขวาไปซ้าย** ในภาษาอาหรับและฮีบรู หน้าต่างจะกลับด้าน แต่มุมมองโค้ดยังคงเรียงจากซ้ายไปขวา

สิ่งที่ Dango เพิ่มเติมจาก AppKit แยกตามส่วนต่างๆ อยู่ใน [ACCESSIBILITY.md](../../../ACCESSIBILITY.md)

## ภาษา

อินเทอร์เฟซแปลเป็น 35 ภาษา ได้แก่ อาหรับ คาตาลัน จีน (ตัวย่อ) จีน (ตัวเต็ม) โครเอเชีย เช็ก เดนมาร์ก ดัตช์ อังกฤษ ฟินแลนด์ ฝรั่งเศส เยอรมัน กรีก ฮีบรู ฮินดี ฮังการี อินโดนีเซีย อิตาลี ญี่ปุ่น เกาหลี มาเลย์ นอร์เวย์ โปแลนด์ โปรตุเกส (บราซิล) โปรตุเกส (โปรตุเกส) โรมาเนีย รัสเซีย สโลวัก สโลวีเนีย สเปน สวีเดน ไทย ตุรกี ยูเครน และเวียดนาม

Dango ทำตามลำดับภาษาใน **การตั้งค่าระบบ › ทั่วไป › ภาษาและภูมิภาค** และคุณยังเลือกภาษาสำหรับ Dango โดยเฉพาะได้ที่นั่นใต้ **แอปพลิเคชัน** หากไม่มีคำแปลสำหรับภาษาของคุณ แอปจะใช้ภาษาอังกฤษ คำศัพท์เป็นไปตามอภิธานศัพท์ [docs/glossary.md](../../../docs/glossary.md) และคำแปลของ Apple เอง Dango จึงอ่านเหมือนส่วนอื่นๆ ของ Mac ของคุณ

## ความเป็นส่วนตัวและความปลอดภัย

- **ไม่มีการวัดและส่งข้อมูลทางไกล** ไม่มีการวิเคราะห์ และไม่มีการส่งรายงานข้อขัดข้องไปที่ใด ข้อผิดพลาดจะไปที่บันทึกของระบบ (คอนโซล ภายใต้ชื่อของแอป)
- **ใช้เครือข่ายเฉพาะสำหรับสิ่งที่คุณเริ่มเอง:** เอเจนต์ที่คุณใช้ ซึ่งแต่ละตัวสื่อสารกับบริการของตัวเอง รีจิสทรี ACP และการดาวน์โหลดเอเจนต์ เซิร์ฟเวอร์ภาษา อะแดปเตอร์ดีบัก และโมเดลการป้อนตามคำบอกเมื่อคุณขอ โฮสต์ CI ที่คุณลงชื่อเข้า การคาดการณ์จาก Copilot หากคุณเลือก ผู้ให้บริการของเอเจนต์ในตัว การถอดเสียงออนไลน์หากคุณเลือก หน้าเว็บที่คุณเปิดในแถบเบราว์เซอร์ และการตรวจหาอัปเดตเมื่อคุณอนุญาตแล้ว
- **โค้ดจะออกจาก Mac** เฉพาะเมื่อคุณเลือกบริการสำหรับสิ่งนั้น ได้แก่ เอเจนต์ การคาดการณ์ของ Copilot และข้อความ Commit ที่เขียนด้วย AI โดย Diff สำหรับข้อความ Commit จะถูกส่งออกไปก็ต่อเมื่อ gitleaks ไม่พบข้อมูลลับในนั้น
- **คีย์และโทเค็น** อยู่ในพวงกุญแจของ macOS ไม่เคยอยู่ในไฟล์การตั้งค่า คีย์ของแอปอื่น เช่น ของ Lowspeak จะถูกอ่านเฉพาะเมื่อคุณยินยอม และเพียงครั้งเดียว
- **การดาวน์โหลดที่กำหนดเวอร์ชันไว้** เอเจนต์ เซิร์ฟเวอร์ภาษา และอะแดปเตอร์ดีบักที่ Dango ติดตั้งจะถูกกำหนดไว้ที่เวอร์ชันที่ทดสอบแล้วและตรวจสอบกับเช็คซัม
- **การลงนามโค้ด** พร้อม Hardened Runtime การอัปเดตจะติดตั้งได้เฉพาะเมื่อมีลายเซ็นของแอปเอง

## ตำแหน่งที่เก็บข้อมูล

`<id>` คือตัวระบุบันเดิล ซึ่งเป็น `local.agentide` สำหรับรุ่นเผยแพร่ (`local.agentide.debug` สำหรับบิลด์ดีบัก) ตัวระบุนี้ไม่มีชื่อที่แสดง การเปลี่ยนชื่อจึงยังคงข้อมูลไว้ทั้งหมด

| ตำแหน่ง | สิ่งที่เก็บ |
|---|---|
| `~/Library/Application Support/<id>/` | `settings.json`, `state.json`, `keybindings.json`, `trust.json` และ `threads/` (รายการของแผง AI), `agent-threads/` (บทสนทนาของเอเจนต์ในตัว), `layouts/` (แถบแยกตามโปรเจ็กต์), `recovery/` (ตัวแก้ไขที่ยังไม่ได้บันทึกหลังแอปขัดข้อง), `checkpoints/` (สำหรับโฟลเดอร์ที่ไม่มี Git), `worktrees/`, `agents/` และ `tools/` (เอเจนต์ เซิร์ฟเวอร์ภาษา และอะแดปเตอร์ดีบักที่ติดตั้งไว้), `task-output/` |
| `~/Library/Caches/<id>/` | รูปภาพที่วาง สคริปต์การผสานรวมกับเชลล์ และรีจิสทรี ACP ลบได้ |
| `~/Library/Logs/<id>/dictation/` | ไฟล์ล็อกของการป้อนตามคำบอก |
| `~/Library/Application Support/Lowspeak` และ `FluidAudio` | โมเดลการป้อนตามคำบอกในเครื่อง ใช้ร่วมกับ Lowspeak |
| `~/Library/WebKit/<id>/` | คุกกี้และข้อมูลเว็บไซต์ของแถบเบราว์เซอร์ |
| `<project>/.dango/settings.json` | การตั้งค่าของโปรเจ็กต์เอง |
| Git Repository ของโปรเจ็กต์ | จุดตรวจสอบ ในรูป Commit ภายใต้ `refs/ide-checkpoints/` การ Push หรือ Fetch ตามปกติจะไม่นำจุดตรวจสอบเหล่านี้ไปด้วย |
| พวงกุญแจ บริการ `<id>` | คีย์ API ของเอเจนต์ในตัวและของการป้อนตามคำบอก และโทเค็น CI |
| `~/.local/bin/dango` | คำสั่งเทอร์มินัล หากคุณติดตั้งไว้ |

Claude เก็บเซสชันของตัวเองไว้ใต้ `~/.claude/projects` Dango อ่านเซสชันเหล่านั้นเพื่อทำงานต่อจากเซสชันเดิม แต่ไม่เปลี่ยนแปลงเซสชันเหล่านั้น

## ข้อจำกัดที่ทราบ

- **ไม่มี App Sandbox** สำหรับตัวแอปเอง เพราะเทอร์มินัล Git เซิร์ฟเวอร์ภาษา และเอเจนต์จะสืบทอดไปด้วย คุณต้องเชื่อถือโฟลเดอร์ก่อนที่สิ่งที่โฟลเดอร์นั้นกำหนดค่าไว้จะทำงาน Antigravity และ OpenCode ไม่มีแซนด์บ็อกซ์ที่ Dango เปิดใช้ได้
- **ตัวเลขการใช้งานและรายละเอียดบริบทของ Claude** อาศัยส่วนของโปรโตคอลที่ระบุว่าเป็นรุ่นทดลอง และจะถูกซ่อนเมื่อไม่มีข้อมูลนั้น
- **การกรอกลับบทสนทนา** ใช้ได้กับ Claude เท่านั้น สำหรับเอเจนต์อื่นจะกรอกลับเฉพาะโค้ด
- **การลงชื่อเข้า CI ผ่านเบราว์เซอร์** ปิดอยู่ ให้ใช้ `gh`, `glab`, โทเค็น หรือสภาพแวดล้อมแทน
- **ไม่มี Gemini CLI ให้เลือก:** Google ยุติการลงชื่อเข้าด้วยบัญชีส่วนตัวและแนะนำให้ใช้ Antigravity แทน เธรด Gemini ก่อนหน้ายังคงอ่านได้

## การบิลด์จากซอร์สโค้ด

สิ่งที่คุณต้องมี:

- macOS 14 ขึ้นไปพร้อม Xcode Command Line Tools (`xcode-select --install`) ไม่จำเป็นต้องมี Xcode
- Rust ตามที่ `rust-toolchain.toml` ระบุ `rust` ของ Homebrew จะบิลด์สำหรับโปรเซสเซอร์ของ Mac เครื่องนี้ ส่วนการบิลด์แบบ Universal ของรุ่นเผยแพร่ต้องใช้ rustup พร้อมเป้าหมาย `aarch64-apple-darwin` และ `x86_64-apple-darwin`
- สำเนาของ [splat](https://github.com/sventmueller/splat) และ [lowspeak](https://github.com/sventmueller/lowspeak) ที่อยู่ข้างสำเนานี้ (`../splat`, `../lowspeak`) ทั้งสองอยู่บน Branch `main` ของตัวเอง Workspace จะนำ Crate จากทั้งสองมาใช้ตามพาธ
- cmake สำหรับทุกบิลด์ที่มีการป้อนตามคำบอก (`make run`, `make build`, `make release`) ซึ่งจะบิลด์ whisper.cpp ส่วน `make check` บิลด์โดยไม่ต้องใช้

| คำสั่ง | สิ่งที่ทำ |
|---|---|
| `make run` | บิลด์แอปดีบัก (`target/debug/Dango Debug.app`) แล้วเปิด |
| `make build` | บิลด์แอปรุ่นเผยแพร่ (`target/release/Dango.app`) ลงนามด้วยใบรับรองในเครื่องที่บิลด์แรกสร้างไว้ในพวงกุญแจเข้าสู่ระบบ และคง `VERSION` ไว้โดยไม่เปลี่ยนแปลง |
| `make lint` | การจัดรูปแบบและ clippy คำเตือนถือว่าล้มเหลว |
| `make check` | `lint` แล้วทดสอบทั้งหมด ไม่ต้องใช้พวงกุญแจ หน้าต่าง หรือเครือข่าย |
| `make test` | `check` แล้วทดสอบตัวเอง `probe` และตรวจสอบการช่วยการเข้าถึง ทั้งแบบซ้ายไปขวาและขวาไปซ้าย ในแอปจริง |
| `make perf` | งบเวลาในบิลด์รุ่นเผยแพร่ มีความหมายเฉพาะบน Mac ที่ไม่ได้ทำงานอื่นอยู่ |
| `make release` | ซ้อมการเผยแพร่ลงใน `target/release-dry-run/` ลงนามด้วยใบรับรองในเครื่อง และไม่ส่งสิ่งใดออกไป |
| `make release-notarized` | `check` แล้วเผยแพร่จริงลงใน `dist/`: ลายเซ็น Developer ID การรับรองโดย Apple และฟีดอัปเดตที่ลงนามด้วยคีย์ของแอปเอง และคง `VERSION` ไว้โดยไม่เปลี่ยนแปลง |
| `make deploy` | บน `main` ที่ไม่มีการเปลี่ยนแปลงค้างอยู่และมีตรา CI สีเขียว: รับรองรุ่นถัดไป อัปเดตและคอมมิต `VERSION` อัปโหลดไฟล์เผยแพร่ แล้วพุชโค้ด ตรา CI และแท็กเวอร์ชัน โดย GitHub จะเผยแพร่รุ่นโดยอัตโนมัติ |

แอปดีบักและแอปรุ่นเผยแพร่เป็นแอปแยกกันที่มีการตั้งค่าและข้อมูลของตัวเอง การบิลด์ การทดสอบ การทดสอบตัวเอง การเผยแพร่ และกฎที่โค้ดปฏิบัติตามอธิบายไว้ใน [docs/development.md](../../../docs/development.md) และการตัดสินใจเบื้องหลังอยู่ใน [docs/plan.md](../../../docs/plan.md) บันทึกประจำรุ่นคือ [RELEASE_NOTES.md](../../../RELEASE_NOTES.md) ซึ่งแปลไว้ข้าง README แต่ละภาษาใน `assets/readme/<language>/`
