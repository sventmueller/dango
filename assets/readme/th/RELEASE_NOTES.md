## แถบ AI
- “แสดงเอาต์พุต” ของคำสั่งเบื้องหลังจะเปิดแถบที่ติดตามเอาต์พุตไปตลอดขณะที่คำสั่งยังทำงานอยู่ แทนที่จะเป็นสำเนาของเอาต์พุต ณ ขณะนั้น แถบจะเปิดที่ท้ายเอาต์พุตและอยู่ตรงนั้นขณะที่มีบรรทัดใหม่เข้ามา จนกว่าคุณจะเลื่อนขึ้น เมื่อเลื่อนกลับลงมาที่ท้ายสุด แถบจะติดตามต่ออีกครั้ง “แสดงเอาต์พุต” บนแถบที่เปิดอยู่แล้วจะนำแถบนั้นขึ้นมาด้านหน้าและแสดงท้ายเอาต์พุต
  - คำสั่งที่เขียนเอาต์พุตลงไฟล์เอง เช่น `make > build.log 2>&1` จะแสดงไฟล์นั้นขณะที่ไฟล์มีขนาดใหญ่ขึ้น
  - เมื่อคำสั่งจบลง แถบจะแสดงเอาต์พุตทั้งหมดของคำสั่ง และ “เปิดในตัวแก้ไข” จะเปิดไฟล์ที่แถบอ่านอยู่
  - แถบจะอ่านเอาต์พุตเฉพาะขณะที่อยู่ด้านหน้าเท่านั้น
