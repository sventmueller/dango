## แถบ AI
- Hook ที่ทำงานสำเร็จแล้วหรือยังทำงานอยู่จะไม่แสดงในไทม์ไลน์อีกต่อไป แม้แต่เป็นแถวที่ยุบไว้สำหรับแต่ละคำตอบ ส่วน Hook ที่ล้มเหลวยังคงแสดงอยู่

## เทอร์มินัล
- เมื่อ Mac ที่ทำงานหนักอ่านเอาต์พุตของโปรแกรมล่าช้า เทอร์มินัลก็ยังรู้ว่าโปรแกรมจบการทำงานแล้ว และเก็บบรรทัดสุดท้ายของโปรแกรมไว้

## Markdown
- สูตรที่มีเครื่องหมาย backtick (`` ` ``) ซึ่งวางมาจาก Word หรือหน้าเว็บ จะยังคงเป็นสูตร แทนที่จะกลายเป็นโค้ด
- รูปภาพในข้อความตัวหนาหรือตัวเอียงจะคงรูปแบบนั้นไว้ในการส่งออกเป็น Word
- ไฟล์ที่มีเซลล์ตารางว่างมากกว่า 500,000 เซลล์จะแสดงตารางเป็นข้อความ แทนที่จะใช้เวลาหลายวินาทีและหน่วยความจำหลายกิกะไบต์
