## วิธีใช้
- เมนู “วิธีใช้” จะพาไปยังโปรเจกต์บน GitHub โดย “รายงานปัญหา…” จะเปิดแบบฟอร์มรายงานที่กรอกเวอร์ชันของ Dango เวอร์ชันของ macOS และประเภทของ Mac ไว้ให้แล้ว “เสนอแนะคุณสมบัติ…” จะเริ่มแนวคิดใหม่ในการสนทนา และ “Dango บน GitHub” จะเปิด Repository

## ตัวแก้ไขและเทอร์มินัล
- ตัวแก้ไขและเทอร์มินัลจะเริ่มต้นที่ 13 พอยต์ เช่นเดียวกับแถบด้านข้าง แถวแถบ และแถบ AI ส่วนขนาดที่คุณตั้งเองจะยังคงเดิม
- หมายเลขบรรทัดจะนับบรรทัดว่างหลังการขึ้นบรรทัดใหม่ครั้งสุดท้าย และบรรทัดเดียวของเอกสารว่างด้วย โดยแสดงข้างเคอร์เซอร์

## AI
- ปุ่มเอาต์พุตของกระบวนการเบื้องหลังจะไม่เปิดไฟล์ว่างอีกต่อไปในขณะที่กระบวนการยังไม่มีเอาต์พุต แต่จะแจ้งว่ายังไม่มีเอาต์พุต หรือเมื่อกระบวนการจบแล้วจะแจ้งว่าไม่มีเอาต์พุตเลย การคลิกครั้งที่สองจะแสดงเอาต์พุตปัจจุบันแทนสำเนาก่อนหน้า และตอนนี้ปุ่มยังแสดงเอาต์พุตของเทอร์มินัล Codex ได้ด้วย ซึ่งก่อนหน้านี้ไม่ทำอะไรเลย

## Markdown
- รูปภาพในการแสดงตัวอย่าง Markdown จะแสดงเร็วขึ้นราวสามเท่า เพราะย่อขนาดด้วยคำสั่งเวกเตอร์ และรูปภาพบน iCloud Drive ดิสก์ภายนอก หรือการแชร์บนเครือข่ายจะโหลดพร้อมกันหลายรูปแทนการโหลดทีละรูป
