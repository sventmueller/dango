## เทอร์มินัล
- ตอนนี้เทอร์มินัลเป็นของ Tapa แอปเทอร์มินัลพี่น้องของ Dango พร้อมทุกสิ่งที่ Tapa เพิ่มเข้ามา ส่วน Dango ยังคงสิ่งที่เทอร์มินัลของตัวเองเคยทำได้: การวางรูปภาพให้เอเจนต์ เซิร์ฟเวอร์สำหรับพัฒนาในแถบเบราว์เซอร์ และ ⌘-คลิกเข้าไปในตัวแก้ไข
- **มุมมอง › แสดง/ซ่อนช่องป้อนข้อมูล** (⌘I ขณะที่เทอร์มินัลมีโฟกัส) เปลี่ยนบรรทัดคำสั่งให้เป็นช่องข้อความ โดยมีโฟลเดอร์และ Branch ของ Git อยู่ด้านบน คำสั่งจะแสดงเป็นสีตามส่วนต่างๆ และคำสั่งที่เชลล์ของคุณรันไม่ได้จะมีเส้นใต้สีแดงแบบเส้นประ
- ข้อเสนอแสดงเป็นสีเทาขณะที่คุณพิมพ์ ทั้งในช่องป้อนข้อมูลและเมื่อไม่มีช่อง โดยมาจากประวัติของคุณ จากข้อกำหนดของเครื่องมือบรรทัดคำสั่งกว่า 700 ตัว และจากโปรเจ็กต์ เช่น Branch ของ git สคริปต์ใน `package.json` และเป้าหมายของ make, just และ cargo → รับข้อเสนอ Tab เติมคำ และเมื่อมีตัวเลือกหลายตัวจะเปิดเมนูที่กรองตามสิ่งที่พิมพ์ ข้อเสนอไม่ใช้เครือข่ายเลย
- บล็อกคำสั่ง: ⌘↑ และ ⌘↓ กระโดดไปมาระหว่างพรอมต์ เมนู **แก้ไข** เลือก คัดลอก และบันทึกเอาต์พุตของคำสั่ง และบุ๊กมาร์กทำเครื่องหมายบรรทัด เมื่อเปิด **ทำเครื่องหมายคำสั่งเป็นบล็อก** แถบจะแสดงแต่ละบล็อก คำสั่งที่ล้มเหลวจะถูกทำเครื่องหมาย และปุ่มเหนือบล็อกจะแสดงสถานะและระยะเวลาของบล็อกนั้น
- **ส่งบล็อกไปยังเอเจนต์** (เมนูแก้ไขและเมนูบริบทของเทอร์มินัล) เปิดแถบ AI ที่แนบบรรทัดคำสั่งและเอาต์พุตของบล็อกปัจจุบันเป็น “เนื้อหาจากภายนอก”
- **ค้นหา** (⌘F ขณะที่เทอร์มินัลมีโฟกัส) ค้นหาทั่วทั้งประวัติด้วยนิพจน์ปกติ ตัวพิมพ์เล็กใหญ่ และทั้งคำ แถบเลื่อนจะทำเครื่องหมายผลการค้นหา
- การแจ้งเตือนของโปรแกรม (OSC 9 และ OSC 777) และเสียงกริ่งของโปรแกรมจะใส่จุดสีแดงบนแถบของเทอร์มินัลขณะที่คุณมองไม่เห็นเทอร์มินัลนั้น และเมื่อแอปอื่นอยู่ด้านหน้า การแจ้งเตือนจะส่งไปยัง macOS ความคืบหน้าที่โปรแกรมรายงาน (OSC 9;4) จะแสดงเป็นวงแหวนบนแถบของโปรแกรมนั้นและเป็นแถบบนไอคอนใน Dock
- การดับเบิลคลิกเลือก URL พาธ หรือค่าแฮชทั้งหมด การลากพร้อม ⌥ เลือกเป็นสี่เหลี่ยม **คัดลอกพร้อมรูปแบบ** คงสีและสไตล์ไว้ และ **เลือกด้วยแป้นพิมพ์** ย้ายการเลือกด้วยปุ่มของ Vim
- การวางหลายบรรทัดที่จะทำงานทันทีจะแสดงให้ดูก่อน และ **Dango › ป้อนข้อมูลผ่านแป้นพิมพ์แบบปลอดภัย** ป้องกันไม่ให้แอปอื่นอ่านสิ่งที่คุณพิมพ์ในเทอร์มินัล
- ลิงก์ประเภทอื่นนอกจากที่อยู่เว็บ `mailto:` และไฟล์ จะไม่เปิดจากเทอร์มินัลอีกต่อไป

## การตั้งค่า
- **การตั้งค่า › เทอร์มินัล** เปิดหรือปิดช่องป้อนข้อมูลสำหรับเทอร์มินัลใหม่ ปุ่ม Vim ของช่องนั้น ข้อเสนอ การแสดงคำสั่งเป็นสี การขีดเส้นใต้คำสั่งที่ไม่รู้จัก บล็อกคำสั่ง การคัดลอกส่วนที่เลือกทันที การแสดงการวางหลายบรรทัดก่อน และการใช้ ⌥ เป็นปุ่มเมตา ซึ่งย้ายมาที่นี่จาก “ทั่วไป”
