## ความปลอดภัย
- ลิงก์ในคำตอบ แผน และรายงานของเอเจนต์ ในการแสดงตัวอย่าง Markdown และใน PDF จะไม่เปิดแอปใด ๆ ด้วยการคลิกเพียงครั้งเดียวอีกต่อไป ที่อยู่เว็บจะเปิดในแถบเบราว์เซอร์ ไฟล์ภายในโปรเจ็กต์จะเปิดในแถบตัวแก้ไข ส่วนอย่างอื่น เช่น ไฟล์ที่อยู่ที่อื่น การแชร์บนเครือข่าย หรือลิงก์ของแอปอื่น จะถามก่อนและแสดงว่าลิงก์นำไปที่ใด
- ที่อยู่สำหรับลงชื่อเข้าและ Remote Control ที่เอเจนต์หรือเซิร์ฟเวอร์ MCP ส่งมาจะเปิดเฉพาะเมื่อเป็นที่อยู่เว็บเท่านั้น
- โฟลเดอร์ที่มีเนื้อหามากกว่าหนึ่งโปรเจ็กต์อยู่มาก เช่น โฟลเดอร์บ้าน เดสก์ท็อป เอกสาร ดาวน์โหลด หรือรูทของวอลุ่ม จะไม่สามารถเชื่อถือทั้งโฟลเดอร์ได้อีกต่อไป ให้เชื่อถือทีละโปรเจ็กต์ ตอนนี้คำถามเรื่องความเชื่อถือจะบอกด้วยว่าครอบคลุมโฟลเดอร์ภายในด้วย
- โทเค็นและการลงชื่อเข้าของ CI จะไม่ถูกส่งผ่าน http ธรรมดาไปยังเซิร์ฟเวอร์อื่นนอกจาก Mac เครื่องนี้ Repository ที่มี Remote ขึ้นต้นด้วย `http://` จะถูกถามผ่าน https
- หากไม่มี gitleaks การคาดการณ์ขณะแก้ไขจะรอก่อนส่งโค้ดไปยังผู้ให้บริการภายนอก Mac เครื่องนี้ จนกว่าคุณจะเลือกส่งโดยไม่ตรวจ การตั้งค่า gitleaks ของโปรเจ็กต์เองจะไม่ปิดการตรวจอีกต่อไป
- เอเจนต์ในตัวจะไม่ถูกชักนำให้เขียนนอกโปรเจ็กต์ผ่านลิงก์ที่ปรากฏขึ้นหลังจากการเขียนได้รับอนุมัติแล้วอีกต่อไป และไฟล์ที่มีฮาร์ดลิงก์อื่นอยู่จะได้รับไฟล์ของตัวเองแทนที่จะถูกเขียนผ่านลิงก์
- การเติมโค้ดของเซิร์ฟเวอร์ภาษาจะไม่ทำให้ตัวแก้ไขค้างอีกต่อไป และการเปลี่ยนชื่อและการลบไฟล์ที่เป็นลิงก์จะมีผลกับตัวลิงก์เอง ไม่ใช่สิ่งที่ลิงก์ชี้ไป
- รูปภาพที่คุณแนบกับพรอมต์จะถูกถอดรหัสโดยบริการถอดรหัสที่ทำงานในแซนด์บ็อกซ์ เช่นเดียวกับที่อื่นทั้งหมด
- โปรแกรมในเทอร์มินัลจะแทนที่คลิปบอร์ดได้เฉพาะขณะที่เทอร์มินัลของโปรแกรมนั้นอยู่ด้านหน้า และเทอร์มินัลจะแจ้งให้ทราบ
- rust-analyzer จะติดตั้งจากรุ่นที่ตรึงไว้พร้อมเช็คซัม แทนที่จะเป็นรุ่นใดก็ตามที่ใหม่ล่าสุดในขณะนั้น

## การค้นหาและการนำทาง
- “เปิดอย่างรวดเร็ว” จะแจ้งเมื่อไม่มีไฟล์ที่ตรงกัน และแสดงว่ากำลังค้นหาไฟล์หรือสัญลักษณ์ของโปรเจ็กต์
- สัญลักษณ์ของโปรเจ็กต์รวม TypeScript และ JavaScript ไว้ด้วยโดยไม่ต้องเปิดไฟล์ของภาษาเหล่านั้น รายการที่ตรงกันทุกตัวอักษรจากโปรเจ็กต์และในภาษาที่คุณกำลังใช้จะแสดงก่อน ส่วนสัญลักษณ์จากไลบรารีและแพ็กเกจที่ติดตั้งไว้จะมีเครื่องหมายกำกับ
- มุมมอง › ค้นหา จะย้ายโฟกัสไปที่ช่องค้นหา

## ตัวแก้ไข
- ตัวแก้ไขจะยังคงมีโฟกัสเมื่อไฟล์ Markdown เปิดพร้อมการแสดงตัวอย่างอยู่ข้าง ๆ เมนูรูปแบบจึงใช้งานได้ทันที คำสั่งของตัวแก้ไขยังใช้งานได้ขณะที่โฟกัสอยู่ในแถบด้านข้างด้วย
- ข้อเสนอที่ท้ายบรรทัดหรือในกล่องด้านล่างบรรทัดจะบอกว่ากด Tab เพื่อรับข้อเสนอนั้น
- แถบที่มีชื่อเดียวกันในภาพรวมแถบจะแยกแยะได้ เช่น ไฟล์และการแสดงตัวอย่างของไฟล์นั้นในเบราว์เซอร์
- เมนูมุมมองไม่มีคำสั่ง “ซ่อนแถบแท็บ” ของ macOS เองอีกต่อไป เนื่องจากแถบของ Dango ไม่ได้ใช้คำสั่งนี้

## ภาษาและการดีบัก
- ตอนนี้เซิร์ฟเวอร์ JSON ตรวจสอบไฟล์แล้ว และเซิร์ฟเวอร์ที่ลงทะเบียนการวินิจฉัยหลังจากเริ่มทำงาน เช่น basedpyright และ sourcekit-lsp จะแสดงการวินิจฉัยเหล่านั้น
- ในกรณีที่ pip ปฏิเสธการติดตั้งลงใน Python เช่น Python ของ Homebrew ตัวดีบักจะเสนอให้ติดตั้ง debugpy ลงในสภาพแวดล้อมเสมือนของโปรเจ็กต์
