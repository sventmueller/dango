## ต้นไม้ไฟล์
- เลือกหลายแถวในต้นไม้ไฟล์ได้ด้วยการคลิกพร้อม ⇧ และ ⌘ และเมนูบริบทบนแถวใดแถวหนึ่งจะมีผลกับทุกแถว: “คัดลอกพาธ” และ “คัดลอกพาธแบบสัมพัทธ์” จะคัดลอกพาธบรรทัดละหนึ่งพาธ “แสดงใน Finder” จะเลือกแถวเหล่านั้นพร้อมกันใน Finder และ “ย้ายไปที่ถังขยะ” จะย้ายทั้งหมด ในกรณีนี้ “เปลี่ยนชื่อ…” และคำสั่งที่เปิดไฟล์เดียวจะใช้ไม่ได้ ส่วนเมนูบนแถวที่อยู่นอกการเลือกจะมีผลกับแถวนั้นเท่านั้น
