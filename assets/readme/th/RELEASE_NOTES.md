## แถบเครื่องมือ
- ลำดับใหม่จากขวา: “เทอร์มินัลใหม่” “เธรด AI ใหม่” และ “แถบเบราว์เซอร์ใหม่” อยู่ในกลุ่มเดียวกัน ทางซ้ายเป็น “แยกไปทางขวา” “แยกลงด้านล่าง” และสวิตช์ของช่องป้อนข้อมูล ตามด้วย “เปิดอย่างรวดเร็ว” และ “กิจกรรม”
- สวิตช์ของช่องป้อนข้อมูลเปิดหรือปิดช่องของเทอร์มินัลที่อยู่ด้านหน้า และแสดงเป็นสีเน้นตราบที่ช่องเปิดอยู่ หากไม่มีเทอร์มินัลอยู่ด้านหน้า สวิตช์จะเป็นสีจาง
- หากติดตั้งเอเจนต์ไว้เพียงตัวเดียว “เธรด AI ใหม่” จะเปิดเอเจนต์นั้นด้วยการคลิกครั้งเดียว มิฉะนั้นการคลิกจะแสดงเอเจนต์ในเมนู การกดปุ่มค้างไว้จะแสดงเมนูเสมอ
- ปุ่มการตั้งค่าอยู่ต่ำลงที่ด้านล่างของแถบด้านข้าง

## เทอร์มินัล
- เมื่อไม่มีช่องป้อนข้อมูล คำสั่งที่คุณพิมพ์จะได้สีเดียวกับในช่อง ได้แก่ คำสั่ง คำสั่งย่อย ตัวเลือก ตัวแปร และตัวดำเนินการ พร้อมเส้นใต้สีแดงแบบประใต้คำสั่งที่เชลล์เรียกใช้ไม่ได้ สีที่เชลล์ตั้งเองยังคงอยู่
- เมื่อไม่มีช่องป้อนข้อมูล รายการคำแนะนำจะเปิดขึ้นเองขณะที่คุณพิมพ์คำ Return จะเรียกใช้บรรทัด และ Tab หรือ → จะรับคำแนะนำสีเทา หลังจากกด ↑ หรือ ↓ ปุ่มเหล่านี้จะรับรายการที่เลือก Esc จะปิดรายการสำหรับคำนั้น และ "การตั้งค่า › เทอร์มินัล" จะปิดฟีเจอร์นี้
