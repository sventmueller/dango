## ความเร็ว
- สิ่งที่เอเจนต์เริ่ม เช่น การบิลด์ การทดสอบ และเชลล์ จะทำงานด้วยลำดับความสำคัญต่ำสุดแทนที่จะอยู่ในสถานะเบื้องหลังของ macOS โดย Dango ยังคงมาก่อนและเอเจนต์ยังคงมาก่อนสิ่งที่เอเจนต์เริ่ม แต่การบิลด์ของเอเจนต์จะกลับมาใช้คอร์ประสิทธิภาพสูงและความเร็วเต็มที่ของดิสก์ได้อีกครั้ง ก่อนหน้านี้สถานะเบื้องหลังลดปริมาณงานที่ทำได้ลงเหลือประมาณหนึ่งในสิบ แม้บน Mac ที่ไม่ได้ทำงานอื่นอยู่เลยก็ตาม

## เอเจนต์
- จุดของแถบ AI จะยังคงเป็นสีเขียวขณะที่คำสั่งเบื้องหลังของเซสชันนั้นยังทำงานอยู่ และการแจ้งว่าเซสชันเสร็จแล้วจะปรากฏก็ต่อเมื่องานเบื้องหลังของเซสชันนั้นจบลงด้วยเท่านั้น
