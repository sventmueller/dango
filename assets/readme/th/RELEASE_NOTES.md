## หน่วยความจำ
- เซสชันเอเจนต์ที่ยาวใช้หน่วยความจำน้อยลงมาก:
  - การเปิดเซสชันก่อนหน้าจะอ่านบันทึกการสนทนาทีละบรรทัด เซสชันที่มีบันทึกการสนทนาขนาด 100 MB ตอนนี้ใช้สูงสุดประมาณ 20 MB แทนที่จะเป็น 65 MB
  - การเรียกเครื่องมือที่เสร็จแล้วจะเก็บไว้เฉพาะสิ่งที่การ์ดของมันแสดง ได้แก่ 400 บรรทัดแรกของเอาต์พุต และจะไม่เก็บอินพุตดิบอีกต่อไปเมื่อการ์ดแสดงฟิลด์ของมันแล้ว “อีก N บรรทัด” ยังคงนับทุกบรรทัด
  - แถบ AI ที่ไม่ได้อยู่ในมุมมองเป็นเวลา 30 วินาทีจะปล่อยการ์ดของมัน และเมื่อแสดงอีกครั้งจะสร้างการ์ดที่อยู่ในมุมมอง ณ ตำแหน่งเดิม
  - หลังจากปิดแถบหรือเปิดเซสชันก่อนหน้า Dango จะคืนหน่วยความจำที่ปล่อยแล้วให้ macOS
- รายการไม่ขยายตัวในหน่วยความจำเมื่อรีเฟรชอีกต่อไป บน macOS 27 การรีเฟรชรายการที่มีแถวแบบเปิดได้แต่ละครั้งจะทิ้งสามเหลี่ยมแสดงรายละเอียดไว้อย่างถาวร และการรีเฟรชแต่ละครั้งจะทิ้งบางส่วนของแต่ละแถวไว้:
  - รายการ CI คอนเทนเนอร์ Software Factory การทดสอบ ดีบัก Git และค้นหา รวมถึงลำดับชั้นการเรียก จะวาดลูกศรของตัวเอง
  - รายการที่ไม่ได้อยู่ในมุมมองจะไม่รีเฟรชอีกต่อไป และจะอัปเดตตามให้ทันเมื่อแสดง
  - รายการเซสชัน CI Software Factory และคอนเทนเนอร์จะเก็บแถวที่ไม่เปลี่ยนแปลงไว้ และ Git จะรีเฟรชเฉพาะแถวของไฟล์ที่สถานะเปลี่ยนไป
- แผงของหน้าต่างที่ปิดแล้วจะถูกปล่อยไปพร้อมกับหน้าต่างนั้น

## แถบ AI
- “แสดงเอาต์พุต” ของคำสั่งเบื้องหลังที่เขียนเอาต์พุตลงไฟล์เอง เช่น `make > build.log 2>&1` จะแสดงไฟล์นั้นเมื่อ CLI ไม่มีเอาต์พุตใดๆ เลย
