## แถบ AI
- `/resume` เปิดภาพรวมของเซสชันก่อนหน้าของเอเจนต์ในโฟลเดอร์นี้ เซสชันที่เลือกจะทำงานต่อในแถบของตัวเอง
- ตอนนี้เอเจนต์และ Copilot ได้รับเวอร์ชันจริงของ Dango แทน 0.0.0

## เทอร์มินัล
- เทอร์มินัลทำงานบนเอนจินหน้าจอใหม่: วาดใหม่เฉพาะบรรทัดที่เปลี่ยนแปลง และประวัติของเทอร์มินัลใช้หน่วยความจำน้อยลงขณะที่โปรแกรมในนั้นไม่ได้ทำงาน

## แถบ
- แถบที่เปิดจากเมนู + หรือด้วย ⌘T จะปรากฏที่ท้ายแถบแท็บ แทนที่จะอยู่ข้างแถบที่อยู่ด้านหน้า
