## ขนาดแบบอักษร
- การตั้งค่าใหม่ “ขนาดแบบอักษรในแถบด้านข้างและแถบ” กำหนดขนาดของแถบด้านข้าง ไอคอนในแถบด้านข้าง และแถวแถบได้ตั้งแต่ 10 ถึง 18 พอยต์ ทุกแผงของแถบด้านข้าง แถบไอคอนทางซ้าย ชื่อแถบของหน้าต่าง และแถวแถบของแต่ละบานหน้าต่างจะขยายและย่อตามสัดส่วน ทั้งข้อความ ไอคอน แถว และระยะห่างระหว่างกัน หน้าต่างที่เปิดอยู่จะเปลี่ยนตามทันที
- ขนาดแบบอักษรในตัวแก้ไขและเทอร์มินัลจะมีผลกับตัวแก้ไขที่เปิดอยู่ทันทีด้วย รวมถึงสไตล์ Markdown และหมายเลขบรรทัด และการแสดงตัวอย่าง Markdown จะขยายและย่อตามสัดส่วนเดียวกัน
- ส่วนหัวของแถบ AI จะเป็นไปตามขนาดแบบอักษรในแถบ AI เช่นเดียวกับไทม์ไลน์ ช่องข้อความ และแถบสถานะ

## AI
- เซสชัน Codex แสดงรายการเอเจนต์ย่อยและเทอร์มินัลเบื้องหลังไว้หลังปุ่มสองปุ่มที่ส่วนหัวของแถบ เช่นเดียวกับเซสชัน Claude คำขอสิทธิ์และปุ่มหยุดของเอเจนต์ย่อยแต่ละตัวทำงานแยกกัน
- ปุ่มที่แสดงเฉพาะบทสนทนาตอนนี้อยู่ระหว่างปุ่มของกระบวนการเบื้องหลังกับที่คั่นหน้า
