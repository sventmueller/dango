## แถบ AI
- แถบ AI ที่ไม่ได้อยู่ในมุมมองเป็นเวลาสามนาทีจะปล่อยกระบวนการ Claude ของมันขณะที่เซสชันว่างอยู่ บทสนทนาและสิ่งที่คุณพิมพ์ไว้ยังคงอยู่ในแถบ และ Prompt ถัดไปจะดำเนินเซสชันต่อ แถบจะเก็บกระบวนการของมันไว้ขณะที่ Claude กำลังทำงาน มี Prompt รออยู่ มีคำถามค้างอยู่ เอเจนต์ย่อย งานเบื้องหลัง หรือคำสั่งยังทำงานอยู่ หรือเปิด Remote Control อยู่
- การสิ้นสุดเอเจนต์จะสิ้นสุดคำสั่งที่เอเจนต์เริ่มไว้ในกลุ่มกระบวนการหรือเซสชันของคำสั่งเองด้วย ซึ่งก่อนหน้านี้อาจยังทำงานต่อไปหลังจากเอเจนต์จบแล้ว
- ไทม์ไลน์จะเพิ่มรายการใหม่ต่อท้าย แทนที่จะทำดัชนีแถวก่อนหน้าทั้งหมดใหม่อีกครั้ง

## ความเร็ว
- หน้าต่างที่กู้คืนจะเปิดเร็วขึ้น: แถบไฟล์ที่ไม่มีการเปลี่ยนแปลงที่ยังไม่ได้บันทึกจะโหลดไฟล์ของมันก็ต่อเมื่อถูกนำขึ้นมาด้านหน้าเท่านั้น
- การค้นหาในโปรเจ็กต์ที่แผงถูกซ่อนอยู่จะหยุดชั่วคราว และทำงานต่อเมื่อแผงแสดงขึ้น
- เครื่องหมายการเปลี่ยนแปลงของ Git ในตัวแก้ไขจะทำการเปรียบเทียบได้ครั้งละไม่เกินหนึ่งรายการต่อไฟล์ การแก้ไขระหว่างนั้นจะถูกรวมเป็นการเปรียบเทียบต่อเนื่องเพียงครั้งเดียว และข้อความของไฟล์ที่ Commit ไว้จะถูกอ่านใหม่เฉพาะเมื่อ Commit เปลี่ยนไป
- มินิแมปของไฟล์ที่มีโค้ดถูกยุบจะเก็บหนึ่งรายการต่อช่วงที่ไม่ได้ยุบ แทนที่จะเป็นหนึ่งรายการต่อบรรทัด
