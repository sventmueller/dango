  LM Studio

## หน้าต่าง
- ทุกไฟล์ เทอร์มินัล หน้าเบราว์เซอร์ เธรด AI Diff และการแสดงตัวอย่าง เป็นแถบ macOS ในหน้าต่างของโฟลเดอร์ ปุ่ม “+”
  ที่ท้ายแถวแถบและ ⌘T มีตัวเลือกไฟล์ใหม่ เทอร์มินัล เบราว์เซอร์ และเอเจนต์ทุกตัวที่ติดตั้งไว้ รวมถึงใน Git Worktree
  ของตัวเอง
- แถบด้านข้างสลับระหว่าง ไฟล์ ค้นหา เอเจนต์ Git ดีบัก CI การทดสอบ คอนเทนเนอร์ และ Software Factory
  คลิกขวาเพื่อซ่อนส่วนที่คุณไม่ใช้ แถบเครื่องมือมีปุ่มย้อนกลับและไปข้างหน้าตามตำแหน่งที่คุณแก้ไข (⌃- และ ⌃⇧-) Branch
  เปิดอย่างรวดเร็ว และภาพรวมกิจกรรม
- หน้าต่างแบ่งเป็นบานหน้าต่างวางเคียงข้างกันหรือซ้อนบนล่าง และซ้อนลึกลงไปได้ตามต้องการเหมือนใน Xcode
  แต่ละบานหน้าต่างเก็บเอกสารของตัวเองซ้อนกันไว้พร้อมแถวแถบของตัวเอง “เปิดไว้ด้านข้าง” แสดงเอกสารที่สองข้างเอกสารแรก
- หลังจากเริ่มใหม่หรือแอปขัดข้อง ทุกหน้าต่างจะกลับมาพร้อมแถบและบานหน้าต่างของตัวเอง
  และตัวแก้ไขที่มีข้อความที่ยังไม่ได้บันทึกจะกลับมาพร้อมข้อความนั้น
- รูปภาพ เสียง วิดีโอ ฟอนต์ และเอกสาร Office เปิดในแถบผ่าน Quick Look ส่วน PDF เปิดผ่าน PDFKit

## ตัวแก้ไข
- สีไวยากรณ์ หมายเลขบรรทัด เครื่องหมายการเปลี่ยนแปลงเทียบกับ Commit ล่าสุด ค้นหาและแทนที่ เปิดอย่างรวดเร็ว (⌘P)
  และการค้นหาในโปรเจ็กต์ (⇧⌘F) สีและสไตล์ Markdown ตามทันแม้ในไฟล์ที่ยาวหลายพันบรรทัดโดยไม่ทำให้การพิมพ์สะดุด
- การเยื้องอัตโนมัติ แท็บหรือช่องว่างตาม `.editorconfig` วงเล็บคู่ การสลับคอมเมนต์ การพับโค้ด ไปที่บรรทัด
  การแสดงช่องว่าง การตัดบรรทัด มินิแมป และส่วนหัวแบบตรึงของบล็อกที่ครอบอยู่
- เคอร์เซอร์หลายตัว: ⌥-คลิก ⌥-ลากเพื่อเลือกคอลัมน์ ⌘D สำหรับรายการถัดไปที่ตรงกัน
- **โหมด Vim:** เปิดใช้ในเมนูตัวแก้ไข มีโหมด normal, insert และ visual การเคลื่อนที่และตัวดำเนินการ รีจิสเตอร์ มาร์ก
  มาโคร การค้นหา และคำสั่ง Ex ข้อความของโหมดนี้แสดงเป็นภาษาของอินเทอร์เฟซ
- ตัวย่อ Emmet ในการเติมโค้ดของ HTML, CSS และ JSX และการแก้ไขปัญหาของ ESLint เมื่อบันทึกหากคุณต้องการ
- ไฟล์คงการเข้ารหัส เครื่องหมายลำดับไบต์ และอักขระขึ้นบรรทัดใหม่ไว้ตามเดิม
  ไฟล์ที่ถูกเปลี่ยนบนดิสก์จะโหลดใหม่เมื่อตัวแก้ไขไม่มีข้อความที่ยังไม่ได้บันทึก
  มิฉะนั้นจะมีแถบแจ้งเตือนเสนอให้ดูความแตกต่างและผสาน
- **การคาดการณ์ขณะพิมพ์:** ขณะที่คุณพิมพ์ ข้อเสนอจะปรากฏเป็นสีเทา กด Tab เพื่อรับ ข้อเสนอมาจาก GitHub Copilot
  หรือจากโมเดลในเครื่องใน Ollama หรือ LM Studio ตามที่คุณเลือกในการตั้งค่า โมเดลในเครื่องจะเก็บโค้ดของคุณไว้บน Mac
  เครื่องนี้

## เซิร์ฟเวอร์ภาษา
Go, Rust, TypeScript และ JavaScript, Python, C, C++ และ Objective-C, Swift, เชลล์สคริปต์, JSON, YAML, CSS, HTML, TOML,
Markdown และ Lua, ESLint ควบคู่กับเซิร์ฟเวอร์ TypeScript รวมถึงเซิร์ฟเวอร์ของคุณเองจากการตั้งค่า การวินิจฉัย
รวมถึงที่ท้ายบรรทัด ข้อมูลเมื่อวางเมาส์ การเติมโค้ด ความช่วยเหลือเรื่อง Signature ไปที่คำจำกัดความ คำจำกัดความของชนิด
และการนำไปใช้ การอ้างอิง ลำดับชั้นการเรียกและลำดับชั้นของชนิด การเปลี่ยนชื่อ การจัดรูปแบบ สีตามความหมาย การพับโค้ด
และโครงร่าง ชนิดและชื่อพารามิเตอร์ภายในบรรทัด แก้ไขด่วนและการปรับโครงสร้างโค้ดหลังไอคอนหลอดไฟ (⌥⌘A)
สัญลักษณ์ของโปรเจ็กต์ด้วย ⌥⌘O หรือ `#` ในเปิดอย่างรวดเร็ว แอปจะใช้ `tsc` ของโปรเจ็กต์ TypeScript
เองเมื่อสามารถทำหน้าที่เป็นเซิร์ฟเวอร์ภาษาได้

## ดีบัก
เบรกพอยต์ รวมถึงแบบมีเงื่อนไข การทำงานทีละขั้น เธรดของโปรแกรมพร้อมสแตกการเรียก ตัวแปรและนิพจน์ที่เฝ้าดูในตัวตรวจสอบ
(⌥⌘I) ค่าที่แสดงข้างโค้ดขณะโปรแกรมหยุดชั่วคราว และคอนโซลดีบักที่ประเมินผลในเฟรมที่หยุดชั่วคราว Rust, C, C++ และ Swift
ผ่าน `lldb-dap` Go ผ่าน `dlv` JavaScript และ TypeScript ผ่านดีบักเกอร์ JavaScript Python ผ่าน debugpy แอปอ่าน
`.vscode/launch.json` ของโปรเจ็กต์ เมนูดีบักใช้ปุ่มลัดแบบเดียวกับ Xcode

  ติดตามล็อก และเปิดเชลล์ในแถบเทอร์มินัล

## เทอร์มินัล
เทอร์มินัลในแถบพร้อมสภาพแวดล้อมของ Login Shell วาดด้วย Metal
การวางหรือลากรูปภาพมาวางจะส่งรูปนั้นให้เอเจนต์เขียนโค้ดที่ทำงานอยู่ในเทอร์มินัล หรือวางพาธของสำเนาที่บันทึกไว้
⌘-คลิกเพื่อเปิดลิงก์และชื่อไฟล์ เซิร์ฟเวอร์สำหรับพัฒนาที่เทอร์มินัลเริ่มไว้สามารถเปิดในแถบเบราว์เซอร์ได้

## Markdown
ไฟล์ Markdown จะเปิดพร้อมการแสดงตัวอย่างอยู่ด้านข้าง (⇧⌘V) รองรับสูตร ไดอะแกรม Mermaid, Graphviz และ PlantUML
และรูปภาพในโฟลเดอร์ เมนูรูปแบบมีตัวหนา ตัวเอียง ลิงก์ หัวเรื่อง รายการ คำพูดอ้างอิง และบล็อกโค้ด ข้อความที่วางจาก Word
หรือหน้าเว็บจะกลายเป็น Markdown **ไฟล์ › ส่งออก** เขียนเป็น PDF ไฟล์ HTML ไฟล์เดียว หรือเอกสาร Word เมื่อติดตั้ง Splat
ไว้ **ไฟล์ › เปิดใน Splat** จะเปิดเอกสารในแอปนั้น

## เบราว์เซอร์
แถบเบราว์เซอร์พร้อมช่องที่อยู่ ย้อนกลับและไปข้างหน้า การค้นหา การดาวน์โหลดที่ถามก่อน และตัวตรวจสอบเว็บ

## Git
แผง Git สำหรับ Stage และละทิ้งการเปลี่ยนแปลงของทั้งไฟล์หรือส่วนที่เปลี่ยนแปลงทีละส่วน การทำ Commit การทำ Commit แล้ว
Push หรือซิงค์ Branch, Stash ความขัดแย้งในการผสาน และกราฟของ Commit ล่าสุด Blame
แสดงว่าใครแก้ไขบรรทัดที่เคอร์เซอร์อยู่เป็นคนสุดท้าย หรือแสดงเป็นคอลัมน์สำหรับทั้งไฟล์ ปุ่มหนึ่งเขียนข้อความ Commit ด้วย
AI โดย Diff จะถูกส่งออกไปก็ต่อเมื่อ gitleaks ไม่พบข้อมูลลับในนั้น และทุก Commit ก็จะถูกตรวจหาข้อมูลลับด้วย เธรด AI
สามารถทำงานใน Git Worktree ของตัวเองได้ แผงจะแสดงสิ่งที่เธรดเปลี่ยนแปลงและนำงานมาใช้ด้วยการผสานหรือ Cherry-pick

## CI
GitHub Actions และ GitLab CI รวมถึง GitHub Enterprise Server และ GitLab ที่โฮสต์เอง: การรัน Job และล็อกของ Branch
ปัจจุบัน การรัน Job ที่ล้มเหลวใหม่ Job เดียว หรือ (บน GitHub) การรันทั้งหมด การเริ่ม Job
แบบแมนนวลหรืออนุมัติการปรับใช้ที่รออยู่ การเริ่ม Pipeline ใหม่หรือ Workflow ที่เริ่มเองได้ และการยกเลิก Merge Request
หรือ Pull Request และ Issue ที่เปิดอยู่จะแสดงในแผงเดียวกันและเปิดในแถบเบราว์เซอร์ ล็อกของ Job
ที่ล้มเหลวสามารถส่งให้เอเจนต์ได้ โดยทำเครื่องหมายว่าเป็นข้อความจากภายนอก โทเค็นมาจากพวงกุญแจ `gh` หรือ `glab`
สภาพแวดล้อมของ Login Shell หรือที่คุณป้อนเอง

## AI
เอเจนต์ทุกตัวทำงานในแถบ AI ที่มีไทม์ไลน์เดียวกัน: คำตอบ การเรียกเครื่องมือพร้อมผลลัพธ์ คำขอสิทธิ์ คำถาม
แผนที่ให้อนุมัติและแสดงความคิดเห็น สิ่งที่ต้องทำ เอเจนต์ย่อย และงานเบื้องหลัง
ปุ่มสองปุ่มที่ส่วนหัวของแถบแสดงรายการเอเจนต์ย่อยและกระบวนการเบื้องหลังที่กำลังทำงาน ก่อนทุก Prompt
แอปจะเก็บจุดตรวจสอบไว้ คุณสามารถตรวจทานและกรอกลับการเปลี่ยนแปลงได้ทีละข้อความ เธรดใหม่จะเริ่มในโหมด “ด้วยตนเอง”
และคำสั่ง Git ที่ทำลายข้อมูลจะไม่ได้รับอนุญาตแบบถาวรเลย ภาพรวมกิจกรรมแสดงทุกอย่างที่กำลังทำงาน
จุดสีเขียวบนแถบแสดงว่าเซสชันกำลังทำงาน จุดสีแดงแสดงว่าเซสชันกำลังรอคุณ
และจะมีการแจ้งเตือนเมื่อเซสชันเสร็จหรือรอขณะที่คุณดูอย่างอื่นอยู่ ไทม์ไลน์ ช่องข้อความ
และแถบสถานะมีขนาดข้อความของตัวเองในการตั้งค่า
- **Claude** ผ่านคำสั่ง `claude` แบบไม่ดัดแปลง พร้อมเซสชัน เอเจนต์ย่อย งานเบื้องหลัง บริบท การใช้งาน และ Remote Control
  จากโทรศัพท์
- **Codex** ผ่าน App Server ของตัวเอง และ **OpenCode** ผ่านเซิร์ฟเวอร์ของตัวเอง แต่ละตัวใช้โปรโตคอลของตนเอง
  พร้อมเธรดของตัวเอง การกรอกลับภายในตัวเอเจนต์เอง และ Remote Control สำหรับ Codex
- **เอเจนต์ ACP:** Antigravity และเอเจนต์อื่นจากรีจิสทรี ACP เมื่อคุณขอ
  เอเจนต์ที่ติดตั้งจะถูกกำหนดไว้ที่เวอร์ชันที่ทดสอบแล้วและตรวจสอบกับเช็คซัม
- **เอเจนต์ในตัว:** Anthropic, OpenAI, Google Gemini, OpenRouter, Ollama, LM Studio และเซิร์ฟเวอร์ที่ใช้ API ของ OpenAI
  หรือ Anthropic พร้อมเครื่องมือสำหรับไฟล์ การค้นหา คำสั่ง การวินิจฉัย และคำขอเว็บ คีย์จะอยู่ในพวงกุญแจ
- คำสั่งของเอเจนต์เองจะเปิดเป็นโอเวอร์เลย์บนแถบ แบบเดียวกันสำหรับเอเจนต์ทุกตัว: สถานะ การส่งออก เซิร์ฟเวอร์ MCP สิทธิ์
  Hook ความจำ การกำหนดค่า Skills ปลั๊กอิน โมเดล บัญชี และคำติชม
- สวิตช์แซนด์บ็อกซ์ของแต่ละเธรดจำกัดสิ่งที่คำสั่งของเอเจนต์ทำได้ เท่าที่เอเจนต์รองรับ
- ข้อความจากภายนอก เช่น เอาต์พุตของเทอร์มินัล หน้าเว็บ หรือล็อก CI จะส่งให้เอเจนต์โดยทำเครื่องหมายว่าไม่น่าเชื่อถือ

## Software Factory
ใบสั่งงานแทน Prompt ทีละรายการ: เป้าหมายพร้อมเกณฑ์การตรวจรับ ที่เขียนเองหรือนำมาจาก Issue ใบสั่งงานแต่ละใบจะถูกวางแผน
สร้าง และตรวจสอบใน Git Worktree ของตัวเอง โดยเอเจนต์จากผู้ผลิตต่างรายกันในบทบาทที่กำหนดไว้: ผู้วางแผนเขียนข้อกำหนด
ผู้สร้างลงมือทำงาน และผู้ตรวจทานจากผู้ผลิตอีกรายตรวจทุกเกณฑ์ คำสั่งด่านตรวจของโปรเจ็กต์ เช่น บิลด์และการทดสอบ
ทำงานในแซนด์บ็อกซ์ และผู้สร้างจะแก้ไขสิ่งที่คำสั่งเหล่านั้นพบ
- คุณตัดสินใจสองจุด: คุณอนุมัติข้อกำหนด และคุณตรวจรับผลลัพธ์พร้อมหลักฐาน ทั้งหมดหรือทีละส่วน
  ไม่มีสิ่งใดถูกนำมาใช้หากคุณไม่ตรวจรับ
- แผงและแถบ Software Factory แสดงใบสั่งงานทุกใบพร้อมสถานี ค่าใช้จ่าย และสิ่งที่กำลังรอ แถบของใบสั่งงานแสดงไทม์ไลน์
  หลักฐาน และขั้นตอนถัดไป และเปิดเซสชันที่กำลังทำงานเป็นแถบ AI
- งบประมาณต่อใบสั่งงานและต่อวัน ขีดจำกัดจำนวนรอบ การหยุดชั่วคราวเมื่อออกจากแอป พักเครื่อง และแบตเตอรี่เหลือน้อย
  และล็อกที่เขียนไว้ก่อนการดำเนินการทุกครั้ง ใบสั่งงานจึงทำต่อได้หลังเริ่มใหม่
- Issue ที่มีป้ายกำกับที่เลือกไว้สามารถเข้ามาเป็นใบสั่งงานได้ ใบสั่งงานที่ตรวจรับแล้วสามารถส่งออกไปเป็น Merge Request
  พร้อมความคิดเห็นใน Issue ของใบสั่งงานนั้นเมื่อคุณคลิก ใบสั่งงานที่มีขอบเขตพาธแยกกันจะทำงานควบคู่กันและถูกนำมาใช้ทีละใบ
- ตัวชี้วัดต่อเอเจนต์และผู้ผลิต การกำหนดเส้นทางตามอัตราผ่านในรอบแรก ข้อเสนอกฎสำหรับ `AGENTS.md` และ `CLAUDE.md`
  จากข้อค้นพบที่เกิดซ้ำ และใบสั่งงานที่เกิดซ้ำจากไฟล์เวิร์กโฟลว์ของโปรเจ็กต์
- ไฟล์เวิร์กโฟลว์ `.dango/factory.toml` ของโฟลเดอร์เก็บด่านตรวจ ระดับความเสี่ยง และขอบเขตพาธ
  คำสั่งด่านตรวจที่เปลี่ยนไปและทุกสิ่งที่ผ่อนขอบเขตลงจะรอให้คุณยืนยัน

## การป้อนตามคำบอก
การป้อนตามคำบอกในช่องข้อความ AI และในตัวแก้ไขผ่านการรู้จำเสียงพูดของ Lowspeak: ปุ่มไมโครโฟน ⌃⌥D หรือปุ่ม fn ขณะที่ Dango
เป็นแอปที่ใช้งานอยู่ ใช้การตั้งค่าและโมเดลของ Lowspeak การถอดเสียงออนไลน์ต้องใช้คีย์ของ OpenAI หรือ Groq

## การอัปเดต
แอปอัปเดตตัวเองผ่าน Sparkle เมื่อเปิดครั้งที่สอง แอปจะถามว่าสามารถตรวจหาอัปเดตเองได้หรือไม่ และจะไม่ส่งคำขอใดๆ
จนกว่าคุณจะยินยอม **Dango › ตรวจหารายการอัปเดต…** ตรวจหาทันที

## การช่วยการเข้าถึง
ชื่อสำหรับ VoiceOver ของแถบด้านข้าง แถบ การ์ดในไทม์ไลน์ AI แถว Git และ CI รวมถึง Software Factory ดีบักเกอร์
และข้อความของเทอร์มินัล ควบคุมด้วยแป้นพิมพ์ได้ทั้งหมดด้วยปุ่มลัดที่เปลี่ยนได้ใน `keybindings.json`
รองรับเพิ่มความต่างของสีและลดการเคลื่อนไหว มุมมองโค้ดยังคงเรียงจากซ้ายไปขวาในอินเทอร์เฟซที่เขียนจากขวาไปซ้าย
ดูรายละเอียดใน ACCESSIBILITY.md

## ความเป็นส่วนตัว
ไม่มีการวัดและส่งข้อมูลทางไกล ไม่มีการวิเคราะห์ และไม่มีรายงานข้อขัดข้อง แอปเชื่อมต่อเฉพาะสำหรับสิ่งที่คุณเริ่มเอง:
เอเจนต์ที่คุณใช้ การดาวน์โหลดที่คุณขอ โฮสต์ CI ที่คุณลงชื่อเข้า การคาดการณ์จาก Copilot หากคุณเลือก
การถอดเสียงออนไลน์หากคุณเลือก หน้าเว็บที่คุณเปิด และการตรวจหาอัปเดตเมื่อคุณอนุญาตแล้ว คีย์และโทเค็นจะอยู่ในพวงกุญแจของ
macOS และเอเจนต์ของ Software Factory จะไม่เห็นข้อมูลเหล่านี้เลย

## ข้อจำกัดที่ทราบ
- การลงชื่อเข้า CI ผ่านเบราว์เซอร์ปิดอยู่ ให้ใช้ `gh`, `glab`, โทเค็น หรือสภาพแวดล้อมแทน
- แอปทำงานโดยไม่มี App Sandbox เพราะเทอร์มินัล Git เซิร์ฟเวอร์ภาษา และเอเจนต์จะสืบทอดไปด้วย
  คุณต้องเชื่อถือโฟลเดอร์ก่อนที่สิ่งที่โฟลเดอร์นั้นกำหนดค่าไว้จะทำงาน Antigravity และ OpenCode
  ไม่มีแซนด์บ็อกซ์ที่แอปเปิดใช้ได้
- ใน Software Factory ผู้สร้างหรือผู้ตรวจทานที่เป็น Codex สามารถอ่านนอก Worktree ของตัวเองได้ เพราะโปรโตคอลของ Codex
  ไม่มีขอบเขตการอ่าน แต่การเขียนยังคงอยู่ภายใน
- ตัวเลขการใช้งานและรายละเอียดบริบทของ Claude อาศัยส่วนของโปรโตคอลที่ระบุว่าเป็นรุ่นทดลอง
  และจะถูกซ่อนเมื่อไม่มีข้อมูลนั้น การกรอกลับบทสนทนาใช้ได้กับ Claude, Codex และ OpenCode
  สำหรับเอเจนต์อื่นจะกรอกลับเฉพาะโค้ด
- ไม่มี Gemini CLI ให้เลือก: Google ยุติการลงชื่อเข้าด้วยบัญชีส่วนตัวและแนะนำให้ใช้ Antigravity แทน เธรด Gemini
  ก่อนหน้ายังคงอ่านได้
