## ความเร็วและหน่วยความจำ
- ทุกอย่างที่เอเจนต์เริ่ม ไม่ว่าจะเขียนด้วยภาษาใด เช่น การบิลด์ การทดสอบ เชลล์ และเซิร์ฟเวอร์ MCP จะทำงานในสถานะเบื้องหลังของ macOS ด้วยลำดับความสำคัญต่ำสุด และถูกจำกัดการเข้าถึงดิสก์และเครือข่าย ส่วนตัวเอเจนต์เอง รวมถึงเอเจนต์ย่อยของ Claude จะทำงานด้วยลำดับความสำคัญปานกลาง เอเจนต์ที่ทำงานเต็มกำลังจะไม่ทำให้ Dango ช้าลงอีกต่อไป ซึ่งรวมถึงเอเจนต์ของ Software Factory ด้วย
- หน้าต่างที่กู้คืนมาจะเริ่มเฉพาะสิ่งที่แสดงอยู่ แถบ AI ที่อยู่หลังแถบอื่นจะเริ่ม CLI ของตัวเองเมื่อถูกนำขึ้นมาด้านหน้าหรือได้รับพรอมต์ ส่วนแถบเบราว์เซอร์ แถบแสดงตัวอย่างเว็บไซต์ และแถบเทอร์มินัลจะโหลดหน้าเว็บหรือเริ่มเชลล์ของตัวเองเมื่อแสดงขึ้นเป็นครั้งแรก
- การค้นหาในโปรเจ็กต์ที่ใช้เวลานานจะไม่วาดผลการค้นหาทั้งหมดใหม่ซ้ำ ๆ ขณะที่ยังค้นหาอยู่อีกต่อไป Software Factory ล็อก CI และแผงการทดสอบจะทำงานน้อยลงขณะที่มองไม่เห็น การทดสอบและการกำหนดค่าการดีบักจะถูกอ่านเมื่อแผงของมันแสดงขึ้นเป็นครั้งแรก และแผง CI กับแผงคอนเทนเนอร์ที่ซ่อนอยู่จะไม่อ่านสิ่งใดเลยจนกว่าจะแสดงขึ้น
- เซสชันที่ยาวนานใช้หน่วยความจำน้อยลง ความแตกต่างที่เสร็จแล้วจะเก็บไว้เฉพาะบรรทัดที่การ์ดของมันแสดง คำขอสิทธิ์ที่ตอบแล้วจะปล่อยอินพุตของมัน แคชกลิฟของเทอร์มินัลไม่ขยายตัวอย่างไม่มีขีดจำกัดอีกต่อไป และแผงไฟล์กับแผง Git จะปล่อยแถวที่ไม่มีอยู่แล้ว
- ตัวโปรแกรมเองมีขนาดเล็กลงประมาณ 40%

## หน้าต่างและเมนู
- การปิดบานหน้าต่างจะย้ายแถบของบานหน้าต่างนั้นไปยังบานหน้าต่างก่อนหน้า หรือถ้าไม่มีก็ไปยังบานหน้าต่างถัดไป แทนที่จะปิดแถบเหล่านั้น มีเพียงบานหน้าต่างของการแสดงตัวอย่างและบานหน้าต่างสุดท้ายเท่านั้นที่ปิดไปพร้อมกับแถบของมัน
- เมนูมุมมองแสดงรายการแผงตามลำดับของสัญลักษณ์ในแถบด้านข้าง
- “จัดการเอเจนต์…” ไม่อยู่ในเมนู + แล้ว แต่ยังคงอยู่ใต้ “+ เซสชันใหม่” ในแผงเอเจนต์

## การแก้ไขข้อบกพร่อง
- “รวมและไม่รวมไฟล์” ในแผงค้นหาไม่แสดงตัวอักษรเกินมาข้างลูกศรอีกต่อไป
- การปิดป๊อปโอเวอร์ความคิดเห็นของข้อกำหนดไม่ทำให้แอปขัดข้องอีกต่อไป
