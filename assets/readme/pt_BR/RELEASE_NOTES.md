## Abas de IA
- Uma aba de IA que fica fora de vista por três minutos encerra seu processo do Claude enquanto a sessão está ociosa. A
  conversa e o que você digitou permanecem na aba, e o próximo prompt retoma a sessão. Uma aba mantém seu processo
  enquanto o Claude trabalha, um prompt espera, uma pergunta está aberta, um subagente, uma tarefa em segundo plano ou
  um comando ainda está em execução ou o Remote Control está ativado.
- Encerrar um agente também encerra os comandos que ele iniciou em um grupo de processos ou uma sessão próprios, que
  antes podiam sobreviver a ele.
- A linha do tempo acrescenta novas entradas no final em vez de indexar novamente todas as linhas anteriores.

## Velocidade
- Janelas restauradas abrem mais rápido: uma aba de arquivo sem alterações não salvas só carrega o arquivo quando vem
  para a frente.
- Uma busca no projeto cujo painel está oculto é pausada e continua quando o painel aparece.
- Os marcadores de alteração do Git no editor executam no máximo uma comparação por vez em cada arquivo; as edições
  feitas nesse meio-tempo são reunidas em uma única comparação seguinte, e o texto do arquivo no commit só é lido
  novamente quando o commit muda.
- O minimapa de um arquivo com código recolhido mantém uma entrada por trecho expandido em vez de uma por linha.

## Busca
- A seta dos filtros fica alinhada com a seta de Substituir acima dela.
