## 메모리
- 긴 에이전트 세션에 필요한 메모리가 크게 줄었습니다.
  - 이전 세션을 열 때 대화 기록을 한 줄씩 읽습니다. 대화 기록이 100 MB인 세션의 최대 사용량은 이제 65 MB가 아니라 약 20 MB입니다.
  - 완료된 도구 호출은 카드에 표시되는 내용만 보관합니다. 출력의 처음 400줄을 보관하며, 카드가 필드를 표시한 후에는 원시 입력을 더 이상 보관하지 않습니다. ‘N줄 더 있음’은 여전히 모든 줄을 셉니다.
  - 30초 동안 보이지 않는 AI 탭은 카드를 해제하고, 다시 표시될 때 원래 위치에서 보이는 카드를 만듭니다.
  - 탭을 닫거나 이전 세션을 연 후, Dango는 해제한 메모리를 macOS에 돌려줍니다.
- 목록이 새로 고쳐질 때 메모리에서 더 이상 커지지 않습니다. macOS 27에서는 펼칠 수 있는 행이 있는 목록을 새로 고칠 때마다 펼침 삼각형이 영구히 남았고, 새로 고칠 때마다 각 행의 일부가 조금씩
  남았습니다.
  - CI, 컨테이너, Software Factory, 테스트, 디버그, Git, 검색 목록과 호출 계층은 화살표를 직접 그립니다.
  - 보이지 않는 목록은 더 이상 새로 고치지 않으며, 표시될 때 밀린 내용을 반영합니다.
  - 세션, CI, Software Factory, 컨테이너 목록은 바뀌지 않은 행을 유지하며, Git은 상태가 바뀐 파일의 행만 새로 고칩니다.
- 닫힌 윈도우의 패널은 윈도우와 함께 해제됩니다.

## AI 탭
- `make > build.log 2>&1`처럼 출력을 직접 파일에 쓰는 백그라운드 명령의 ‘출력 보기’는 CLI에 출력이 전혀 없을 때 그 파일을 보여줍니다.
