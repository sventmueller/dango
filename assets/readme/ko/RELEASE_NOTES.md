## 터미널
- 터미널이 이제 Dango의 자매 터미널 앱인 Tapa의 터미널이 되어 Tapa가 더하는 모든 기능을 갖춥니다. 에이전트에 이미지 붙여넣기, 브라우저 탭의 개발 서버, 편집기로 여는 ⌘-클릭 등 Dango의 터미널이 이전에 하던 일은 그대로 유지됩니다.
- **보기 › 입력 필드 보기/가리기**(터미널에 포커스가 있을 때 ⌘I)는 명령 줄을 텍스트 필드로 바꾸고, 그 위에 폴더와 Git 브랜치를 보여 줍니다. 명령은 부분별로 색상이 구분되며, 셸이 실행할 수 없는 명령에는 빨간 점선 밑줄이 표시됩니다.
- 제안은 입력 필드에서든 입력 필드 없이든 입력하는 동안 회색으로 표시됩니다. 기록, 700개가 넘는 명령 줄 도구의 사양, 그리고 git 브랜치, `package.json` 스크립트, make, just, cargo 타깃 같은 프로젝트의 정보에서 가져옵니다. →는 제안을 받아들이고, Tab은 완성하며 후보가 여러 개이면 입력할수록 좁혀지는 메뉴를 엽니다. 제안은 네트워크를 절대 사용하지 않습니다.
- 명령 블록에서는 ⌘↑와 ⌘↓로 프롬프트 사이를 이동하고, **편집** 메뉴로 명령의 출력을 선택, 복사, 저장하며, 책갈피로 줄을 표시합니다. **명령을 블록으로 표시**를 켜면 막대가 각 블록을 보여 주고, 실패한 명령이 표시되며, 블록 위의 버튼이 상태와 걸린 시간을 보여 줍니다.
- **블록을 에이전트에 보내기**(편집 메뉴와 터미널의 컨텍스트 메뉴)는 AI 탭을 열어 현재 블록의 명령 줄과 출력을 ‘외부 콘텐츠’로 첨부합니다.
- **찾기**(터미널에 포커스가 있을 때 ⌘F)는 정규 표현식, 대소문자 구분, 전체 단어 일치로 전체 기록을 검색하며, 스크롤 막대에 결과가 표시됩니다.
- 프로그램의 알림(OSC 9 및 OSC 777)과 벨은 터미널이 보이지 않는 동안 터미널 탭에 빨간색 점을 붙이며, 다른 앱이 앞에 있으면 알림이 macOS로 전달됩니다. 프로그램이 보고하는 진행 상황(OSC 9;4)은 탭에 고리로, Dock 아이콘에 막대로 표시됩니다.
- 이중 클릭하면 URL, 경로, 해시를 통째로 선택하고, ⌥-드래그하면 사각형 영역을 선택합니다. **서식 포함 복사**는 색상과 스타일을 유지하고, **키보드로 선택**은 Vim 키로 선택 영역을 움직입니다.
- 즉시 실행될 여러 줄 붙여넣기는 먼저 표시되며, **Dango › 보안 키보드 엔트리**는 터미널에 입력하는 내용을 다른 앱이 읽지 못하게 합니다.
- 웹 주소, `mailto:`, 파일 이외의 종류의 링크는 더 이상 터미널에서 열리지 않습니다.

## 설정
- **설정 › 터미널**에서는 새 터미널의 입력 필드, 그 Vim 키, 제안, 명령 색상 구분, 알 수 없는 명령의 밑줄, 명령 블록, 선택 영역 즉시 복사, 여러 줄 붙여넣기 먼저 표시, Meta 키로 쓰는 ⌥을 켜고 끕니다. Meta 키로 쓰는 ⌥은 일반에서 이곳으로 옮겨졌습니다.
