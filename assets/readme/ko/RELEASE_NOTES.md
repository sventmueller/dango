## 도구 막대
- 오른쪽부터 새 순서: ‘새로운 터미널’, ‘새로운 AI 스레드’, ‘새로운 브라우저 탭’이 한 그룹에 있고, 그 왼쪽에 ‘오른쪽으로 분할’, ‘아래로 분할’과 입력 필드 스위치, 그다음 ‘빠르게 열기’와 ‘활동’이 있습니다.
- 입력 필드 스위치는 앞에 있는 터미널의 필드를 켜거나 끄며, 필드가 켜져 있는 동안 강조 색상으로 표시됩니다. 앞에 터미널이 없으면 흐리게 표시됩니다.
- 에이전트가 하나만 설치되어 있으면 ‘새로운 AI 스레드’가 클릭 한 번으로 그 에이전트를 엽니다. 그렇지 않으면 클릭하면 에이전트가 메뉴로 표시됩니다. 버튼을 길게 누르면 항상 메뉴가 표시됩니다.
- 설정 버튼이 사이드바 아래쪽의 더 낮은 위치로 옮겨졌습니다.

## 터미널
- 입력 필드 없이도 입력한 명령이 필드와 같은 색으로 표시됩니다. 명령, 하위 명령, 옵션, 변수, 연산자에 색이 입혀지고, 셸이 실행할 수 없는 명령에는 빨간 점선 밑줄이 그어집니다. 셸이 직접 지정한 색은 그대로 유지됩니다.
- 입력 필드 없이도 단어를 입력하면 제안 목록이 저절로 열립니다. Return은 줄을 실행하고 Tab 또는 →는 회색 제안을 받아들이며, ↑ 또는 ↓로 선택을 옮긴 뒤에는 선택한 항목을 받아들입니다. Esc는 그 단어에 대한 목록을 닫고, '설정 › 터미널'에서 끌 수 있습니다.
