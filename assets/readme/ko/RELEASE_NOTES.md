## 속도
- 빌드, 테스트, 셸 등 에이전트가 시작하는 것은 이제 macOS의 백그라운드 상태 대신 가장 낮은 우선순위로 실행됩니다. Dango가 여전히 가장 먼저이고 에이전트는 자신이 시작한 것보다 앞서지만, 에이전트의 빌드는 다시 성능 코어와 디스크의 최대 속도를 사용합니다. 백그라운드 상태에서는 다른 작업이 없는 Mac에서도 처리량이 약 10분의 1로 줄어들었습니다.

## 에이전트
- AI 탭의 점은 해당 세션의 백그라운드 명령이 아직 실행 중인 동안 초록색으로 유지되며, 세션이 끝났다는 알림은 백그라운드 작업까지 끝난 뒤에야 표시됩니다.
