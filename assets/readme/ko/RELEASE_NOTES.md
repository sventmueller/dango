## 속도와 메모리
- 에이전트가 시작하는 모든 것, 즉 빌드, 테스트, 셸, MCP 서버 등은 언어와 관계없이 macOS의 백그라운드 상태에서 실행됩니다. 우선순위는 가장 낮고 디스크와 네트워크 접근도 제한됩니다. 에이전트 자체는 Claude의 하위 에이전트를 포함해 중간 우선순위로 실행됩니다. 이제 에이전트가 최대 부하로 작동해도 Dango가 느려지지 않으며, 이는 Software Factory의 에이전트에도 적용됩니다.
- 복원된 윈도우는 보이는 것만 시작합니다. 다른 탭 뒤에 있는 AI 탭은 앞으로 나오거나 프롬프트를 받을 때 CLI를 시작하고, 브라우저, 사이트 미리보기, 터미널 탭은 처음 표시될 때 페이지를 불러오거나 셸을 시작합니다.
- 오래 걸리는 프로젝트 검색이 실행되는 동안 모든 결과를 계속 다시 그리지 않습니다. Software Factory, CI 로그, ‘테스트’ 패널은 보이지 않는 동안 작업을 줄입니다. 테스트와 디버그 구성은 해당 패널이 처음 표시될 때 읽히며, 숨겨진 ‘CI’ 패널과 ‘컨테이너’ 패널은 표시될 때까지 아무것도 읽지 않습니다.
- 긴 세션에 필요한 메모리가 줄었습니다. 완료된 차이점은 카드에 표시되는 줄만 유지하고, 응답한 권한 요청은 입력을 해제하며, 터미널의 글리프 캐시는 더 이상 끝없이 커지지 않고, ‘파일’ 패널과 ‘Git’ 패널은 사라진 줄을 해제합니다.
- 프로그램 자체의 크기가 약 40% 줄었습니다.

## 윈도우와 메뉴
- 분할 창을 닫으면 그 탭이 닫히지 않고 앞의 분할 창으로, 앞의 분할 창이 없으면 뒤의 분할 창으로 옮겨집니다. 미리보기의 분할 창과 마지막 분할 창만 탭과 함께 닫힙니다.
- ‘보기’ 메뉴는 패널을 사이드바 아이콘과 같은 순서로 나열합니다.
- ‘에이전트 관리…’가 + 메뉴에서 빠졌습니다. ‘에이전트’ 패널의 ‘+ 새로운 세션’ 아래에는 그대로 있습니다.

## 수정 사항
- ‘검색’ 패널의 ‘파일 포함 및 제외’에서 화살표 옆에 엉뚱한 글자가 더 이상 표시되지 않습니다.
- 사양의 댓글 팝오버를 닫아도 더 이상 앱이 충돌하지 않습니다.
