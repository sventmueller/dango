## AI 탭
- 3분 동안 보이지 않은 AI 탭은 세션이 유휴 상태인 동안 Claude 프로세스를 종료합니다. 대화와 입력한 내용은 탭에 남으며, 다음 프롬프트가 세션을 재개합니다. Claude가 작업 중이거나, 프롬프트가 대기 중이거나, 답하지 않은 질문이 있거나, 하위 에이전트, 백그라운드 작업 또는 명령이 아직 실행 중이거나, Remote Control이 켜져 있는 동안에는 탭이 프로세스를 유지합니다.
- 에이전트를 종료하면 에이전트가 자체 프로세스 그룹이나 세션에서 시작한 명령도 함께 종료됩니다. 이전에는 이러한 명령이 에이전트보다 오래 실행될 수 있었습니다.
- 타임라인은 이전의 모든 행의 색인을 다시 생성하는 대신 새 항목을 끝에 추가합니다.

## 속도
- 복원된 윈도우가 더 빨리 열립니다. 저장되지 않은 변경 사항이 없는 파일 탭은 앞으로 나올 때에야 파일을 불러옵니다.
- 패널이 가려진 프로젝트 검색은 일시 정지되었다가 패널이 표시되면 계속됩니다.
- 편집기의 Git 변경 표시는 파일마다 한 번에 최대 하나의 비교만 실행합니다. 비교하는 동안의 편집은 하나의 후속 비교로 합쳐지며, 파일의 커밋된 텍스트는 커밋이 바뀌었을 때만 다시 읽습니다.
- 접힌 코드가 있는 파일의 미니맵은 줄마다 항목을 하나씩 두는 대신 펼쳐진 구간마다 항목을 하나씩 유지합니다.
