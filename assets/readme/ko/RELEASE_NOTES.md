## AI 탭
- 백그라운드 명령의 ‘출력 보기’는 이제 그 순간의 출력 사본 대신, 명령이 실행되는 동안 출력을 따라가는 탭을 엽니다. 탭은 출력의 끝에서 열리며, 위로 스크롤하기 전까지는 새 줄이 들어와도 끝에 머무릅니다. 끝까지 스크롤해 돌아가면 다시 출력을 따라갑니다. 이미 열려 있는 탭에서 ‘출력 보기’를 누르면 해당 탭이 끝 위치에서 앞으로 나옵니다.
  - `make > build.log 2>&1`처럼 출력을 직접 파일에 쓰는 명령은 해당 파일이 커지는 대로 보여 줍니다.
  - 명령이 끝나면 탭에 전체 출력이 표시되며, ‘편집기에서 열기’는 그 바탕이 되는 파일을 엽니다.
  - 탭은 앞에 있는 동안에만 출력을 읽습니다.
