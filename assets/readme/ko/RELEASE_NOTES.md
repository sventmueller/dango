## 보안
- 에이전트의 응답, 계획, 보고서, Markdown 미리보기, PDF에 있는 링크를 한 번 클릭해도 더 이상 앱이 열리지 않습니다. 웹 주소는 브라우저 탭에서, 프로젝트 안의 파일은 편집기 탭에서 열립니다. 다른 곳에 있는 파일, 네트워크 공유, 다른 앱의 링크 등 그 밖의 것은 먼저 묻고 링크가 어디로 연결되는지 보여 줍니다.
- 에이전트나 MCP 서버가 넘겨주는 로그인 및 Remote Control 주소는 웹 주소일 때만 열립니다.
- 홈 폴더, 데스크탑, 문서, 다운로드, 볼륨의 루트처럼 프로젝트 하나보다 훨씬 많은 것을 포함하는 폴더는 더 이상 전체를 신뢰할 수 없습니다. 프로젝트별로 신뢰하십시오. 이제 신뢰 질문에서 그 안의 폴더에도 신뢰가 적용된다고 알려 줍니다.
- CI 토큰과 로그인 정보는 이 Mac 이외의 서버로 일반 http를 통해 전송되지 않습니다. 원격이 `http://`로 시작하는 저장소에는 https로 요청합니다.
- gitleaks가 없으면 편집 예측은 이 Mac 외부의 제공자에게 코드를 보내기 전에, 검사 없이 보내기를 선택할 때까지 기다립니다. 프로젝트 자체의 gitleaks 설정으로 더 이상 검사가 꺼지지 않습니다.
- 내장 에이전트가 쓰기가 승인된 후에 나타나는 링크를 통해 프로젝트 밖에 쓰도록 유도될 수 없게 되었으며, 다른 하드 링크가 있는 파일은 링크를 통해 쓰이는 대신 별도의 파일이 됩니다.
- 언어 서버의 자동 완성으로 편집기가 더 이상 멈추지 않으며, 언어 서버가 링크된 파일의 이름을 변경하거나 삭제하면 링크가 가리키는 대상이 아니라 링크 자체에 적용됩니다.
- 프롬프트에 첨부하는 이미지는 다른 모든 곳과 마찬가지로 샌드박스 처리된 디코딩 서비스에서 디코딩됩니다.
- 터미널의 프로그램은 해당 터미널이 앞에 있는 동안에만 클립보드를 대체할 수 있으며, 터미널이 이를 알려 줍니다.
- rust-analyzer는 그때그때의 최신 버전 대신 체크섬으로 고정된 릴리스에서 설치됩니다.

## 검색과 탐색
- ‘빠르게 열기’는 일치하는 파일이 없을 때 이를 알려 주고, 파일과 프로젝트의 심볼 중 무엇을 검색하는지 보여 줍니다.
- 프로젝트의 심볼에 TypeScript와 JavaScript가 해당 파일을 열지 않아도 포함됩니다. 프로젝트의 정확한 일치와 작업 중인 언어의 항목이 먼저 표시되며, 라이브러리와 설치된 패키지의 심볼에는 표시가 붙습니다.
- ‘보기’ › ‘검색’을 선택하면 검색 필드로 포커스가 이동합니다.

## 편집기
- Markdown 파일이 옆에 미리보기와 함께 열릴 때도 편집기가 포커스를 유지하므로 ‘포맷’ 메뉴를 바로 사용할 수 있습니다. 포커스가 사이드바에 있는 동안에도 편집기 명령이 작동합니다.
- 줄 끝이나 그 아래 상자에 표시되는 제안은 Tab으로 받을 수 있다고 알려 줍니다.
- 탭 개요에서 이름이 같은 탭을 구별할 수 있습니다. 예를 들어 파일과 브라우저에 표시된 그 미리보기입니다.
- ‘보기’ 메뉴에 Dango의 탭에서 사용하지 않는 macOS 자체의 ‘탭 막대 가리기’가 더 이상 표시되지 않습니다.

## 언어와 디버깅
- 이제 JSON 서버가 파일을 검사하며, basedpyright와 sourcekit-lsp처럼 시작 후에 진단을 등록하는 서버의 진단도 표시됩니다.
- Homebrew의 Python처럼 pip가 Python에 설치를 거부하는 경우, 디버거가 프로젝트의 가상 환경에 debugpy를 설치하도록 제안합니다.
