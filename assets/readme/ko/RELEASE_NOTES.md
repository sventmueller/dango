Dango의 첫 번째 릴리스입니다. Dango는 코딩 에이전트와 함께 작업하기 위한 네이티브 macOS 편집기입니다. 편집기, 터미널, 브라우저, Git, CI, 디버거, AI 스레드가 폴더마다 하나의 윈도우를 함께
씁니다. 앱은 AppKit 기반의 Rust로 작성되었으며, WebKit은 브라우저 탭에서만 사용됩니다. 인터페이스는 35개 언어로 제공됩니다.

## 요구 사항
- macOS 14 이상, Apple 실리콘 또는 Intel 기반 Mac.
- AI 스레드에는 선택한 에이전트가 필요합니다. Claude에는 로그인된 `claude` 명령이 필요합니다. Codex에는 Node.js가 필요하며, 요청하면 앱이 고정된 버전의 패키지를 설치합니다.
  Antigravity와 OpenCode는 직접 설치한 `agy` 또는 `opencode`나, 고정된 버전의 다운로드를 사용합니다. 내장 에이전트에는 API 키, 또는 이 Mac의 Ollama나 LM Studio가
  필요합니다.
- 언어 서버와 디버그 어댑터는 요청하면 설치됩니다. gopls와 `dlv`에는 Go가 필요합니다. TypeScript, Python, JSON, YAML, CSS, HTML, 셸 서버와 JavaScript
  디버거에는 Node.js가 필요합니다. clangd, sourcekit-lsp, `lldb-dap`은 Xcode Command Line Tools에 포함되어 있습니다.
- 편집 예측에는 GitHub Copilot 구독(무료 플랜도 가능) 또는 Ollama나 LM Studio의 fill-in-the-middle 모델이 필요합니다.

## 윈도우
- 모든 파일, 터미널, 브라우저 페이지, AI 스레드, 차이점 보기, 미리보기는 폴더 윈도우의 macOS 탭입니다. 탭 막대 끝의 ‘+’와 ⌘T로 새로운 파일, 터미널, 브라우저, 설치된 각 에이전트를 열 수
  있으며, 별도의 Git 워크트리에서도 열 수 있습니다.
- 사이드바는 파일, 검색, 에이전트, Git, 디버그, CI 사이를 전환합니다(⌘1–⌘6). 사용하지 않는 항목은 오른쪽 클릭으로 가릴 수 있습니다. 도구 막대에는 편집한 위치를 오가는 뒤로 및 앞으로(⌃- 및
  ⌃⇧-), 브랜치, 빠르게 열기, 활동 개요가 있습니다.
- ‘옆에 열기’는 두 번째 문서를 첫 번째 문서 옆에 표시합니다. 재시동하거나 충돌한 후에도 모든 윈도우가 탭과 함께 복원되며, 저장하지 않은 텍스트가 있는 편집기는 그 텍스트와 함께 복원됩니다.
- 이미지, 오디오, 비디오, 서체, Office 문서는 Quick Look을 통해, PDF는 PDFKit을 통해 탭에서 열립니다.

## 편집기
- 구문 색상, 행 번호, 마지막 커밋 대비 변경 표시, 찾기 및 대치, 빠르게 열기(⌘P), 프로젝트 검색(⇧⌘F).
- 자동 들여쓰기, `.editorconfig`에 따른 탭 또는 공백, 괄호 쌍, 주석 전환, 접기, 행으로 이동, 공백 문자 표시, 줄 바꿈.
- 여러 커서: ⌥-클릭, ⌥-드래그로 열 선택, ⌘D로 다음 항목 선택.
- 파일의 인코딩, 바이트 순서 표시, 줄 끝 문자가 유지됩니다. 디스크에서 변경된 파일은 편집기에 저장하지 않은 텍스트가 없으면 다시 로드됩니다. 저장하지 않은 텍스트가 있으면 막대에 차이점과 병합이 제공됩니다.
- **편집 예측:** 입력하는 동안 제안이 회색으로 나타나며, Tab 키로 수락합니다. 제안은 설정에서 선택한 대로 GitHub Copilot 또는 Ollama나 LM Studio의 로컬 모델에서 제공됩니다. 로컬
  모델을 사용하면 코드가 이 Mac 밖으로 나가지 않습니다.

## 언어 서버
Go, Rust, TypeScript 및 JavaScript, Python, C, C++ 및 Objective-C, Swift, 셸 스크립트, JSON, YAML, CSS, HTML, TOML, Markdown,
Lua, 그리고 설정에서 추가한 사용자 서버. 진단, 호버, 자동 완성, 시그니처 도움말, 정의·유형 정의·구현으로 이동, 참조, 호출 계층 및 유형 계층, 이름 변경, 포맷, 시맨틱 색상, 접기, 개요; 행 안에
표시되는 유형과 매개변수 이름; 전구 아이콘 뒤의 빠른 수정 및 리팩토링(⌥⌘A); ⌥⌘O 또는 빠르게 열기의 `#`으로 찾는 프로젝트 심볼. TypeScript 프로젝트 자체의 `tsc`가 언어 서버 역할을 할 수
있으면 그것을 사용합니다.

## 디버거
중단점(조건부 포함), 단계별 실행, 스레드와 호출 스택, 인스펙터(⌥⌘I)의 변수와 감시식, 프로그램이 일시 정지된 동안 코드 옆에 표시되는 값, 일시 정지된 프레임에서 식을 평가하는 디버그 콘솔. Rust, C,
C++, Swift는 `lldb-dap`, Go는 `dlv`, JavaScript와 TypeScript는 JavaScript 디버거, Python은 debugpy를 통해 지원합니다. 프로젝트의
`.vscode/launch.json`을 읽습니다. 디버그 메뉴는 Xcode의 단축키를 사용합니다.

## 터미널
로그인 셸의 환경을 사용하는 탭 속 터미널로, Metal로 그려집니다. 이미지를 붙여넣거나 드롭하면 터미널에서 실행 중인 코딩 에이전트에 전달되거나, 저장된 사본의 경로가 붙여넣어집니다. ⌘-클릭으로 링크와 파일
이름을 엽니다. 터미널에서 시작한 개발 서버는 브라우저 탭에서 열 수 있습니다.

## Markdown
Markdown 파일은 옆에 미리보기를 표시한 상태로 열립니다(⇧⌘V). 수식, Mermaid, Graphviz, PlantUML 다이어그램, 폴더의 이미지도 표시됩니다. 포맷 메뉴로 굵게, 기울임꼴, 링크, 제목,
목록, 인용, 코드 블록을 지정할 수 있으며, Word나 웹 페이지에서 붙여넣은 텍스트는 Markdown으로 들어옵니다. **파일 › 내보내기**는 PDF, 단일 HTML 파일 또는 Word 문서로 저장합니다.
Splat이 설치되어 있으면 **파일 › Splat에서 열기**로 문서를 Splat에서 엽니다.

## 브라우저
주소 필드, 뒤로 및 앞으로, 검색, 사전 확인을 거치는 다운로드, Web Inspector를 갖춘 브라우저 탭.

## Git
Git 패널에서 파일 또는 개별 헝크의 스테이징과 폐기, 커밋, 커밋 후 푸시 또는 동기화, 브랜치, 스태시, 병합 충돌, 최근 커밋 그래프를 다룰 수 있습니다. Blame은 커서가 있는 행을 마지막으로 변경한
사람을 표시하거나, 파일 전체에 대해 열로 표시합니다. 버튼 하나로 AI가 커밋 메시지를 작성합니다. 차이점은 gitleaks가 시크릿을 찾지 못한 경우에만 전송되며, 모든 커밋도 시크릿이 있는지 검사합니다. AI
스레드는 별도의 Git 워크트리에서 작업할 수 있으며, 패널에 변경 내용이 표시되고 병합이나 체리픽으로 작업을 가져옵니다.

## CI
GitHub Actions와 GitLab CI, 그리고 GitHub Enterprise Server와 자체 관리형 GitLab도 지원합니다. 현재 브랜치의 실행, 잡, 로그; 실패한 잡, 단일 잡 또는
(GitHub에서) 전체 실행의 재실행, 수동 잡 시작이나 대기 중인 배포 승인, 새 파이프라인이나 수동으로 시작할 수 있는 워크플로 시작, 취소. 열려 있는 병합 요청 또는 풀 리퀘스트와 이슈도 같은 패널에
나열되며 브라우저 탭에서 열립니다. 실패한 잡의 로그는 외부 텍스트로 표시해 에이전트에 넘길 수 있습니다. 토큰은 키체인, `gh` 또는 `glab`, 로그인 셸의 환경에서 가져오거나 직접 입력합니다.

## AI
모든 에이전트는 같은 타임라인을 가진 AI 탭에서 작업합니다. 응답, 출력이 포함된 도구 호출, 권한 요청, 질문, 승인하고 의견을 남길 수 있는 계획, 할 일, 하위 에이전트, 백그라운드 작업이 표시되며, 탭
헤더의 두 버튼으로 실행 중인 하위 에이전트와 백그라운드 프로세스를 나열할 수 있습니다. 앱은 프롬프트마다 체크포인트를 저장하며, 변경 사항을 메시지별로 검토하고 되감을 수 있습니다. 새 스레드는 ‘수동’ 모드로
시작하며, 파괴적인 Git 명령은 절대 영구적으로 허용되지 않습니다. 활동 개요에는 실행 중인 모든 항목이 나열됩니다. 탭의 초록색 점은 작업 중인 세션을, 빨간색 점은 응답을 기다리는 세션을 나타내며, 다른 곳을
보고 있는 동안 세션이 끝나거나 대기하면 알림으로 알려 줍니다.
- **Claude**는 `claude` 명령을 그대로 사용하며 세션, 하위 에이전트, 백그라운드 작업, 컨텍스트, 사용량을 지원합니다.
- **ACP 에이전트:** Codex, Antigravity, OpenCode 및 요청 시 ACP 레지스트리의 다른 에이전트. 설치된 에이전트는 테스트된 버전으로 고정되며 체크섬으로 검증됩니다.
- **내장 에이전트:** Anthropic, OpenAI, Google Gemini, OpenRouter, Ollama, LM Studio 및 OpenAI나 Anthropic의 API를 지원하는 서버. 파일,
  검색, 명령, 진단, 웹 요청을 위한 도구를 갖추고 있으며, 키는 키체인에 보관됩니다.
- 스레드별 샌드박스 스위치로 에이전트의 명령이 할 수 있는 일을 에이전트가 지원하는 범위 내에서 제한합니다.
- 터미널 출력, 웹 페이지, CI 로그 같은 외부 텍스트는 신뢰할 수 없음으로 표시되어 에이전트에 전달됩니다.

## 받아쓰기
Lowspeak의 음성 인식으로 AI 메시지 필드와 편집기에 받아쓰기할 수 있습니다. 마이크 버튼, ⌃⌥D 또는 Dango가 활성 앱일 때 fn 키를 사용합니다. Lowspeak의 설정과 모델을 사용하며, 온라인
전사에는 OpenAI 또는 Groq 키가 필요합니다.

## 업데이트
앱은 Sparkle을 통해 스스로 업데이트합니다. 두 번째 실행 시 자동으로 확인해도 되는지 묻고, 동의하기 전에는 어떤 요청도 보내지 않습니다. **Dango › 업데이트 확인…**은 즉시 확인합니다.

## 손쉬운 사용
사이드바, 탭, AI 타임라인의 카드, Git 및 CI 행, 디버거, 터미널 텍스트에 VoiceOver 이름을 제공합니다. `keybindings.json`에서 변경할 수 있는 단축키로 모든 기능을 키보드로 제어할
수 있습니다. 대비 증가와 동작 줄이기를 지원하며, 오른쪽에서 왼쪽으로 쓰는 인터페이스에서도 코드 보기는 왼쪽에서 오른쪽으로 유지됩니다. 자세한 내용은 ACCESSIBILITY.md에 있습니다.

## 개인정보 보호
원격 측정, 분석, 충돌 보고서가 없습니다. 앱은 사용자가 시작한 작업에 대해서만 연결합니다. 사용하는 에이전트, 요청한 다운로드, 로그인한 CI 호스트, 선택한 경우 Copilot의 예측, 선택한 경우 온라인
전사, 여는 페이지, 허용한 후의 업데이트 확인이 이에 해당합니다. 키와 토큰은 macOS 키체인에 보관됩니다.

## 알려진 제한 사항
- 브라우저를 통한 CI 로그인은 꺼져 있습니다. `gh`, `glab`, 토큰 또는 환경 변수를 사용하십시오.
- 터미널, Git, 언어 서버, 에이전트가 이를 상속하게 되므로 앱은 App Sandbox 없이 실행됩니다. 폴더가 구성한 항목은 해당 폴더를 신뢰해야 실행됩니다. Antigravity와 OpenCode에는 앱이
  켤 수 있는 샌드박스가 없습니다.
- Claude의 사용량 수치와 컨텍스트 세부 내역은 실험적으로 표시된 프로토콜 일부에 의존하며, 해당 부분이 없으면 가려집니다. 대화 되감기는 Claude에서만 작동하며, 다른 에이전트에서는 코드만 되감깁니다.
- Gemini CLI는 제공되지 않습니다. Google이 개인 계정 로그인을 종료하고 Antigravity로 안내하기 때문입니다. 이전 Gemini 스레드는 계속 읽을 수 있습니다.
