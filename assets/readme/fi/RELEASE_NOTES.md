- Kun kuormitettu Mac lukee ohjelman tulosteen myöhässä, pääte huomaa silti, että ohjelma päättyi, ja säilyttää sen viimeiset rivit.

## Markdown
- Wordista tai verkkosivulta sijoitettu kaava, jossa on gravis-merkki (`` ` ``), pysyy kaavana eikä muutu koodiksi.
- Lihavoidun tai kursivoidun tekstin kuvat säilyttävät Word-viennissä sekä lihavoinnin että kursiivin.
- Tiedosto, jossa on yli 500 000 tyhjää taulukon solua, näyttää taulukkonsa tekstinä sen sijaan, että se veisi sekunteja ja gigatavuja muistia.
