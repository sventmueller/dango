## AI-välilehti
- `/resume` avaa yleiskatsauksen agentin aiemmista istunnoista tässä kansiossa; valittu istunto jatkuu omassa välilehdessään.
- Agentit ja Copilot saavat nyt tietää Dango-sovelluksen oikean version 0.0.0:n sijaan.

## Pääte
- Pääte toimii uudella näyttömoottorilla: se piirtää uudelleen vain muuttuneet rivit, ja sen historia vie vähemmän muistia, kun päätteessä oleva ohjelma on joutilaana.

## Välilehdet
- Valikosta + tai ⌘T:llä avattu välilehti ilmestyy välilehtipalkin loppuun eikä edessä olevan välilehden viereen.
