## Arborescence des fichiers
- Plusieurs lignes de l’arborescence des fichiers peuvent être sélectionnées avec ⇧-clic et ⌘-clic, et le menu contextuel sur l’une d’elles agit sur toutes : « Copier le chemin » et « Copier le chemin relatif » copient un chemin par ligne, « Afficher dans le Finder » les sélectionne ensemble dans le Finder et « Placer dans la corbeille » les y place toutes. « Renommer… » et les commandes qui ouvrent un seul fichier ne sont alors pas disponibles ; le menu sur une ligne hors de la sélection n’agit que sur cette ligne.
