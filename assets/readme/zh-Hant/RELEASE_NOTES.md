## AI 標籤頁
- 在視圖外停留三分鐘的 AI 標籤頁，會在工作階段閒置時釋放其 Claude 程序。對話內容和你輸入的文字仍會保留在標籤頁中，下一則提示詞會恢復該工作階段。當 Claude 正在工作、有提示詞在等待、有提問尚未回覆、子代理程式、背景任務或指令仍在執行，或 Remote Control 已開啟時，標籤頁會保留其程序。
- 結束代理程式時，也會結束它在獨立的程序群組或工作階段中啟動的指令；以前這些指令可能在代理程式結束後繼續執行。
- 時間軸會將新項目附加到結尾，而不再為先前的所有列重新建立索引。

## 速度
- 還原的視窗開啟得更快：沒有未儲存變更的檔案標籤頁，只有在移到最前方時才會載入其檔案。
- 面板處於隱藏狀態的專案搜尋會暫停，並在面板顯示時繼續。
- 編輯器的 Git 變更標記對每個檔案同一時間最多只執行一次比較；比較期間的編輯會合併為一次後續比較，而且只有在提交有所變更時，才會重新讀取檔案已提交的文字。
- 含有收合程式碼的檔案，其縮圖會為每個未收合的區段保留一個項目，而不再是每行一個。
