## 終端機
- 終端機現在來自 Dango 的姊妹終端機 App Tapa，帶來它新增的一切，同時 Dango 保留了其終端機以往的功能：將影像貼上給代理程式、瀏覽器標籤頁中的開發伺服器、⌘-按一下跳到編輯器。
- **顯示方式 › 顯示／隱藏輸入欄位**（終端機為焦點時按 ⌘I）會把指令列變成文字欄位，上方顯示檔案夾和 Git 分支。指令會依組成部分著色，Shell 無法執行的指令會加上紅色虛線底線。
- 建議會在你輸入時以灰色顯示，不論是否使用輸入欄位：來自你的歷史記錄、700 多個指令列工具的規格，以及專案，例如 git 分支、`package.json` 腳本，以及 make、just 和 cargo 目標。按 → 採用建議；Tab 會進行補全，有多個候選項目時會打開一個選單，繼續輸入即可篩選。建議絕不使用網路。
- 指令區塊：⌘↑ 和 ⌘↓ 會在提示符號之間跳轉，**編輯** 選單可選取、拷貝和儲存指令的輸出，書籤會標記行。開啟 **將指令標示為區塊** 後，直條會標出每個區塊，失敗的指令會被標示，區塊上的按鈕會顯示它的狀態和所花時間。
- **將區塊傳送給代理程式**（「編輯」選單和終端機的快速選單）會打開 AI 標籤頁，將目前區塊的指令列和輸出以「外部內容」附上。
- **尋找**（終端機為焦點時按 ⌘F）會以正規表示式、區分大小寫和全字比對搜尋整個歷史記錄；捲軸會標示出結果。
- 程式的通知（OSC 9 和 OSC 777）及其響鈴會在你看不到終端機時，在其標籤頁上顯示紅點；當其他 App 位於前方時，通知會傳送到 macOS。程式回報的進度（OSC 9;4）會以圓環顯示在其標籤頁上，並以進度列顯示在 Dock 圖像上。
- 連按兩下可整個選取 URL、路徑或雜湊值，按住 ⌥ 拖移可選取矩形範圍，**拷貝並保留格式** 會保留顏色和樣式，**使用鍵盤選取** 會用 Vim 的按鍵移動選取範圍。
- 會立即執行的多行貼上會先顯示出來，**Dango › 加密的鍵盤輸入** 可防止其他 App 讀取你在終端機中鍵入的內容。
- 除了網址、`mailto:` 和檔案以外的其他種類連結，終端機不再打開。

## 設定
- **設定 › 終端機** 可切換新終端機的輸入欄位、其 Vim 按鍵、建議、指令著色、未知指令的底線、指令區塊、立即拷貝所選內容、先顯示多行貼上，以及將 ⌥ 作為 Meta 鍵，最後一項是從「一般」移到這裡的。
