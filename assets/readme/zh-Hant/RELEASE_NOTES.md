## 速度與記憶體
- 代理程式啟動的所有項目，無論使用哪種語言，例如建置、測試、Shell 和 MCP 伺服器，都會在 macOS 的背景狀態下執行：優先順序最低，磁碟和網路存取受到限制。代理程式本身（包括 Claude 的子代理程式）以中等優先順序執行。滿載運作的代理程式不再拖慢 Dango；這也適用於 Software Factory 的代理程式。
- 回復的視窗只會啟動顯示出來的內容：位於其他標籤頁後方的 AI 標籤頁會在移到最前方或收到提示詞時才啟動其 CLI，瀏覽器、網站預覽和終端機標籤頁則在首次顯示時才載入頁面或啟動 Shell。
- 耗時較長的專案搜尋在執行期間不再反覆重繪所有結果。Software Factory、CI 記錄和「測試」面板在看不到時會減少工作；測試和除錯設定會在其面板首次顯示時才讀取，隱藏的「CI」和「容器」面板在顯示前不會讀取任何內容。
- 長時間的工作階段使用更少記憶體：已完成的差異只保留其卡片顯示的行，已回覆的權限請求會釋放其輸入內容，終端機的字符快取不再無限制增長，「檔案」和「Git」面板會釋放已不存在的列。
- 程式本身縮小了約 40%。

## 視窗與選單
- 關閉窗格時，其標籤頁會移到前一個窗格，若沒有則移到後一個窗格，而不再一併關閉。只有預覽所在的窗格和最後一個窗格會連同其標籤頁一起關閉。
- 「顯示方式」選單會依側邊欄圖像的順序列出各個面板。
- 「管理代理程式⋯」已從「+」選單中移除；它仍位於「代理程式」面板的「+ 新增工作階段」下方。

## 錯誤修正
- 「搜尋」面板中的「包含與排除檔案」不再於其箭頭旁顯示多餘的字母。
- 關閉規格的註解彈出式視窗不再導致當機。
