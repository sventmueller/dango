## 安全性
- 代理程式的回答、計畫和報告中、Markdown 預覽中以及 PDF 中的連結不再按一下就打開任何 App。網址會在瀏覽器標籤頁中打開，專案內的檔案會在編輯器標籤頁中打開；其他任何內容，例如其他位置的檔案、網路共享或其他 App 的連結，都會先詢問並顯示其指向的位置。
- 代理程式或 MCP 伺服器傳來的登入和 Remote Control 位址只有在是網址時才會打開。
- 包含的內容遠不止一個專案的檔案夾，例如個人專屬檔案夾、桌面、文件、下載項目或卷宗的根目錄，不再能被整體信任；請逐一信任其中的專案。信任詢問現在會說明信任也適用於其中的檔案夾。
- CI Token 和登入資訊絕不會透過明文 http 傳送到此 Mac 以外的伺服器；遠端位址以 `http://` 開頭的儲存庫會透過 https 查詢。
- 沒有 gitleaks 時，編輯預測會在程式碼傳送給此 Mac 以外的供應商之前等待，直到你選擇不經檢查傳送。專案自己的 gitleaks 設定不再能關閉檢查。
- 內建代理程式不再會被寫入獲准後才出現的連結引導到專案以外寫入；具有其他硬連結的檔案會得到一個獨立的檔案，而不是經由連結直接寫入。
- 語言伺服器的自動完成不再會讓編輯器停止回應，它對連結檔案的重新命名和刪除會作用於連結本身，而不是其指向的內容。
- 你附加到提示詞中的圖片會像其他地方一樣，由沙盒中的解碼服務進行解碼。
- 終端機中的程式只有在其終端機位於最前方時才能取代剪貼板，而且終端機會告知這一點。
- rust-analyzer 從固定了核對碼的版本安裝，而不是當時剛好最新的版本。

## 搜尋與導覽
- 「快速打開」會在沒有符合的檔案時給出提示，並顯示它搜尋的是檔案還是專案的符號。
- 專案的符號現在包含 TypeScript 和 JavaScript，無需打開它們的檔案。來自專案和你所用語言的完全符合項目會排在前面；來自程式庫和已安裝套件的符號會加上標記。
- 「顯示方式 › 搜尋」會將焦點移到搜尋欄位中。

## 編輯器
- 打開 Markdown 檔案並在旁邊顯示其預覽時，編輯器會保留焦點，因此「格式」選單立即可用。焦點位於側邊欄時，編輯器指令同樣可用。
- 行尾或其下方框中的建議會提示按 Tab 接受。
- 標籤頁總覽中同名的標籤頁現在可以區分，例如一個檔案和它在瀏覽器中的預覽。
- 「顯示方式」選單不再提供 macOS 內建的「隱藏標籤頁列」，Dango 的標籤頁並不使用它。

## 語言與除錯
- JSON 伺服器現在會檢查檔案，啟動後才註冊診斷的伺服器，例如 basedpyright 和 sourcekit-lsp，也會顯示其診斷。
- 在 pip 拒絕安裝到 Python 中的情況下（例如 Homebrew 的 Python），除錯器會提議將 debugpy 安裝到專案的虛擬環境中。
