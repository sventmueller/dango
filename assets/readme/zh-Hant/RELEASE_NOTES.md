## 工具列
- 從右起的新順序：「新增終端機」「新增 AI 對話」和「新增瀏覽器標籤頁」為一組，其左側是「向右分割」「向下分割」和輸入欄位開關，再往左是「快速打開」和「活動」。
- 輸入欄位開關可開啟或關閉前方終端機的輸入欄位，欄位開啟時以強調色顯示；前方沒有終端機時，開關呈灰色。
- 如果只安裝了一個代理程式，「新增 AI 對話」按一下即可開啟它；否則按一下會在選單中列出代理程式。按住按鈕一律顯示選單。
- 設定按鈕移到側邊欄底部更低的位置。

## 終端機
- 沒有輸入欄位時，你輸入的指令也會獲得與輸入欄位相同的顏色：指令、子指令、選項、變數和運算子，shell 無法執行的指令下方會出現紅色虛線底線。shell 自己設定的顏色會保留。
- 沒有輸入欄位時，輸入單字時建議列表會自動開啟。Return 會執行該行，Tab 或 → 會採用灰色建議；用 ↑ 或 ↓ 移動選擇後，它們會採用所選項目。Esc 會關閉該單字的列表，「設定 › 終端機」可將其關閉。
