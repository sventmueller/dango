## 輔助說明
- 「輔助說明」選單可前往 GitHub 上的專案：「回報問題⋯」會打開已填好 Dango 版本、macOS 版本和 Mac 類型的回報表單，「建議功能⋯」會在討論區開始一個新點子，「GitHub 上的 Dango」會打開儲存庫。

## 編輯器與終端機
- 編輯器與終端機現在以 13 點開始，與側邊欄、標籤列和 AI 標籤頁相同；你自行設定的大小會保留不變。
- 行號現在也會在游標旁標出最後一個換行之後的空白行，以及空白文件中唯一的一行。

## AI
- 背景程序尚未輸出任何內容時，其輸出按鈕不再打開空白檔案，而是提示尚無輸出；程序結束後則提示沒有任何輸出。再次點按會顯示目前的輸出，而不是先前的副本；先前沒有作用的 Codex 終端機，現在也可以用此按鈕顯示其輸出。
