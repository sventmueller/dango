## Ταχύτητα
- Ό,τι ξεκινά ένας πράκτορας, όπως builds, δοκιμές και κελύφη, εκτελείται με τη χαμηλότερη προτεραιότητα αντί να
  εκτελείται στην κατάσταση παρασκηνίου του macOS. Το Dango εξακολουθεί να προηγείται και οι πράκτορες πριν από ό,τι
  ξεκινούν, όμως τα builds τους χρησιμοποιούν ξανά τους πυρήνες επιδόσεων και την πλήρη ταχύτητα του δίσκου· η κατάσταση
  παρασκηνίου είχε μειώσει την απόδοσή τους σε περίπου ένα δέκατο ακόμη και σε ένα Mac που κατά τα άλλα ήταν αδρανές.

## Πράκτορες
- Η κουκκίδα μιας καρτέλας AI παραμένει πράσινη όσο εκτελείται ακόμη μια εντολή παρασκηνίου της συνεδρίας της, και η
  ειδοποίηση ότι μια συνεδρία ολοκληρώθηκε έρχεται μόνο αφού τελειώσει και η εργασία της στο παρασκήνιο.
