## Μνήμη
- Οι μακριές συνεδρίες πρακτόρων χρειάζονται πολύ λιγότερη μνήμη:
  - Το άνοιγμα μιας προηγούμενης συνεδρίας διαβάζει την καταγραφή της μία γραμμή τη φορά· μια συνεδρία με καταγραφή 100
    MB φτάνει πλέον το πολύ περίπου τα 20 MB αντί για 65 MB.
  - Μια ολοκληρωμένη κλήση εργαλείου κρατά μόνο ό,τι δείχνει η κάρτα της: τις πρώτες 400 γραμμές της εξόδου της, και όχι
    πλέον την ακατέργαστη είσοδο μόλις η κάρτα δείξει τα πεδία της. Το «N ακόμη γραμμές» εξακολουθεί να μετρά κάθε
    γραμμή.
  - Μια καρτέλα AI που μένει εκτός προβολής για 30 δευτερόλεπτα αφήνει τις κάρτες της, και όταν εμφανιστεί ξανά
    δημιουργεί όσες είναι ορατές, στο σημείο όπου βρισκόταν.
  - Αφού κλείσει μια καρτέλα ή ανοίξει μια προηγούμενη συνεδρία, το Dango επιστρέφει στο macOS τη μνήμη που
    απελευθέρωσε.
- Οι λίστες δεν μεγαλώνουν πλέον στη μνήμη όταν ανανεώνονται. Στο macOS 27 κάθε ανανέωση μιας λίστας με αναπτυσσόμενες
  γραμμές άφηνε πίσω της οριστικά ένα τρίγωνο ανάπτυξης, και κάθε ανανέωση άφηνε πίσω λίγο από κάθε γραμμή:
  - Οι λίστες CI, Container, Software Factory, Δοκιμές, Αποσφαλμάτωση, Git και Αναζήτηση, καθώς και η ιεραρχία κλήσεων,
    σχεδιάζουν μόνες τους τα βέλη τους.
  - Οι λίστες εκτός προβολής δεν ανανεώνονται πλέον· ενημερώνονται όταν εμφανιστούν.
  - Οι λίστες Συνεδρίες, CI, Software Factory και Container κρατούν τις γραμμές που δεν άλλαξαν, και το Git ανανεώνει
    μόνο τις γραμμές των αρχείων των οποίων άλλαξε η κατάσταση.
- Τα πλαίσια ενός κλειστού παραθύρου απελευθερώνονται μαζί του.

## Καρτέλες AI
- Η «Εμφάνιση εξόδου» μιας εντολής παρασκηνίου που γράφει η ίδια την έξοδό της σε αρχείο, όπως `make > build.log 2>&1`,
  δείχνει αυτό το αρχείο όταν το CLI δεν έχει τίποτα από την έξοδο.
