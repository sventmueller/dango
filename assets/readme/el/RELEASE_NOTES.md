## Δέντρο αρχείων
- Στο δέντρο αρχείων μπορούν να επιλεγούν πολλές γραμμές με ⇧-κλικ και ⌘-κλικ, και το μενού συντομεύσεων σε μία από αυτές ενεργεί σε όλες: η «Αντιγραφή διαδρομής» και η «Αντιγραφή σχετικής διαδρομής» αντιγράφουν μία διαδρομή ανά γραμμή, η «Εμφάνιση στο Finder» τις επιλέγει μαζί στο Finder και η «Μεταφορά στον Κάδο» τις μεταφέρει όλες. Η «Μετονομασία…» και οι εντολές που ανοίγουν ένα μόνο αρχείο δεν είναι τότε διαθέσιμες· το μενού σε μια γραμμή εκτός της επιλογής ενεργεί μόνο σε αυτήν.
