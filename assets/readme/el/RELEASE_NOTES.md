## Καρτέλες AI
- Μια καρτέλα AI που μένει εκτός προβολής για τρία λεπτά τερματίζει τη διεργασία Claude της όσο η συνεδρία είναι
  αδρανής. Η συζήτηση και ό,τι έχετε πληκτρολογήσει μένουν στην καρτέλα, και το επόμενο prompt συνεχίζει τη συνεδρία.
  Μια καρτέλα κρατά τη διεργασία της όσο το Claude εργάζεται, ένα prompt περιμένει, μια ερώτηση είναι ανοιχτή, ένας
  υποπράκτορας, μια εργασία παρασκηνίου ή μια εντολή εκτελείται ακόμη, ή το Remote Control είναι ενεργό.
- Ο τερματισμός ενός πράκτορα τερματίζει επίσης τις εντολές που ξεκίνησε σε δική τους ομάδα διεργασιών ή συνεδρία, οι
  οποίες παλιότερα μπορούσαν να συνεχίσουν να εκτελούνται και μετά από αυτόν.
- Το χρονολόγιο προσθέτει τις νέες καταχωρίσεις στο τέλος του αντί να ευρετηριάζει ξανά όλες τις προηγούμενες γραμμές.

## Ταχύτητα
- Τα παράθυρα που επαναφέρονται ανοίγουν γρηγορότερα: μια καρτέλα αρχείου χωρίς μη αποθηκευμένες αλλαγές φορτώνει το
  αρχείο της μόνο όταν έρθει στο προσκήνιο.
- Μια αναζήτηση στο έργο της οποίας το πλαίσιο είναι κρυφό μπαίνει σε παύση και συνεχίζει όταν εμφανιστεί το πλαίσιο.
- Οι σημάνσεις αλλαγών Git του επεξεργαστή εκτελούν το πολύ μία σύγκριση τη φορά ανά αρχείο· οι επεξεργασίες στο μεταξύ
  συγκεντρώνονται σε μία επόμενη σύγκριση, και το κείμενο του αρχείου στο commit διαβάζεται ξανά μόνο όταν έχει αλλάξει
  το commit.
- Ο μικροχάρτης ενός αρχείου με συμπτυγμένο κώδικα κρατά μία καταχώριση ανά αναπτυγμένο τμήμα αντί για μία ανά γραμμή.

## Αναζήτηση
- Το βέλος των φίλτρων ευθυγραμμίζεται με το βέλος της Αντικατάστασης ακριβώς από πάνω του.
