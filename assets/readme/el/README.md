# Dango

**Ο εγγενής επεξεργαστής για macOS για εργασία με πράκτορες κώδικα.**

Το Dango συγκεντρώνει τον κώδικα, τους πράκτορες που τον αλλάζουν και ό,τι τους περιβάλλει σε ένα παράθυρο ανά φάκελο: έναν επεξεργαστή με διακομιστές γλώσσας και προβλέψεις επεξεργασίας, τερματικά, ένα πρόγραμμα περιήγησης, Git, CI, έναν αποσφαλματωτή και νήματα AI με το Claude, το Codex, το Antigravity, το OpenCode ή έναν πράκτορα ενσωματωμένο στην εφαρμογή. Κάθε πράκτορας δουλεύει στο ίδιο χρονολόγιο, ρωτά πριν αλλάξει αρχεία ή εκτελέσει εντολές και αφήνει ένα σημείο ελέγχου πριν από κάθε prompt, ώστε να μπορείτε να ελέγξετε και να αναιρέσετε με επιστροφή ό,τι έκανε, μήνυμα προς μήνυμα. Τίποτα από όσα ρυθμίζει ένας φάκελος δεν εκτελείται πριν του δώσετε την εμπιστοσύνη σας, και το κείμενο από έξω φτάνει σε έναν πράκτορα σημασμένο ως μη αξιόπιστο. Υπαγορεύστε στον επεξεργαστή και στο πεδίο μηνύματος· η αναγνώριση ομιλίας μπορεί να μείνει στο Mac σας. Το Dango είναι γραμμένο σε Rust πάνω σε γνήσια στοιχεία ελέγχου του AppKit, χωρίς Electron, μιλά 35 γλώσσες και δεν έχει τηλεμετρία.

## Οι λειτουργίες με μια ματιά

- **Όλοι οι πράκτορες σε ένα χρονολόγιο.** Το Claude μέσω της δικής του εντολής `claude`, το Codex, το Antigravity και το OpenCode μέσω του Agent Client Protocol, περισσότεροι από το μητρώο ACP, και ένας πράκτορας ενσωματωμένος στην εφαρμογή για Anthropic, OpenAI, Google Gemini, OpenRouter, Ollama και LM Studio. Απαντήσεις, κλήσεις εργαλείων, αιτήματα αδειών, σχέδια, εκκρεμότητες, υποπράκτορες και εργασίες παρασκηνίου φαίνονται ίδια, όποιος πράκτορας κι αν εκτελείται.
- **Έλεγχος και επιστροφή.** Πριν από κάθε prompt το Dango κρατά ένα σημείο ελέγχου. Ό,τι άλλαξε ένας πράκτορας μπορεί να ελεγχθεί και να αναιρεθεί με επιστροφή ανά μήνυμα, και ένα νήμα μπορεί να δουλεύει σε δικό του worktree του Git και να παραδίδει τη δουλειά του με συγχώνευση ή cherry-pick.
- **Ένα παράθυρο ανά φάκελο.** Αρχεία, τερματικά, σελίδες του προγράμματος περιήγησης, νήματα AI, προβολές διαφορών και προεπισκοπήσεις είναι καρτέλες macOS αυτού του παραθύρου. Η πλαϊνή στήλη περιέχει τα Αρχεία, Αναζήτηση, Πράκτορες, Git, Δοκιμές, Αποσφαλμάτωση, CI και Container.
- **Ένας πραγματικός επεξεργαστής κώδικα.** Χρώματα σύνταξης, πολλαπλοί δρομείς, δίπλωμα, `.editorconfig`, διακομιστές γλώσσας για 17 γλώσσες με συμπλήρωση, μετάβαση στον ορισμό, αναφορές, μετονομασία, γρήγορες διορθώσεις και ιεραρχίες, και προβλέψεις επεξεργασίας από το GitHub Copilot ή από ένα τοπικό μοντέλο.
- **Αποσφαλματωτής, Git και CI ενσωματωμένα.** Σημεία διακοπής και εκτέλεση βήμα προς βήμα για Rust, C, C++, Swift, Go, JavaScript, TypeScript και Python· stage μεμονωμένων τμημάτων, branch, stash, διενέξεις και γράφημα commit· εκτελέσεις, job και αρχεία καταγραφής από GitHub Actions και GitLab CI.
- **Το τερματικό του Tapa.** Μπλοκ εντολών των οποίων την έξοδο αντιγράφετε, αποθηκεύετε ή δίνετε σε έναν πράκτορα, ένα πεδίο εισαγωγής με προτάσεις από το ιστορικό σας και το έργο, αναζήτηση σε όλο το ιστορικό, καθώς και γνωστοποιήσεις και πρόοδος από τα προγράμματα που εκτελούνται σε αυτό.
- **Προσεκτικό με τους φακέλους σας.** Ένας φάκελος που δεν έχει την εμπιστοσύνη σας δεν ξεκινά τίποτα: ούτε διεργασίες Git, ούτε διακομιστές γλώσσας, ούτε hook, ούτε πράκτορες. Οι καταστροφικές εντολές Git δεν επιτρέπονται ποτέ μόνιμα, και τα commit ελέγχονται για μυστικά.
- **Υπαγόρευση.** Μιλήστε στον επεξεργαστή και στο πεδίο μηνύματος, διαδικτυακά μέσω OpenAI ή Groq ή τοπικά με Whisper και Parakeet.
- **Εγγενές μέχρι το κόκαλο.** Παράθυρα, καρτέλες, μενού και γραμμές εργαλείων του AppKit, TextKit 2 για τον επεξεργαστή, Metal για το τερματικό, WebKit μόνο στην καρτέλα του προγράμματος περιήγησης. Η σκούρα εμφάνιση, η Αύξηση αντίθεσης και το VoiceOver λειτουργούν όπως σε κάθε εφαρμογή Mac.
- **Στη γλώσσα σας.** Η διεπαφή διατίθεται σε 35 γλώσσες: Αραβικά, Καταλανικά, Κινεζικά (απλοποιημένα), Κινεζικά (παραδοσιακά), Κροατικά, Τσεχικά, Δανικά, Ολλανδικά, Αγγλικά, Φινλανδικά, Γαλλικά, Γερμανικά, Ελληνικά, Εβραϊκά, Χίντι, Ουγγρικά, Ινδονησιακά, Ιταλικά, Ιαπωνικά, Κορεατικά, Μαλαισιανά, Νορβηγικά, Πολωνικά, Πορτογαλικά (Βραζιλία), Πορτογαλικά (Πορτογαλία), Ρουμανικά, Ρωσικά, Σλοβακικά, Σλοβενικά, Ισπανικά, Σουηδικά, Ταϊλανδικά, Τουρκικά, Ουκρανικά και Βιετναμέζικα.

## Απαιτήσεις

- macOS 14 Sonoma ή νεότερη έκδοση, σε Apple Silicon ή Intel. Το Dango αναπτύσσεται και δοκιμάζεται σε macOS 27.
- Για τα νήματα AI, ο πράκτορας που θέλετε να χρησιμοποιήσετε· δείτε [Πράκτορες AI](#πράκτορες-ai).
- Για τους διακομιστές γλώσσας και τους προσαρμογείς αποσφαλμάτωσης, που το Dango εγκαθιστά όταν το ζητήσετε: Go για τα gopls και `dlv`· Node.js για τους διακομιστές TypeScript, Python, JSON, YAML, CSS, HTML και shell και για τον αποσφαλματωτή JavaScript· τα Xcode Command Line Tools για τα clangd, sourcekit-lsp και `lldb-dap`. Το rust-analyzer λαμβάνεται από τις εκδόσεις του στο GitHub.
- Για τις προβλέψεις επεξεργασίας, μια συνδρομή GitHub Copilot (αρκεί η δωρεάν) ή ένα μοντέλο fill-in-the-middle στο Ollama ή στο LM Studio.

## Εγκατάσταση

**Από την εικόνα δίσκου.** Κάθε έκδοση είναι μια εικόνα δίσκου, `Dango-<version>.dmg`, με μία καθολική εφαρμογή για Apple Silicon και Intel, υπογεγραμμένη με Developer ID και επικυρωμένη από την Apple. Ανοίξτε την και σύρετε το Dango στον φάκελο Εφαρμογές. Ένα Homebrew Cask εγκαθιστά την ίδια εικόνα. Δεν έχει δημοσιευτεί ακόμη καμία έκδοση.

**Ενημερώσεις.** Το Dango από την εικόνα δίσκου διατηρείται ενημερωμένο μέσω του [Sparkle](https://sparkle-project.org). Στη δεύτερη εκκίνηση ρωτά αν μπορεί να ελέγχει μόνο του για ενημερώσεις· μέχρι να συμφωνήσετε, δεν κάνει κανένα αίτημα. Η εντολή **Dango › Έλεγχος για ενημερώσεις…** ελέγχει αμέσως. Οι ενημερώσεις είναι υπογεγραμμένες με το δικό κλειδί της εφαρμογής, το οποίο ελέγχει το Sparkle πριν εγκαταστήσει οτιδήποτε. Μια δική σας δόμηση δεν έχει πρόγραμμα ενημέρωσης.

**Από τον πηγαίο κώδικα.** Δείτε [Δόμηση από τον πηγαίο κώδικα](#δόμηση-από-τον-πηγαίο-κώδικα) και μετά μετακινήστε το `target/release/Dango.app` στο `/Applications`.

**Η εντολή τερματικού.** Η εντολή **Dango › Εγκατάσταση εντολής «dango»…** γράφει ένα μικρό σενάριο στο `~/.local/bin/dango`, χωρίς δικαιώματα διαχειριστή· το `~/.local/bin` πρέπει να βρίσκεται στο `PATH` σας. Έπειτα το `dango .` ανοίγει τον τρέχοντα φάκελο και το `dango file.rs` ένα αρχείο. Το Dango δεν αντικαθιστά ποτέ εκεί αρχείο που δεν έγραψε το ίδιο.

## Πρώτα βήματα

1. **Ανοίξτε έναν φάκελο** με ⌘O ή `dango <folder>`. Την πρώτη φορά, το Dango ρωτά αν τον εμπιστεύεστε (δείτε [Εμπιστοσύνη](#εμπιστοσύνη)).
2. **Η πλαϊνή στήλη** εναλλάσσεται μεταξύ των Αρχεία (⌘1), Αναζήτηση (⌘2), Πράκτορες (⌘3), Git (⌘4), Δοκιμές (⌘5), Αποσφαλμάτωση (⌘6), CI (⌘7) και Container (⌘8)· ένα δεξί κλικ αποκρύπτει όσα δεν χρησιμοποιείτε, και το ⌃⌘S συμπτύσσει την πλαϊνή στήλη.
3. **Κάθε έγγραφο είναι μια καρτέλα** του παραθύρου του φακέλου, οι ίδιες οι καρτέλες του macOS. Το «+» στο τέλος της γραμμής καρτελών και το ⌘T προσφέρουν νέο αρχείο, τερματικό, το πρόγραμμα περιήγησης και κάθε εγκατεστημένο πράκτορα, και σε δικό του worktree του Git· αν κρατήσετε πατημένο το «+», εμφανίζονται τα ίδια ως μενού.
4. **Το Γρήγορο άνοιγμα** με ⌘P βρίσκει αρχεία, και με `#` τα σύμβολα του έργου· το ⇧⌘F κάνει αναζήτηση και αντικατάσταση στο έργο.
5. **Μιλήστε με έναν πράκτορα** σε μια καρτέλα AI. Το ⌘Esc μεταφέρει την εστίαση του πληκτρολογίου στο πεδίο μηνύματός του και πίσω.
6. **Οι Ρυθμίσεις** με ⌘, περιέχουν τις καρτέλες Γενικά, Τερματικό, CI, Πράκτορες, Software Factory, Ενσωματωμένος πράκτορας, Διακομιστής γλώσσας, Υπαγόρευση και Πρόβλεψη.

Η γραμμή εργαλείων περιέχει το Πίσω και το Εμπρός στα σημεία όπου κάνατε αλλαγές (⌃- και ⌃⇧-), το branch, το Γρήγορο άνοιγμα και την επισκόπηση Δραστηριότητα, που παραθέτει ό,τι εκτελείται. Το **Άνοιγμα δίπλα** στο μενού συντομεύσεων ενός αρχείου δείχνει ένα δεύτερο έγγραφο δίπλα στο πρώτο. Μετά από επανεκκίνηση ή κατάρρευση, κάθε παράθυρο επανέρχεται με τις καρτέλες του, και οι επεξεργαστές με μη αποθηκευμένο κείμενο επανέρχονται μαζί με αυτό. Εικόνες, ήχος, βίντεο, γραμματοσειρές και έγγραφα Office ανοίγουν σε καρτέλα μέσω Quick Look, τα PDF μέσω PDFKit.

## Πράκτορες AI

| Πράκτορας | Πώς εκτελείται | Τι χρειάζεται |
|---|---|---|
| Claude | η εντολή `claude`, με απευθείας επικοινωνία μέσω του πρωτοκόλλου της stream-json | το `claude` εγκατεστημένο και με σύνδεση· το Dango αναζητά στο `PATH` του κελύφους σύνδεσης, στα `~/.local/bin`, `~/.claude/local`, `/opt/homebrew/bin` και `/usr/local/bin`. Η σύνδεση γίνεται μόνο στο ίδιο το `claude` |
| Codex | `codex-acp` μέσω του Agent Client Protocol (ACP) | Node.js και npm· το Dango εγκαθιστά το πακέτο σε καθορισμένη έκδοση όταν το ζητήσετε |
| Antigravity | `agy acp` | το δικό σας `agy` στο `PATH`, ή η λήψη σε καθορισμένη έκδοση, που εγκαθίσταται όταν το ζητήσετε |
| OpenCode | `opencode acp` | το δικό σας `opencode` στο `PATH`, ή η λήψη σε καθορισμένη έκδοση, που εγκαθίσταται όταν το ζητήσετε |
| Άλλοι πράκτορες ACP | από το μητρώο ACP, που ανακτάται μόνο όταν το ζητήσετε | ό,τι ορίζει η καταχώριση του μητρώου· οι καταχωρίσεις χωρίς άθροισμα ελέγχου εγκαθίστανται μόνο αφού επιβεβαιώσετε |
| Ενσωματωμένος πράκτορας | ενσωματωμένος στην εφαρμογή, με εργαλεία για αρχεία, αναζήτηση, εντολές, διαγνωστικά και αιτήματα ιστού | ένα κλειδί API για Anthropic, OpenAI, Google Gemini ή OpenRouter, που φυλάσσεται στην κλειδοθήκη· Ollama ή LM Studio σε αυτό το Mac χωρίς κλειδί· οποιοσδήποτε διακομιστής μιλά το API του OpenAI ή του Anthropic |

Οι **Ρυθμίσεις › Πράκτορες** δείχνουν ποιους πράκτορες έχει αυτό το Mac, εγκαθιστούν τους υπόλοιπους και τις ενημερώσεις τους, και ανοίγουν το μητρώο ACP. Οι πράκτορες που εγκαθιστά το Dango είναι κλειδωμένοι σε δοκιμασμένες εκδόσεις και ελέγχονται με τα δημοσιευμένα αθροίσματα ελέγχου τους (npm integrity ή SHA-256)· το Dango δεν εκτελεί κανένα πακέτο `npx` χωρίς έκδοση.

### Το χρονολόγιο

Κάθε πράκτορας δουλεύει σε μια καρτέλα AI με το ίδιο χρονολόγιο: απαντήσεις, κλήσεις εργαλείων με την έξοδό τους, αιτήματα αδειών, ερωτήσεις, σχέδια για έγκριση και σχολιασμό (⌥⌘K), εκκρεμότητες, υποπράκτορες και εργασίες παρασκηνίου. Δύο κουμπιά στην κεφαλίδα της καρτέλας παραθέτουν τους υποπράκτορες και τις διεργασίες παρασκηνίου που εκτελούνται. Αναφέρετε ένα αρχείο, το `@terminal` ή το `@browser` για να δώσετε στον πράκτορα το περιεχόμενό του. Μια πράσινη κουκκίδα στην καρτέλα δείχνει μια συνεδρία που δουλεύει, μια κόκκινη μια συνεδρία που σας περιμένει, και μια γνωστοποίηση σας ενημερώνει όταν τελειώσει ή περιμένει ενώ κοιτάτε αλλού. Για το Claude, η γραμμή κατάστασης δείχνει τα συμφραζόμενα και τη χρήση.

### Άδειες και λειτουργίες

Τα νέα νήματα ξεκινούν στη λειτουργία «Χειροκίνητα»: ο πράκτορας ρωτά πριν αλλάξει αρχεία ή εκτελέσει εντολές. Για καταστροφικές εντολές Git (`push --force`, `reset --hard`, `clean -fd`) το Dango δεν προσφέρει «Να επιτρέπεται πάντα». Ο ενσωματωμένος πράκτορας κρατά τους κανόνες «Να επιτρέπεται πάντα» ανά έργο, τους παραθέτει στις **Ρυθμίσεις › Ενσωματωμένος πράκτορας** και ρωτά για καταστροφικές εντολές Git κάθε φορά, ό,τι κι αν είναι αποθηκευμένο· το Claude και οι πράκτορες ACP κρατούν τέτοιους κανόνες στη δική τους διαμόρφωση. Με το «Επιτρέπονται όλα» και χωρίς sandbox, το νήμα δείχνει μια μόνιμη προειδοποίηση.

### Σημεία ελέγχου και worktree

Πριν από κάθε prompt το Dango κρατά ένα σημείο ελέγχου, ως commit κάτω από το `refs/ide-checkpoints/` στο αποθετήριο του έργου, ή στον δικό του φάκελο για έργο χωρίς Git· ένα κανονικό push ή fetch δεν τα μεταφέρει ποτέ. Ό,τι άλλαξε ένας πράκτορας μπορεί να ελεγχθεί και να αναιρεθεί με επιστροφή ανά μήνυμα. Ένα νήμα μπορεί να δουλεύει σε δικό του worktree του Git: το πλαίσιο Git δείχνει τι άλλαξε και ενσωματώνει τη δουλειά με συγχώνευση ή cherry-pick.

## Επεξεργαστής

- **Χρώματα σύνταξης, αριθμοί γραμμών και σημάδια αλλαγών** σε σχέση με το τελευταίο commit, εύρεση και αντικατάσταση, Γρήγορο άνοιγμα (⌘P) και αναζήτηση στο έργο (⇧⌘F).
- **Η εσοχή** ακολουθεί το αρχείο και το `.editorconfig`: στηλοθέτες ή κενά, αυτόματη εσοχή, ζεύγη αγκυλών.
- **Πολλαπλοί δρομείς:** ⌥-κλικ, ⌥-σύρσιμο για στήλη, ⌃⇧↑ και ⌃⇧↓, ⌘D για την επόμενη εμφάνιση.
- **Δίπλωμα** (⌥⌘← και ⌥⌘→, με ⇧ για όλα), εναλλαγή σχολίων (⌘/), μετάβαση σε γραμμή (⌃G), ορατά κενά και αναδίπλωση γραμμών (⌥Z).
- **Τα αρχεία διατηρούν την κωδικοποίησή τους**, το σημάδι σειράς byte και τις αλλαγές γραμμής. Ένα αρχείο που άλλαξε στον δίσκο φορτώνεται ξανά όταν ο επεξεργαστής δεν έχει μη αποθηκευμένο κείμενο· διαφορετικά, μια γραμμή προσφέρει τις διαφορές και συγχώνευση.
- **Προβλέψεις επεξεργασίας.** Καθώς πληκτρολογείτε, εμφανίζεται μια πρόταση με γκρι, και το Tab την αποδέχεται. Προέρχεται από το GitHub Copilot ή από ένα τοπικό μοντέλο στο Ollama ή στο LM Studio, όπως επιλέξετε στις **Ρυθμίσεις › Πρόβλεψη**· ένα τοπικό μοντέλο κρατά τον κώδικά σας σε αυτό το Mac.
- **Μικροχάρτης και σταθερή κύλιση** (μενού Επεξεργαστής): μια στενή εικόνα ολόκληρου του αρχείου δίπλα στο κείμενο, και οι γραμμές κεφαλίδας των μπλοκ στα οποία βρίσκεται η πάνω γραμμή, σταθερές πάνω από αυτήν.
- **Διαγνωστικά στο τέλος γραμμής** (μενού Προβολή): το σοβαρότερο μήνυμα κάθε γραμμής μετά από ένα δευτερόλεπτο αδράνειας, με ένα σύμβολο για τη σοβαρότητά του.
- **Ζωντανή προεπισκόπηση στατικών σελίδων:** η εντολή Επεξεργαστής › Άνοιγμα σε καρτέλα περιήγησης παρέχει τις σελίδες ενός φακέλου που έχει την εμπιστοσύνη σας από το ίδιο το Dango και φορτώνει ξανά την καρτέλα όταν αποθηκεύεται ένα αρχείο.
- Το **Prettier** μορφοποιεί JavaScript, TypeScript, CSS, HTML, Markdown και άλλα, όπου το ρυθμίζει το έργο, με το `node_modules/.bin/prettier` του ίδιου του έργου· η ρύθμιση `formatter` επιλέγει τον μορφοποιητή ανά γλώσσα.
- **Λειτουργία Vim** (Επεξεργαστής › Λειτουργία Vim): λειτουργίες Normal, Insert, Visual και Replace, μετρητές, τελεστές με κινήσεις και αντικείμενα κειμένου, `.`, καταχωρητές, σημάδια και μακροεντολές. Τα `u` και ⌃R χρησιμοποιούν την αναίρεση του επεξεργαστή, και ένα πέρασμα εισαγωγής είναι ένα βήμα. Τα `"+` και `"*` είναι το πρόχειρο· η ρύθμιση `vimClipboard` κάνει και τον ανώνυμο καταχωρητή πρόχειρο. Τα `/`, `?`, `n`, `N`, `*`, `:s` και `:%s` αναζητούν με τις κανονικές εκφράσεις της Rust, όχι με τα μοτίβα του Vim: χωρίς `\v`, και `\b` αντί για `\<` και `\>`. Οι εντολές Ex είναι οι `:w`, `:q`, `:wq`, `:x`, `:noh` και `:<line>`. Στη λειτουργία Normal το Vim παίρνει το ⌃G από τη μετάβαση σε γραμμή.
- **Συγχρονισμός ρυθμίσεων** μέσω ενός φακέλου στο iCloud Drive (**Ρυθμίσεις › Γενικά**): οι ρυθμίσεις και οι συντομεύσεις σας έρχονται μαζί σας στα άλλα Mac σας· διαδρομές, τοπικές διευθύνσεις και συγκαταθέσεις μένουν στο καθένα χωριστά.

## Διακομιστές γλώσσας

Go, Rust, TypeScript και JavaScript, Python, C, C++ και Objective-C, Swift, σενάρια shell, JSON, YAML, CSS, HTML, TOML, Markdown και Lua, καθώς και δικοί σας διακομιστές από τις **Ρυθμίσεις › Διακομιστής γλώσσας**. Το Dango εγκαθιστά έναν διακομιστή όταν το ζητήσετε, στον δικό του φάκελο εργαλείων, και χρησιμοποιεί το `tsc` ενός έργου TypeScript όταν μπορεί να λειτουργήσει ως διακομιστής γλώσσας.

Τι προσφέρουν: διαγνωστικά (τα ⌘' και ⇧⌘' μετακινούνται ανάμεσά τους), πληροφορίες κατά την αιώρηση (⌃⌘I), συμπλήρωση (⌥Esc), βοήθεια υπογραφής, μετάβαση στον ορισμό (⌃⌘J), ορισμό τύπου και υλοποίηση, αναφορές (⌃⇧⌘F), ιεραρχίες κλήσεων και τύπων (⌃⇧⌘H), μετονομασία (⌃⌘E), μορφοποίηση (⌥⇧F), σημασιολογικά χρώματα, δίπλωμα και διάρθρωση (⇧⌘O)· τύποι και ονόματα παραμέτρων μέσα στη γραμμή· γρήγορες διορθώσεις και αναδιαρθρώσεις πίσω από μια λάμπα (⌥⌘A)· τα σύμβολα του έργου με ⌥⌘O.

Εκτός από τον διακομιστή του ίδιου του αρχείου, το ESLint ελέγχει JavaScript και TypeScript σε έργα που το χρησιμοποιούν, με τις γρήγορες διορθώσεις του, και οι συντομογραφίες του Emmet εμφανίζονται στη συμπλήρωση για HTML, CSS και JSX. Το Dango εγκαθιστά και τα δύο όταν το ζητήσετε· οι **Ρυθμίσεις › Γενικά** διορθώνουν τα προβλήματα του ESLint κατά την αποθήκευση, αν το θέλετε.

Ένα σύμβολο σε κάθε δοκιμή στο περιθώριο την εκτελεί, το ⌥-κλικ την αποσφαλματώνει και ένα αποτυχημένο assert επισημαίνει τη γραμμή του. Οι δοκιμές εκτελούνται μόνο σε έμπιστους φακέλους, αφού εκτελούν τον κώδικα του έργου· το `cargo test` παραθέτει τις δοκιμές του μόνο όταν το ζητήσετε, καθώς η απαρίθμηση μεταγλωττίζει κάθε πρόγραμμα δοκιμών.

## Τερματικό

Τα τερματικά ανοίγουν ως καρτέλες (**Αρχείο › Νέο τερματικό**, ⌃\`) με το κέλυφος σύνδεσης και το περιβάλλον του. Το τερματικό είναι του [Tapa](https://github.com/sventmueller/tapa), με δικό του πυρήνα VT, σχεδιασμένο με Metal: xterm και VT520 με το πρωτόκολλο πληκτρολογίου του Kitty, συνδέσμους OSC 8, συγχρονισμένη έξοδο, truecolor και αναφορά ποντικιού, στο μέγεθος κειμένου του επεξεργαστή και με τα φωτεινά και σκοτεινά χρώματα του Tapa. Η ενσωμάτωση κελύφους του για zsh, bash και fish ρυθμίζεται μόνη της χωρίς να αγγίζει τα αρχεία διαμόρφωσής σας και σας ακολουθεί όταν συνδέεστε με `ssh` σε άλλο υπολογιστή. Μετά από επανεκκίνηση, ένα τερματικό επανέρχεται ως νέο κέλυφος στον φάκελο όπου βρισκόταν, μόνο σε φακέλους που έχουν την εμπιστοσύνη σας· ό,τι έδειχνε δεν επανέρχεται.

- **Μπλοκ εντολών.** Κάθε εντολή και η έξοδός της σχηματίζουν ένα μπλοκ. Τα ⌘↑ και ⌘↓ μεταβαίνουν μεταξύ προτροπών. Η **Επιλογή μπλοκ** (⇧⌘A), η **Αντιγραφή εξόδου** (⌥⌘C), η **Αποθήκευση εξόδου…** (⌥⌘S) και η **Σύμπτυξη/ανάπτυξη μπλοκ** (⇧⌘↩) δρουν στο τρέχον μπλοκ· η **Προσθήκη/αφαίρεση σελιδοδείκτη** (⇧⌘M) σημαδεύει μια γραμμή, και τα ⇧⌘↑ και ⇧⌘↓ μεταβαίνουν μεταξύ σελιδοδεικτών. Με ενεργή τη **Σήμανση εντολών ως μπλοκ**, μια μπάρα στο περιθώριο δείχνει κάθε μπλοκ, οι εντολές που απέτυχαν επισημαίνονται, η εντολή που εκτελείται μένει στην κορυφή όσο κυλά η έξοδός της, και κουμπιά πάνω από το μπλοκ κάτω από τον δείκτη δείχνουν την κατάστασή του, τη διάρκειά του και τις ίδιες ενέργειες.
- **Η Αποστολή μπλοκ στον πράκτορα** (μενού Επεξεργασία και μενού συντομεύσεων του τερματικού) ανοίγει μια νέα καρτέλα AI με τη γραμμή εντολών και την έξοδο του τρέχοντος μπλοκ συνημμένες ως Εξωτερικό περιεχόμενο (δείτε [Εμπιστοσύνη](#εμπιστοσύνη)), και ένα πρόχειρο μήνυμα που ρωτά για την αιτία όταν η εντολή απέτυχε, όπως κάνει το αρχείο καταγραφής ενός αποτυχημένου job του CI. Δεν έχει συντόμευση μέχρι να δώσετε μία στο `terminal.blockToAgent` στο `keybindings.json`.
- **Το πεδίο εισαγωγής.** Η **Προβολή › Εμφάνιση/απόκρυψη πεδίου εισαγωγής** (⌘I) μετατρέπει τη γραμμή εντολών σε πεδίο κειμένου στο κάτω μέρος του τερματικού, με τον φάκελο και το branch του Git από πάνω του· τα νέα τερματικά ακολουθούν την τελευταία σας επιλογή. Το Return στέλνει όλο το πεδίο στο κέλυφος. Χρειάζεται την ενσωμάτωση κελύφους και παραμερίζει για προγράμματα πλήρους οθόνης όπως το vim, το htop ή το claude.
- **Οι προτάσεις** εμφανίζονται με γκρι αμέσως μετά από ό,τι πληκτρολογείτε, μέσα στο πεδίο εισαγωγής και χωρίς αυτό: από το ιστορικό σας, με τον φάκελο, το branch και τον κωδικό εξόδου με τους οποίους εκτελέστηκε κάθε εντολή, από προδιαγραφές για περισσότερα από 700 εργαλεία γραμμής εντολών, και από το έργο, όπως branch του git, κοντέινερ docker, σενάρια του `package.json` και στόχοι make, just και cargo. Το → αποδέχεται μια πρόταση· το Tab συμπληρώνει και, με πολλές υποψήφιες, ανοίγει ένα μενού που φιλτράρεται καθώς πληκτρολογείτε. Πριν πληκτρολογήσετε, το πεδίο μπορεί να προτείνει την εντολή που συνήθως ακολουθεί. Οι εντολές χρωματίζονται ανάλογα με τα μέρη τους, και μια εντολή που το κέλυφός σας δεν μπορεί να εκτελέσει παίρνει μια κόκκινη διακεκομμένη υπογράμμιση. Οι προτάσεις δεν χρησιμοποιούν ποτέ το δίκτυο και ξεκινούν προγράμματα μόνο από το `PATH` του κελύφους σύνδεσης.
- **Η Εύρεση** (⌘F, ⌘G και ⇧⌘G όταν ένα τερματικό έχει την εστίαση) αναζητά σε όλο το ιστορικό, με κανονικές εκφράσεις, διάκριση πεζών-κεφαλαίων και ολόκληρες λέξεις, και μετρά τα αποτελέσματα· η γραμμή κύλισης σημειώνει τα αποτελέσματα, τις προτροπές και τις εντολές που απέτυχαν.
- **Επιλογή και αντιγραφή.** Ένα διπλό κλικ επιλέγει ένα URL, μια διαδρομή, ένα hash ή μια διεύθυνση IP ολόκληρα, και η μεταφορά με ⌥ επιλέγει ένα ορθογώνιο. Η **Επιλογή με το πληκτρολόγιο** (⇧⌘C) μετακινεί μια επιλογή με τα πλήκτρα του Vim, η **Αντιγραφή με μορφοποίηση** (⇧⌥⌘C) διατηρεί χρώματα και στυλ. Ένα πρόγραμμα μπορεί να αντιγράψει μέσω OSC 52 μόνο όσο το τερματικό του έχει την εστίαση του πληκτρολογίου, και το τερματικό το δηλώνει· κανένα πρόγραμμα δεν διαβάζει το πρόχειρο.
- **Επικόλληση.** Κείμενο που θα εκτελούσε μια εντολή στην αλλαγή γραμμής του, ή περιέχει χαρακτήρες ελέγχου, εμφανίζεται πρώτα σε ένα παράθυρο διαλόγου, εκτός αν το πρόγραμμα το διαβάζει ως bracketed paste. Η επικόλληση μιας εικόνας την παραδίδει σε έναν πράκτορα κώδικα που εκτελείται στο τερματικό και τη διαβάζει ο ίδιος από το πρόχειρο, ή επικολλά τη διαδρομή ενός αντιγράφου αποθηκευμένου στις κρυφές μνήμες· μέσω `ssh` το τερματικό λέει γιατί δεν το κάνει. Τα αρχεία που αποτίθενται σε ένα τερματικό, μαζί και οι εικόνες, φτάνουν ως διαδρομές σε εισαγωγικά· μια εικόνα που αποτίθεται από αλλού, όπως από μια ιστοσελίδα, ακολουθεί τον δρόμο μιας επικολλημένης.
- **Σύνδεσμοι.** Το ⌘-κλικ ανοίγει μια διεύθυνση ιστού στην καρτέλα του προγράμματος περιήγησης, έναν σύνδεσμο `mailto:` στο Mail και ένα όνομα αρχείου, και με τη γραμμή και τη στήλη του, στον επεξεργαστή του Dango· οι σύνδεσμοι εντοπίζονται ακόμη και χωρίς OSC 8. Σύνδεσμοι άλλων ειδών δεν ανοίγουν.
- **Διακομιστές ανάπτυξης.** Όταν ένα πρόγραμμα στο τερματικό ξεκινά έναν διακομιστή ανάπτυξης, μια μπάρα πάνω από το τερματικό αναφέρει τη διεύθυνσή του, και το **Άνοιγμα σε καρτέλα περιήγησης** τον ανοίγει εκεί.
- **Γνωστοποιήσεις και πρόοδος.** Το κουδούνι και μια γνωστοποίηση που ζητά ένα πρόγραμμα (OSC 9 και OSC 777) βάζουν την κόκκινη κουκκίδα στην καρτέλα του τερματικού όσο δεν το βλέπετε· όσο μια άλλη εφαρμογή είναι μπροστά, η γνωστοποίηση πηγαίνει και στο macOS, και ένα κλικ πάνω της φέρνει πίσω το τερματικό. Η πρόοδος που αναφέρει ένα πρόγραμμα (OSC 9;4) εμφανίζεται ως δακτύλιος στην καρτέλα του και ως γραμμή στο εικονίδιο του Dock.
- **Η Ασφαλής πληκτρολόγηση** (**Dango › Ασφαλής πληκτρολόγηση**) εμποδίζει άλλες εφαρμογές να διαβάζουν ό,τι πληκτρολογείτε σε ένα τερματικό· ενεργοποιείται επίσης μόνη της όσο ένα πρόγραμμα ζητά συνθηματικό.
- **Πλήκτρα.** Το ⌘K καθαρίζει το τερματικό (**Επεξεργασία › Εκκαθάριση τερματικού**)· τα ⌃C και Esc πηγαίνουν στο πρόγραμμα που εκτελείται σε αυτό. Οι εντολές του τερματικού βρίσκονται στα μενού Επεξεργασία και Προβολή, και οι συντομεύσεις τους δρουν μόνο όσο ένα τερματικό έχει την εστίαση του πληκτρολογίου, έτσι τα ⌘I, ⌘↑ ή ⌘F κρατούν τη σημασία τους στον επεξεργαστή. Το μενού συντομεύσεων ανοίγει επίσης ένα **Νέο τερματικό εδώ** και κλείνει το τερματικό με το **Κλείσιμο περιοχής**.

Οι **Ρυθμίσεις › Τερματικό** ενεργοποιούν και απενεργοποιούν το πεδίο εισαγωγής για νέα τερματικά, τα πλήκτρα Vim του, τις προτάσεις, τον χρωματισμό των εντολών, την υπογράμμιση των άγνωστων, τα μπλοκ εντολών, την άμεση αντιγραφή της επιλογής, την πρώτη εμφάνιση των επικολλήσεων πολλών γραμμών και το ⌥ ως μετα-πλήκτρο.

## Πρόγραμμα περιήγησης

Μια καρτέλα προγράμματος περιήγησης με πεδίο διεύθυνσης (⌘L), Πίσω και Εμπρός (⌘[ και ⌘]), επαναφόρτωση (⌘R), αναζήτηση, λήψεις που ρωτούν πρώτα, και τον Web Inspector. Το `@browser` δίνει τη σελίδα σε έναν πράκτορα, σημασμένη ως κείμενο από έξω.

## Git

Το πλαίσιο Git κάνει stage και απόρριψη αρχείων ή μεμονωμένων τμημάτων, κάνει commit, commit και push ή συγχρονισμό, αλλάζει και δημιουργεί branch, κρατά stash, επιλύει διενέξεις συγχώνευσης και σχεδιάζει ένα γράφημα των πρόσφατων commit. Το Blame δείχνει ποιος άλλαξε τελευταίος τη γραμμή όπου βρίσκεται ο δρομέας, ή μια στήλη για όλο το αρχείο. Ένα κουμπί γράφει το μήνυμα commit με AI· οι διαφορές αποστέλλονται μόνο αφού το gitleaks δεν βρει μυστικά σε αυτές, και κάθε commit ελέγχεται επίσης για μυστικά.

## CI

GitHub Actions και GitLab CI, επίσης GitHub Enterprise Server και αυτοδιαχειριζόμενο GitLab:

- εκτελέσεις, job και αρχεία καταγραφής του τρέχοντος branch·
- επανεκτέλεση αποτυχημένων job, ενός μεμονωμένου job ή, στο GitHub, μιας ολόκληρης εκτέλεσης· εκκίνηση χειροκίνητων job ή έγκριση αναπτύξεων σε αναμονή· εκκίνηση νέου pipeline ή workflow που μπορεί να ξεκινήσει χειροκίνητα· ακύρωση·
- τα ανοιχτά pull requests ή merge requests και τα issues, που ανοίγουν στην καρτέλα του προγράμματος περιήγησης·
- το αρχείο καταγραφής ενός αποτυχημένου job, που δίνεται σε έναν πράκτορα σημασμένο ως κείμενο από έξω.

Το token προέρχεται από την κλειδοθήκη, το `gh` ή το `glab`, το περιβάλλον του κελύφους σύνδεσης, ή είναι αυτό που εισάγετε στις **Ρυθμίσεις › CI**.

## Container

Το πλαίσιο Container εμφανίζει τα έργα Compose του Docker με τις υπηρεσίες τους, μεμονωμένα container, image και volume, και ακολουθεί τα συμβάντα του Docker τη στιγμή που συμβαίνουν. Ένα αρχείο Compose του φακέλου εμφανίζεται ως έργο ακόμη και πριν υπάρξει κάποιο από τα container του. Τα container ξεκινούν, σταματούν και επανεκκινούνται· τα αρχεία καταγραφής τους και ένα shell ανοίγουν σε καρτέλες τερματικού, και μια δημοσιευμένη θύρα ανοίγει στην καρτέλα του προγράμματος περιήγησης. Η διαγραφή ενός container, ενός image ή ενός volume, καθώς και η εκκαθάριση αχρησιμοποίητων δεδομένων, ζητούν πρώτα επιβεβαίωση. Οι εντολές up, down και pull του Compose εκτελούνται μόνο σε έμπιστους φακέλους, αφού το Compose δομεί και εκτελεί ό,τι περιγράφει το έργο. Το μενού του πλαισίου επιλέγει το Docker context του παραθύρου χωρίς να αλλάζει αυτό που χρησιμοποιούν τα shell σας· οι ίδιες εντολές βρίσκονται στο μενού Container. Απαιτείται η γραμμή εντολών `docker`, Docker 24.0.6 ή νεότερο.

## Markdown

- **Προεπισκόπηση.** Ένα αρχείο Markdown ανοίγει με την προεπισκόπησή του δίπλα· η εντολή **Προβολή › Εμφάνιση/απόκρυψη προεπισκόπησης δίπλα** (⇧⌘V) την κλείνει και την ανοίγει, και οι **Ρυθμίσεις › Γενικά** απενεργοποιούν την αυτόματη προεπισκόπηση. Η προεπισκόπηση σχεδιάζει τύπους, διαγράμματα Mermaid, Graphviz και PlantUML και τις εικόνες του φακέλου· εικόνες από τον ιστό φορτώνονται μόνο σε φάκελο που έχει την εμπιστοσύνη σας ή αφού τις ζητήσετε στην προεπισκόπηση.
- **Μενού Μορφή:** έντονα (⌘B), πλάγια (⌘I), διακριτή διαγραφή (⇧⌘X), κώδικας (⌥⇧⌘C), σύνδεσμος (⇧⌘K), επικεφαλίδες 1–3 (⌥⌘1–⌥⌘3), λίστες με κουκκίδες και αριθμημένες λίστες, εργασίες, παραθέσεις και μπλοκ κώδικα. Κάθε εντολή λειτουργεί ως εναλλαγή, στην επιλογή ή στις γραμμές, και αποτελεί ένα βήμα αναίρεσης.
- **Επικόλληση.** Κείμενο από το Word ή από ιστοσελίδα φτάνει ως Markdown, και οι εικόνες του ως αρχεία δίπλα στο έγγραφο· το ⌥⇧⌘V επικολλά απλό κείμενο.
- **Εξαγωγή.** Η εντολή **Αρχείο › Εξαγωγή** γράφει PDF, ένα μεμονωμένο αρχείο HTML με τις εικόνες του μέσα, ή έγγραφο Word. Οι εικόνες από τον ιστό συμπεριλαμβάνονται μόνο από φάκελο που έχει την εμπιστοσύνη σας.
- **Άνοιγμα στο Splat.** Όπου είναι εγκατεστημένο το [Splat](https://github.com/sventmueller/splat), η εντολή **Αρχείο › Άνοιγμα στο Splat** και τα μενού συντομεύσεων του δέντρου αρχείων και των καρτελών ανοίγουν εκεί το έγγραφο, αφού το αποθηκεύσουν.

## Υπαγόρευση

Υπαγορεύστε στο πεδίο μηνύματος μιας καρτέλας AI ή στον επεξεργαστή: με το κουμπί μικροφώνου εκεί, την εντολή **Επεξεργασία › Έναρξη υπαγόρευσης** (⌃⌥D) ή το πλήκτρο fn (κρατήστε το πατημένο για εγγραφή, πατήστε το δύο φορές για να συνεχιστεί η εγγραφή). Η αναγνώριση ομιλίας είναι αυτή του [Lowspeak](https://github.com/sventmueller/lowspeak)· το ίδιο το Lowspeak δεν χρειάζεται να είναι εγκατεστημένο.

- **Οι Ρυθμίσεις › Υπαγόρευση** ορίζουν τη λειτουργία και το μοντέλο (διαδικτυακά με OpenAI ή Groq, τοπικά με Whisper ή Parakeet), τη γλώσσα, τη μετεπεξεργασία, το μικρόφωνο και το δικό σας λεξιλόγιο.
- **Τα τοπικά μοντέλα** λαμβάνονται από το Hugging Face όταν επιλέξετε ένα, με ένδειξη προόδου και δυνατότητα ακύρωσης. Αποθηκεύονται στους φακέλους που χρησιμοποιεί το Lowspeak, ώστε κάθε εφαρμογή να χρησιμοποιεί ό,τι λήφθηκε από την άλλη. Ένα τοπικό μοντέλο κρατά την εγγραφή σε αυτό το Mac.
- **Η διαδικτυακή μεταγραφή** χρειάζεται κλειδί OpenAI ή Groq, το οποίο το Dango κρατά σε δικό του στοιχείο της κλειδοθήκης.
- **Από το Lowspeak.** Αν το Lowspeak έχει ρυθμιστεί διαφορετικά από τις προεπιλογές, η καρτέλα Υπαγόρευση προσφέρει μία φορά να μεταφέρει τις ρυθμίσεις του, και τα κλειδιά του κατόπιν αιτήματος· το macOS ρωτά πριν το Dango διαβάσει ένα κλειδί (επιλέξτε «Να επιτρέπεται» και όχι «Να επιτρέπεται πάντα»).
- **Άδειες.** Το macOS ζητά άδεια για το μικρόφωνο στην πρώτη υπαγόρευση. Το πλήκτρο fn λειτουργεί όσο το Dango είναι η ενεργή εφαρμογή και το Lowspeak δεν εκτελείται· χρειάζεται την άδεια Προσβασιμότητας, την οποία το Dango ζητά μετά την πρώτη υπαγόρευση, ποτέ κατά την εκκίνηση.

## Εμπιστοσύνη

Ένας φάκελος μπορεί να κάνει προγράμματα να εκτελεστούν μόλις ξεκινήσει κάτι μέσα του: hook του Git και ρυθμίσεις του αποθετηρίου όπως το `core.fsmonitor`, διακομιστές γλώσσας από το `node_modules`, hook πρακτόρων, `.mcp.json`. Την πρώτη φορά που ανοίγετε έναν φάκελο, το Dango ρωτά αν τον εμπιστεύεστε.

- **Αξιόπιστος:** το Git, οι διακομιστές γλώσσας, οι αποσφαλματωτές, οι πράκτορες και το CI εκτελούνται για αυτόν τον φάκελο και για ό,τι βρίσκεται κάτω από αυτόν.
- **Περιορισμένος:** μπορείτε να διαβάζετε και να επεξεργάζεστε· τα σημάδια αλλαγών στον επεξεργαστή προέρχονται από απευθείας ανάγνωση του `.git`. Τίποτα από όσα ρυθμίζει ο φάκελος δεν ξεκινά. Τα πλαίσια Git, CI και AI το αναφέρουν και προσφέρουν να δώσετε την εμπιστοσύνη σας στον φάκελο.

Κείμενο που δεν προέρχεται από εσάς μπορεί να περιέχει οδηγίες που στοχεύουν να κατευθύνουν έναν πράκτορα (prompt injection). Γι’ αυτό η έξοδος ενός τερματικού (`@terminal` ή ένα μπλοκ εντολής που δίνεται σε πράκτορα), μια σελίδα του προγράμματος περιήγησης (`@browser`), ένα αρχείο καταγραφής CI που δίνεται σε πράκτορα, ένα αρχείο εκτός του έργου και μεγαλύτερο κείμενο επικολλημένο από ιστοσελίδα στέλνονται σημασμένα: η ετικέτα γράφει «Εξωτερικό περιεχόμενο», και ο πράκτορας λαμβάνει το κείμενο με την επισήμανση ότι είναι μη αξιόπιστα δεδομένα των οποίων τις οδηγίες δεν πρέπει να ακολουθήσει. Οι ιστοσελίδες του ενσωματωμένου πράκτορα έρχονται με την ίδια επισήμανση. Το επικολλημένο κείμενο θεωρείται ότι προέρχεται από ιστοσελίδα όταν το πρόγραμμα περιήγησης το δηλώνει στο πρόχειρο, όπως κάνουν το Safari, το Chrome και το Firefox· κείμενο από αλλού, καθώς και μια σύντομη φράση λίγων λέξεων, παραμένει δικό σας.

## Sandbox

Το ίδιο το Dango εκτελείται χωρίς το App Sandbox, επειδή θα το κληρονομούσε κάθε πρόγραμμα που ξεκινά: τα τερματικά, το Git, οι διακομιστές γλώσσας και οι πράκτορες δεν θα μπορούσαν να λειτουργήσουν. Αντί γι’ αυτό, κάθε νήμα AI έχει έναν διακόπτη sandbox, απενεργοποιημένο από προεπιλογή. Τι περιορίζει εξαρτάται από τον πράκτορα, και η επεξήγηση του διακόπτη το αναφέρει:

| Πράκτορας | Με ενεργοποιημένο το sandbox |
|---|---|
| Claude | οι εντολές shell εκτελούνται στο δικό του sandbox του Claude· τα εργαλεία του για αρχεία και ιστό όχι |
| Codex | οι εντολές και οι αλλαγές γράφουν μόνο μέσα στο έργο, χωρίς δίκτυο |
| Ενσωματωμένος πράκτορας | τα αρχεία, τα αιτήματα ιστού και οι εντολές μένουν μέσα στο έργο και στους επιτρεπόμενους φακέλους, χωρίς δίκτυο (`sandbox-exec`) |
| Antigravity, OpenCode | κανένα sandbox που να μπορεί να ενεργοποιήσει το Dango |

## Εμφάνιση και προσβασιμότητα

- **Η σκούρα εμφάνιση** ακολουθεί το σύστημα· η **Αύξηση αντίθεσης** και η **Μείωση κίνησης** τηρούνται.
- **Το VoiceOver** ονομάζει την πλαϊνή στήλη, τις καρτέλες, τις κάρτες του χρονολογίου AI, τις γραμμές Git και CI και τον αποσφαλματωτή, διαβάζει τις γραμμές του τερματικού και ανακοινώνει νέα έξοδο. Τα σημεία διακοπής δεν διακρίνονται ποτέ μόνο από το χρώμα.

## Απόρρητο και ασφάλεια

- **Χωρίς τηλεμετρία,** χωρίς αναλύσεις, χωρίς αναφορές κατάρρευσης που στέλνονται οπουδήποτε. Τα σφάλματα πηγαίνουν στο αρχείο καταγραφής του συστήματος (Console.app, κάτω από το όνομα της εφαρμογής).
- **Το δίκτυο μόνο για ό,τι ξεκινάτε εσείς:** οι πράκτορες που χρησιμοποιείτε, ο καθένας με τη δική του υπηρεσία· το μητρώο ACP και οι λήψεις πρακτόρων, διακομιστών γλώσσας, προσαρμογέων αποσφαλμάτωσης και μοντέλων υπαγόρευσης όταν τις ζητάτε· οι hosts CI στους οποίους συνδέεστε· οι προβλέψεις επεξεργασίας από το Copilot αν το επιλέξατε· οι πάροχοι του ενσωματωμένου πράκτορα· η διαδικτυακή μεταγραφή αν την επιλέξατε· οι σελίδες που ανοίγετε στην καρτέλα του προγράμματος περιήγησης· και ο έλεγχος για ενημερώσεις μόλις τον επιτρέψετε.
- **Κώδικας φεύγει από το Mac** μόνο όπου επιλέξατε μια υπηρεσία γι’ αυτόν: έναν πράκτορα, τις προβλέψεις του Copilot, ένα μήνυμα commit γραμμένο από AI. Οι διαφορές για ένα μήνυμα commit αποστέλλονται μόνο αφού το gitleaks δεν βρει μυστικά σε αυτές.
- **Τα κλειδιά και τα token** μένουν στην κλειδοθήκη του macOS, ποτέ σε αρχείο ρυθμίσεων. Κλειδιά άλλων εφαρμογών, όπως του Lowspeak, διαβάζονται μόνο όταν συμφωνήσετε, και μόνο μία φορά.
- **Λήψεις σε καθορισμένες εκδόσεις.** Οι πράκτορες, οι διακομιστές γλώσσας και οι προσαρμογείς αποσφαλμάτωσης που εγκαθιστά το Dango είναι κλειδωμένοι σε δοκιμασμένες εκδόσεις και ελέγχονται με τα αθροίσματα ελέγχου τους.
- **Υπογραφή κώδικα** με το Hardened Runtime· οι ενημερώσεις εγκαθίστανται μόνο με τη δική υπογραφή της εφαρμογής.

## Πού βρίσκονται τα δεδομένα

Το `<id>` είναι το αναγνωριστικό πακέτου (bundle identifier), `local.agentide` για την έκδοση κυκλοφορίας (`local.agentide.debug` για δομήσεις αποσφαλμάτωσης). Δεν περιέχει το εμφανιζόμενο όνομα, οπότε μια μετονομασία διατηρεί όλα τα δεδομένα.

| Θέση | Περιεχόμενο |
|---|---|
| `~/Library/Application Support/<id>/` | `settings.json`, `state.json`, `keybindings.json`, `trust.json`, `terminal-history.sqlite` (το ιστορικό εντολών των τερματικών)· `threads/` (η λίστα του πλαισίου AI), `agent-threads/` (συνομιλίες του ενσωματωμένου πράκτορα), `layouts/` (καρτέλες ανά έργο), `recovery/` (μη αποθηκευμένοι επεξεργαστές μετά από κατάρρευση), `checkpoints/` (για φακέλους χωρίς Git), `worktrees/`, `agents/` και `tools/` (εγκατεστημένοι πράκτορες, διακομιστές γλώσσας και προσαρμογείς αποσφαλμάτωσης), `task-output/` |
| `~/Library/Caches/<id>/` | επικολλημένες εικόνες, σενάρια ενσωμάτωσης κελύφους, το μητρώο ACP· μπορεί να διαγραφεί |
| `~/Library/Logs/<id>/dictation/` | τα αρχεία καταγραφής της υπαγόρευσης |
| `~/Library/Application Support/Lowspeak` και `FluidAudio` | τοπικά μοντέλα υπαγόρευσης, κοινά με το Lowspeak |
| `~/Library/WebKit/<id>/` | cookies και δεδομένα ιστοτόπων της καρτέλας του προγράμματος περιήγησης |
| `<project>/.dango/settings.json` | οι δικές ρυθμίσεις του έργου |
| το αποθετήριο Git του έργου | σημεία ελέγχου, ως commit κάτω από το `refs/ide-checkpoints/`· ένα κανονικό push ή fetch δεν τα μεταφέρει ποτέ |
| κλειδοθήκη, υπηρεσία `<id>` | κλειδιά API του ενσωματωμένου πράκτορα και της υπαγόρευσης, token CI |
| `~/.local/bin/dango` | η εντολή τερματικού, αν την εγκαταστήσατε |

Το Claude κρατά τις δικές του συνεδρίες στο `~/.claude/projects`· το Dango τις διαβάζει για να συνεχίσει μια συνεδρία αλλά δεν τις αλλάζει.

## Γνωστοί περιορισμοί

- **Χωρίς App Sandbox** για την ίδια την εφαρμογή, επειδή θα το κληρονομούσαν τα τερματικά, το Git, οι διακομιστές γλώσσας και οι πράκτορες· ένας φάκελος πρέπει να έχει την εμπιστοσύνη σας πριν εκτελεστεί οτιδήποτε ρυθμίζει. Το Antigravity και το OpenCode δεν έχουν sandbox που να μπορεί να ενεργοποιήσει το Dango.
- **Τα στοιχεία χρήσης και η ανάλυση των συμφραζομένων του Claude** βασίζονται σε τμήματα του πρωτοκόλλου του που χαρακτηρίζονται πειραματικά, και αποκρύπτονται όταν λείπουν.
- **Η επιστροφή της συνομιλίας** λειτουργεί μόνο με το Claude· για τους άλλους πράκτορες επιστρέφει μόνο ο κώδικας.
- **Η σύνδεση στο CI μέσω του προγράμματος περιήγησης** είναι απενεργοποιημένη· χρησιμοποιήστε `gh`, `glab`, ένα token ή το περιβάλλον.
- **Δεν εμφανίζονται εικόνες μέσα στο τερματικό:** γραφικά Kitty, Sixel και εικόνες iTerm2 δεν προβάλλονται.
- **Το Gemini CLI δεν προσφέρεται:** η Google τερμάτισε τη σύνδεσή του με προσωπικό λογαριασμό και παραπέμπει στο Antigravity. Τα παλαιότερα νήματα Gemini παραμένουν αναγνώσιμα.

## Δόμηση από τον πηγαίο κώδικα

Χρειάζεστε:

- macOS 14 ή νεότερη έκδοση με τα Xcode Command Line Tools (`xcode-select --install`)· το ίδιο το Xcode δεν χρειάζεται.
- Rust όπως το ορίζει το `rust-toolchain.toml`. Το `rust` του Homebrew δομεί για τον επεξεργαστή αυτού του Mac· η καθολική δόμηση μιας έκδοσης χρειάζεται το rustup με τους στόχους `aarch64-apple-darwin` και `x86_64-apple-darwin`.
- Αντίγραφα των [splat](https://github.com/sventmueller/splat), [lowspeak](https://github.com/sventmueller/lowspeak) και [tapa](https://github.com/sventmueller/tapa) δίπλα σε αυτό (`../splat`, `../lowspeak`, `../tapa`), το καθένα στο branch του `main`· ο χώρος εργασίας παίρνει crates από αυτά μέσω διαδρομής, το τερματικό από το Tapa.
- cmake, για κάθε δόμηση με υπαγόρευση (`make run`, `make build`, `make release`), που δομεί το whisper.cpp. Το `make check` δομεί χωρίς αυτό.

| Εντολή | Τι κάνει |
|---|---|
| `make run` | δομεί την εφαρμογή αποσφαλμάτωσης (`target/debug/Dango Debug.app`) και την ανοίγει |
| `make build` | δομεί την εφαρμογή κυκλοφορίας (`target/release/Dango.app`), υπογεγραμμένη με τοπικό πιστοποιητικό που δημιουργεί η πρώτη δόμηση στην κλειδοθήκη σύνδεσης· διατηρεί το `Cargo.toml` αμετάβλητο |
| `make lint` | μορφοποίηση και clippy· οι προειδοποιήσεις την κάνουν να αποτύχει |
| `make check` | `lint`, μετά όλα τα τεστ· δεν χρειάζεται κλειδοθήκη, παράθυρο ή δίκτυο |
| `make test` | `check`, μετά το αυτοτέστ `probe` και τον έλεγχο προσβασιμότητας, από αριστερά προς τα δεξιά και από δεξιά προς τα αριστερά, στην πραγματική εφαρμογή |
| `make perf` | οι χρονικοί προϋπολογισμοί, σε δόμηση κυκλοφορίας· έχει νόημα μόνο σε Mac που κατά τα άλλα είναι αδρανές |
| `make release` | μια δοκιμαστική εκτέλεση της κυκλοφορίας στο `target/release-dry-run/`, υπογεγραμμένη με το τοπικό πιστοποιητικό· δεν στέλνει τίποτα πουθενά |
| `make release-notarized` | `check`, μετά η ίδια η κυκλοφορία στο `dist/`: υπογραφή Developer ID, επικύρωση (notarization), η ροή ενημερώσεων υπογεγραμμένη με το δικό κλειδί της εφαρμογής· διατηρεί το `Cargo.toml` αμετάβλητο |
| `make deploy` | σε καθαρό `main`, με ή χωρίς σφραγίδα CI: επικυρώνει την επόμενη έκδοση, κάνει commit το `Cargo.toml`, ανεβάζει τα αρχεία της έκδοσης, κάνει push τον κώδικα και την ετικέτα έκδοσης, μαζί με την πράσινη σφραγίδα CI αν υπάρχει, και έπειτα δημοσιεύει μόνο του την έκδοση |

Η έκδοση αποσφαλμάτωσης και η έκδοση κυκλοφορίας είναι ξεχωριστές εφαρμογές με δικές τους ρυθμίσεις και δεδομένα. Η δόμηση, τα τεστ, τα αυτοτέστ, η κυκλοφορία και οι κανόνες που ακολουθεί ο κώδικας περιγράφονται στο [docs/development.md](../../../docs/development.md), οι αποφάσεις πίσω από αυτά στο [docs/plan.md](../../../docs/plan.md). Οι σημειώσεις έκδοσης είναι το [RELEASE_NOTES.md](../../../RELEASE_NOTES.md), μεταφρασμένο δίπλα σε κάθε README στο `assets/readme/<language>/`.
