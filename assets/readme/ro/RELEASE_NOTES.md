## Dimensiunile fontului
- O opțiune nouă, „Dimensiune font în bara laterală și file”, stabilește dimensiunea barei laterale, a pictogramelor
  ei și a barelor de file între 10 și 18 puncte. Fiecare panou al barei laterale, bara de pictograme din stânga,
  titlurile filelor ferestrei și barele de file proprii ale zonelor cresc și se micșorează proporțional: textul,
  pictogramele, rândurile și spațiul dintre ele. Ferestrele deschise se adaptează imediat.
- Dimensiunea fontului în editor și terminal ajunge acum imediat și la editoarele deschise, cu stilurile Markdown și
  numerele de linie ale acestora, iar previzualizarea Markdown crește și se micșorează în aceeași proporție.
- Antetul unei file IA urmează dimensiunea fontului din fila IA, ca și cronologia, câmpul de mesaj și linia de stare
  ale acesteia.

## IA
- Sesiunile Codex își listează subagenții și terminalele în fundal în spatele celor două butoane din antetul filei,
  așa cum fac sesiunile Claude; cererile de permisiune ale unui subagent și butonul său de oprire funcționează
  separat.
- Butonul care afișează doar discuția se află acum între butonul proceselor în fundal și marcaj.
