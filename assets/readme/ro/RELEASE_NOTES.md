## Filă IA
- `/resume` deschide o prezentare a sesiunilor anterioare ale agentului în acest dosar; sesiunea aleasă continuă într-o filă proprie.
- Agenții și Copilot primesc acum versiunea reală a Dango în loc de 0.0.0.

## Terminal
- Terminalul rulează pe un nou motor de afișare: redesenează doar liniile modificate, iar istoricul său ocupă mai puțină memorie cât timp programul din el este inactiv.

## File
- O filă deschisă din meniul + sau cu ⌘T apare la sfârșitul barei de file în loc să apară lângă cea din față.
