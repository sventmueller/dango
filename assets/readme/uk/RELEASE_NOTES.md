## Панель інструментів
- Новий порядок справа: «Новий термінал», «Новий ШІ-чат» і «Нова вкладка браузера» в одній групі, ліворуч від них «Розділити праворуч», «Розділити вниз» і перемикач поля введення, далі «Швидко відкрити» та «Активність».
- Перемикач поля введення вмикає і вимикає поле термінала на передньому плані та має колір акценту, поки поле ввімкнене; без термінала на передньому плані він неактивний.
- Якщо встановлено лише одного агента, «Новий ШІ-чат» відкриває його одним клацанням; інакше клацання показує агентів у меню. Якщо втримувати кнопку, меню показується завжди.
- Кнопка параметрів розташована нижче, біля нижнього краю бічної панелі.

## Термінал
- Без поля введення команда, яку ви вводите, отримує ті самі кольори, що й у полі: команда, підкоманди, параметри, змінні й оператори, а під командою, яку оболонка не може виконати, зʼявляється червоне пунктирне підкреслення. Кольори, які задає сама оболонка, зберігаються.
- Без поля введення список підказок відкривається сам, коли ви вводите слово. Return виконує рядок, Tab або → приймають сіру підказку; після ↑ або ↓ вони приймають вибраний елемент. Esc закриває список для цього слова, а «Параметри › Термінал» вимикає його.
