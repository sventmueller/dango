## Вкладки ШІ
- Вкладка ШІ, яка три хвилини лишається поза полем зору, відпускає свій процес Claude, поки сеанс простоює. Діалог і те,
  що ви ввели, лишаються у вкладці, а наступний запит відновлює сеанс. Вкладка зберігає свій процес, поки Claude працює,
  запит чекає в черзі, є відкрите запитання, ще працює субагент, фонова задача чи команда або ввімкнено Remote Control.
- Завершення агента завершує й команди, які він запустив у власній групі процесів або власному сеансі; раніше вони могли
  його пережити.
- Хронологія додає нові записи в кінець, а не індексує заново всі попередні рядки.

## Швидкість
- Відновлені вікна відкриваються швидше: вкладка файлу без незбережених змін завантажує свій файл лише тоді, коли
  виходить на передній план.
- Пошук у проєкті, панель якого прихована, призупиняється й продовжується, коли панель зʼявляється.
- Позначки змін Git у редакторі виконують для кожного файлу щонайбільше одне порівняння за раз; зміни, внесені під час
  нього, обʼєднуються в одне наступне порівняння, а закомічений текст файлу перечитується лише тоді, коли змінився
  коміт.
- Мінікарта файлу зі згорнутим кодом зберігає один запис на кожну розгорнуту ділянку, а не на кожен рядок.
