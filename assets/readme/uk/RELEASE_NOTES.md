Це перший випуск Dango — нативного редактора для macOS для роботи з агентами програмування. Редактор, термінали,
браузер, Git, CI, налагоджувач і ШІ-чати ділять одне вікно на папку. Програму написано на Rust поверх AppKit; WebKit
використовується лише у вкладці браузера. Інтерфейс доступний 35 мовами.

## Вимоги
- macOS 14 або новіша, на Apple silicon або Intel.
- Для ШІ-чатів — вибраний вами агент: Claude потребує команди `claude` з виконаним входом; Codex потребує Node.js, а
  програма на ваш запит установлює його пакет закріпленої версії; Antigravity і OpenCode використовують ваш власний
  `agy` чи `opencode` або завантаження закріпленої версії; власний агент потребує ключа API або Ollama чи LM Studio на
  цьому Mac.
- Мовні сервери й адаптери налагодження встановлюються на ваш запит. gopls і `dlv` потребують Go; сервери для
  TypeScript, Python, JSON, YAML, CSS, HTML і shell та налагоджувач JavaScript потребують Node.js; clangd, sourcekit-lsp
  і `lldb-dap` постачаються з Xcode Command Line Tools.
- Передбачення під час редагування потребують підписки GitHub Copilot (підійде й безкоштовна) або моделі
  fill-in-the-middle в Ollama чи LM Studio.

## Вікно
- Кожен файл, термінал, сторінка браузера, ШІ-чат, diff і попередній перегляд — це вкладка macOS у вікні папки. «+» в
  кінці панелі вкладок і ⌘T пропонують новий файл, термінал, браузер і кожного встановленого агента, також у власному
  git worktree.
- Бічна панель перемикається між розділами Файли, Пошук, Агенти, Git, Налагодити і CI (⌘1–⌘6); клацанням правою кнопкою
  можна сховати ті, якими ви не користуєтеся. На панелі інструментів — назад і вперед місцями, які ви редагували (⌃- і
  ⌃⇧-), гілка, Швидко відкрити й огляд Активність.
- «Відкрити поруч» показує другий документ поруч із першим. Після перезапуску чи збою кожне вікно повертається зі своїми
  вкладками, а редактори з незбереженим текстом — разом із цим текстом.
- Зображення, аудіо, відео, шрифти й документи Office відкриваються у вкладці через Quick Look, PDF — через PDFKit.

## Редактор
- Підсвічування синтаксису, номери рядків, позначки змін відносно останнього коміту, пошук і заміна, Швидко відкрити
  (⌘P) і пошук у проєкті (⇧⌘F).
- Автоматичні відступи, табуляція чи пробіли згідно з `.editorconfig`, парні дужки, перемикання коментарів, згортання,
  перехід до рядка, видимі пробіли й перенесення рядків.
- Кілька курсорів: ⌥-клацання, ⌥-перетягування для стовпця, ⌘D для наступного входження.
- Файли зберігають кодування, мітку порядку байтів і закінчення рядків. Файл, змінений на диску, перезавантажується,
  якщо в редакторі немає незбереженого тексту; інакше панель пропонує відмінності та злиття.
- **Передбачення під час редагування:** поки ви друкуєте, сірим зʼявляється пропозиція; Tab приймає її. Пропозиції
  надходять від GitHub Copilot або від локальної моделі в Ollama чи LM Studio — що ви виберете в параметрах; локальна
  модель залишає ваш код на цьому Mac.

## Мовні сервери
Go, Rust, TypeScript і JavaScript, Python, C, C++ і Objective-C, Swift, shell-скрипти, JSON, YAML, CSS, HTML, TOML,
Markdown і Lua, а також власні сервери з параметрів. Діагностика, підказки при наведенні, автодоповнення, довідка щодо
сигнатур, перехід до визначення, визначення типу й реалізації, посилання, ієрархії викликів і типів, перейменування,
форматування, семантичні кольори, згортання та структура; типи й назви параметрів усередині рядка; швидкі виправлення й
рефакторинги за лампочкою (⌥⌘A); символи проєкту через ⌥⌘O або `#` у Швидко відкрити. Власний `tsc` проєкту TypeScript
використовується, якщо він може працювати як мовний сервер.

## Налагодження
Точки зупину, зокрема з умовами, покрокове виконання, потоки з їхніми стеками викликів, змінні й контрольні вирази в
Інспекторі (⌥⌘I), значення поруч із кодом, поки програму призупинено, і консоль налагодження, що обчислює вирази в
призупиненому кадрі. Rust, C, C++ і Swift через `lldb-dap`, Go через `dlv`, JavaScript і TypeScript через налагоджувач
JavaScript, Python через debugpy. Файл `.vscode/launch.json` проєкту зчитується. Меню «Налагодити» використовує
скорочення клавіш Xcode.

## Термінал
Термінали у вкладках із середовищем оболонки входу, відмальовані за допомогою Metal. Вставлене чи перетягнуте зображення
передається агентові програмування, що працює в терміналі, або вставляється шлях до збереженої копії. ⌘-клацання
відкриває посилання й імена файлів. Сервер розробки, запущений терміналом, можна відкрити у вкладці браузера.

## Markdown
Файл Markdown відкривається з попереднім переглядом поруч (⇧⌘V), з формулами, діаграмами Mermaid, Graphviz і PlantUML та
зображеннями з папки. Меню «Формат» для жирного, курсиву, посилань, заголовків, списків, цитат і блоків коду; текст,
вставлений із Word чи вебсторінки, надходить як Markdown. **Файл › Експортувати** записує PDF, один файл HTML або
документ Word. Якщо встановлено Splat, **Файл › Відкрити в Splat** відкриває документ у ньому.

## Браузер
Вкладка браузера з полем адреси, кнопками назад і вперед, пошуком, завантаженнями з попереднім запитанням і
Веб-інспектором.

## Git
Панель Git з індексуванням і скасуванням змін у цілих файлах чи окремих фрагментах, комітами, комітом із push або
синхронізацією, гілками, stash, конфліктами злиття та графом останніх комітів. Blame показує, хто востаннє змінив рядок
під курсором, або стовпець для всього файлу. Кнопка пише повідомлення коміту за допомогою ШІ; diff надсилається лише
після того, як gitleaks не знайшов у ньому секретів, і кожен коміт так само перевіряється на секрети. ШІ-чат може
працювати у власному git worktree; панель показує, що він змінив, і переносить роботу через злиття або cherry-pick.

## CI
GitHub Actions і GitLab CI, також GitHub Enterprise Server і GitLab на власному сервері: запуски, завдання й журнали
поточної гілки; повторний запуск невдалих завдань, окремого завдання або (на GitHub) усього запуску, запуск ручних
завдань або схвалення розгортань, що очікують, запуск нового pipeline чи workflow, який можна запустити вручну, і
скасування. Відкриті merge request або pull request та issues показано в тій самій панелі, і вони відкриваються у
вкладці браузера. Журнал невдалого завдання можна передати агентові з позначкою тексту ззовні. Токен береться з вʼязки,
з `gh` чи `glab`, із середовища оболонки входу, або ви вводите його самі.

## ШІ
Кожен агент працює у вкладці ШІ з однаковою хронологією: відповіді, виклики інструментів з їхнім виводом, запити
дозволів, запитання, плани для схвалення й коментування, списки справ, субагенти й фонові задачі; дві кнопки в заголовку
вкладки показують запущені субагенти й фонові процеси. Перед кожним запитом програма створює контрольну точку; зміни
можна переглянути й відкотити для кожного повідомлення окремо. Нові чати починаються в режимі «Вручну», а деструктивні
команди git ніколи не дозволяються назавжди. Огляд Активність показує все, що працює. Зелена крапка на вкладці позначає
сеанс, що працює, червона — сеанс, що чекає на вас, а сповіщення повідомляє, коли сеанс завершився чи чекає, поки ви
дивитеся деінде.
- **Claude** через незмінену команду `claude`, із сеансами, субагентами, фоновими задачами, контекстом і використанням.
- **ACP-агенти:** Codex, Antigravity і OpenCode, а на ваш запит — інші з реєстру ACP; встановлені агенти закріплено за
  перевіреними версіями й звірено з їхніми контрольними сумами.
- **Власний агент:** Anthropic, OpenAI, Google Gemini, OpenRouter, Ollama, LM Studio і сервери з API OpenAI або
  Anthropic, з інструментами для файлів, пошуку, команд, діагностики й вебзапитів; ключі залишаються у вʼязці.
- Перемикач пісочниці для кожного чату обмежує, що можуть робити команди агента, наскільки агент це підтримує.
- Текст ззовні, як-от вивід термінала, вебсторінка чи журнал CI, надходить агентові з позначкою ненадійного.

## Диктування
Диктування в поле повідомлення ШІ та в редактор через розпізнавання мовлення Lowspeak: кнопка мікрофона, ⌃⌥D або клавіша
fn, поки Dango — активна програма. Використовує параметри й моделі Lowspeak; онлайн-транскрипція потребує ключа OpenAI
або Groq.

## Оновлення
Програма оновлюється сама через Sparkle. Під час другого запуску вона питає, чи можна самостійно перевіряти оновлення;
доки ви не погодитеся, вона не надсилає жодного запиту. **Dango › Перевірити наявність оновлень…** перевіряє одразу.

## Доступність
Назви VoiceOver для бічної панелі, вкладок, карток хронології ШІ, рядків Git і CI, налагоджувача та тексту термінала;
повне керування з клавіатури зі скороченнями, які можна змінити в `keybindings.json`; «Збільшити контраст» і «Зменшити
рух»; подання коду лишаються зліва направо в інтерфейсах із письмом справа наліво. Подробиці — в ACCESSIBILITY.md.

## Конфіденційність
Жодної телеметрії, аналітики чи звітів про збої. Програма підʼєднується лише для того, що ви запускаєте: агенти, якими
ви користуєтеся, завантаження, які ви запитуєте, хости CI, у які ви входите, передбачення від Copilot, якщо ви його
вибрали, онлайн-транскрипція, якщо ви її вибрали, сторінки, які ви відкриваєте, і перевірка оновлень, щойно ви її
дозволили. Ключі й токени залишаються у вʼязці macOS.

## Відомі обмеження
- Вхід до CI через браузер вимкнено; використовуйте `gh`, `glab`, токен або середовище.
- Програма працює без App Sandbox, бо його успадкували б термінали, git, мовні сервери й агенти; папці потрібно
  довіряти, перш ніж запуститься будь-що, що вона налаштовує. Antigravity і OpenCode не мають пісочниці, яку програма
  могла б увімкнути.
- Показники використання й розподіл контексту Claude спираються на частини його протоколу, позначені як
  експериментальні, і приховуються, якщо їх немає. Відкат діалогу працює лише для Claude; для інших агентів відкочується
  лише код.
- Gemini CLI не пропонується: Google припинив вхід з особистим обліковим записом і радить Antigravity. Попередні чати
  Gemini лишаються доступними для читання.
