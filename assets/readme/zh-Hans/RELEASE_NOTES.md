## 工具栏
- 从右起的新顺序：“新建终端”“新建 AI 对话”和“新建浏览器标签页”为一组，其左侧是“向右拆分”“向下拆分”和输入栏开关，再往左是“快速打开”和“活动”。
- 输入栏开关可打开或关闭前方终端的输入栏，输入栏打开时以强调色显示；前方没有终端时，开关呈灰色。
- 如果只安装了一个智能体，“新建 AI 对话”点按一次即可打开它；否则点按会在菜单中列出智能体。按住按钮始终显示菜单。
- 设置按钮移到了边栏底部更靠下的位置。

## 终端
- 没有输入栏时，你输入的命令也会获得与输入栏相同的颜色：命令、子命令、选项、变量和运算符，shell 无法运行的命令下方会出现红色虚线下划线。shell 自己设置的颜色会保留。
- 没有输入栏时，输入单词时建议列表会自动打开。Return 运行该行，Tab 或 → 采用灰色建议；用 ↑ 或 ↓ 移动选择后，它们会采用所选条目。Esc 关闭该单词的列表，“设置 › 终端”可将其关闭。
