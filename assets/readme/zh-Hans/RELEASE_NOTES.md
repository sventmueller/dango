## 帮助
- “帮助”菜单可前往 GitHub 上的项目：“报告问题…”会打开已填好 Dango 版本、macOS 版本和 Mac 类型的报告表单，“建议新功能…”会在讨论区开始一个新想法，“GitHub 上的 Dango”会打开仓库。

## 编辑器和终端
- 编辑器和终端现在以 13 磅开始，与边栏、标签栏和 AI 标签页相同；你自己设置的大小保持不变。
- 行号现在也会在光标旁标出最后一个换行符之后的空行，以及空文稿中唯一的一行。

## AI
- 后台进程尚未输出任何内容时，其输出按钮不再打开空文件，而是提示尚无输出；进程结束后则提示没有任何输出。再次点按会显示当前输出，而不是之前的副本；此前不起作用的 Codex 终端，现在也可以用该按钮显示其输出。

## Markdown
- Markdown 预览中的图片显示速度提高到约三倍：图片通过向量指令缩小，iCloud 云盘、外置磁盘或网络共享上的图片会同时载入多张，而不是逐张载入。
