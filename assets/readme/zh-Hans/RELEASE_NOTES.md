## AI 标签页
- 在视图外停留三分钟的 AI 标签页，会在会话空闲时释放其 Claude 进程。对话内容和你输入的文字仍保留在标签页中，下一条提示词会恢复该会话。当 Claude 正在工作、有提示词在等待、有提问尚未回答、子智能体、后台任务或命令仍在运行，或 Remote Control 已开启时，标签页会保留其进程。
- 结束智能体时，也会结束它在单独的进程组或会话中启动的命令；以前这些命令可能在智能体结束后继续运行。
- 时间线会将新条目追加到末尾，而不再重新索引之前的所有行。

## 速度
- 恢复的窗口打开得更快：没有未保存更改的文件标签页，只有在切换到前台时才会载入其文件。
- 面板处于隐藏状态的项目搜索会暂停，并在面板显示时继续。
- 编辑器的 Git 更改标记对每个文件同一时间最多只运行一次比较；比较期间的编辑会合并为一次后续比较，并且只有在提交发生变化时才会重新读取文件已提交的文本。
- 含有折叠代码的文件，其缩略图为每个未折叠的片段保留一个条目，而不再是每行一个。
