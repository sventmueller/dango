## 终端
- 终端现在来自 Dango 的姐妹终端 App Tapa，带来它新增的一切，同时 Dango 保留了其终端以前的功能：将图像粘贴给智能体、浏览器标签页中的开发服务器、⌘-点按跳转到编辑器。
- **显示 › 显示/隐藏输入栏**（终端拥有焦点时按 ⌘I）会把命令行变成一个文本栏，上方显示文件夹和 Git 分支。命令会按组成部分着色，Shell 无法运行的命令会带有红色虚线下划线。
- 建议会在你输入时以灰色显示，无论是否使用输入栏：来自你的历史记录、700 多个命令行工具的规格，以及项目，例如 git 分支、`package.json` 脚本，以及 make、just 和 cargo 目标。按 → 采用建议；Tab 进行补全，有多个候选项时会打开一个菜单，继续输入即可筛选。建议从不联网。
- 命令块：⌘↑ 和 ⌘↓ 在提示符之间跳转，**编辑** 菜单可选择、拷贝和保存命令的输出，书签用于标记行。开启 **将命令标记为块** 后，竖条会标出每个块，失败的命令会被标记，块上的按钮会显示其状态和耗时。
- **将块发送给智能体**（“编辑”菜单和终端的上下文菜单）会打开一个 AI 标签页，将当前块的命令行和输出作为“外部内容”附上。
- **查找**（终端拥有焦点时按 ⌘F）使用正则表达式、区分大小写和全字匹配搜索整个历史记录；滚动条会标出结果。
- 程序的通知（OSC 9 和 OSC 777）及其响铃会在你看不到终端时，在终端的标签页上显示红点；当其他 App 位于前面时，通知会发送到 macOS。程序报告的进度（OSC 9;4）会以圆环显示在其标签页上，并以进度条显示在程序坞图标上。
- 连按两次可整体选中 URL、路径或哈希值，按住 ⌥ 拖移可选中矩形区域，**带格式拷贝** 保留颜色和样式，**使用键盘选择** 用 Vim 的按键移动选区。
- 会立即运行的多行粘贴会先显示出来，**Dango › 安全键盘输入** 可防止其他 App 读取你在终端中键入的内容。
- 除网址、`mailto:` 和文件以外的其他类型链接，终端不再打开。

## 设置
- **设置 › 终端** 可切换新终端的输入栏、其 Vim 按键、建议、命令着色、未知命令的下划线、命令块、立即拷贝所选内容、先显示多行粘贴，以及将 ⌥ 用作 Meta 键，最后一项是从“通用”移到这里的。
