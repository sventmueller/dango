## 安全性
- 智能体的回答、计划和报告中、Markdown 预览中以及 PDF 中的链接不再单击一下就打开任何 App。网址在浏览器标签页中打开，项目内的文件在编辑器标签页中打开；其他任何内容，例如其他位置的文件、网络共享或其他 App 的链接，都会先询问并显示其指向的位置。
- 智能体或 MCP 服务器传来的登录和 Remote Control 地址只有在是网址时才会打开。
- 包含的内容远不止一个项目的文件夹，例如个人文件夹、桌面、文稿、下载或宗卷的根目录，不再能被整体信任；请逐个项目地信任它们。信任询问现在会说明信任也适用于其中的文件夹。
- CI Token 和登录信息绝不会通过明文 http 发送到此 Mac 以外的服务器；远程仓库地址以 `http://` 开头的仓库会通过 https 查询。
- 没有 gitleaks 时，编辑预测会在代码发送给此 Mac 之外的提供商之前等待，直到你选择不经检查发送。项目自己的 gitleaks 设置不再能关闭检查。
- 内置智能体不再会被写入获批后才出现的链接引导到项目之外写入；具有其他硬链接的文件会得到一个独立的文件，而不是经由链接直接写入。
- 语言服务器的补全不再会让编辑器卡住，它对链接文件的重命名和删除会作用于链接本身，而不是其指向的内容。
- 你附加到提示词中的图片会像其他地方一样，由沙盒中的解码服务进行解码。
- 终端中的程序只有在其终端位于前台时才能替换剪贴板，并且终端会告知这一点。
- rust-analyzer 从固定了校验和的版本安装，而不是当时碰巧最新的版本。

## 搜索与导航
- “快速打开”会在没有匹配的文件时给出提示，并显示它搜索的是文件还是项目的符号。
- 项目的符号现在包括 TypeScript 和 JavaScript，无需打开它们的文件。来自项目和你所用语言的完全匹配项排在前面；来自库和已安装软件包的符号会被标记。
- “显示 › 搜索”会将焦点放到搜索栏中。

## 编辑器
- 打开 Markdown 文件并在旁边显示其预览时，编辑器会保留焦点，因此“格式”菜单立即可用。焦点位于边栏时，编辑器命令同样可用。
- 行尾或其下方框中的建议会提示按 Tab 接受。
- 标签页概览中同名的标签页现在可以区分，例如一个文件和它在浏览器中的预览。
- “显示”菜单不再提供 macOS 自带的“隐藏标签页栏”，Dango 的标签页并不使用它。

## 语言与调试
- JSON 服务器现在会检查文件，启动后才注册诊断的服务器，例如 basedpyright 和 sourcekit-lsp，也会显示其诊断。
- 在 pip 拒绝安装到 Python 中的情况下（例如 Homebrew 的 Python），调试器会提议将 debugpy 安装到项目的虚拟环境中。
