## 速度与内存
- 智能体启动的所有内容，无论使用哪种语言，例如构建、测试、Shell 和 MCP 服务器，都会在 macOS 的后台状态下运行：优先级最低，磁盘和网络访问受到限制。智能体本身（包括 Claude 的子智能体）以中等优先级运行。满负荷运行的智能体不再拖慢 Dango；这同样适用于 Software Factory 的智能体。
- 恢复的窗口只启动显示出来的内容：位于其他标签页后面的 AI 标签页会在移到前台或收到提示词时才启动其 CLI，浏览器、网站预览和终端标签页则在首次显示时才加载页面或启动 Shell。
- 耗时较长的项目搜索在运行期间不再反复重绘全部结果。Software Factory、CI 日志和“测试”面板在不可见时会减少工作；测试和调试配置会在其面板首次显示时才读取，隐藏的“CI”和“容器”面板在显示之前不读取任何内容。
- 长时间的会话占用更少内存：已完成的差异只保留其卡片所显示的行，已回答的权限请求会释放其输入，终端的字形缓存不再无限增长，“文件”和“Git”面板会释放已不存在的行。
- 程序本身缩小了约 40%。

## 窗口与菜单
- 关闭窗格时，其标签页会移到前一个窗格，若没有则移到后一个窗格，而不再随之关闭。只有预览所在的窗格和最后一个窗格会连同其标签页一起关闭。
- “显示”菜单按边栏图标的顺序列出各个面板。
- “管理智能体…”已从“+”菜单中移除；它仍位于“智能体”面板的“+ 新会话”下方。

## 问题修复
- “搜索”面板中的“包含和排除文件”不再在其箭头旁显示多余的字母。
- 关闭规格的评论弹出框不再导致崩溃。
