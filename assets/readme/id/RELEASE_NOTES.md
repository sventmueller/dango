## Tab AI
- “Tampilkan Output” pada perintah latar belakang kini membuka tab yang mengikuti output selama perintah berjalan, bukan
  salinannya pada saat itu. Tab terbuka di akhir output dan tetap di sana saat baris baru masuk, hingga Anda menggulir
  ke atas; menggulir kembali ke akhir membuatnya mengikuti output lagi. “Tampilkan Output” pada tab yang sudah terbuka
  membawanya ke depan, di akhir output.
  - Perintah yang menulis sendiri output-nya ke file, seperti `make > build.log 2>&1`, menampilkan file tersebut selagi
    file itu terus bertambah.
  - Setelah perintah selesai, tab menampilkan seluruh output-nya; “Buka di Editor” membuka file di baliknya.
  - Tab hanya membaca output selama tab itu berada di depan.
