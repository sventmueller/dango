# Dango

**Нативный редактор для macOS для работы с агентами программирования.**

Dango собирает код, агентов, которые его меняют, и все, что их окружает, в одном окне на каждую папку: редактор с языковыми серверами и предсказаниями при наборе, терминалы, браузер, Git, CI, отладчик и ИИ-чаты с Claude, Codex, Antigravity, OpenCode или агентом, встроенным в приложение. Каждый агент работает в одной и той же ленте, спрашивает, прежде чем менять файлы или выполнять команды, и оставляет контрольную точку перед каждым промптом, так что Вы можете просмотреть и откатить сделанное им сообщение за сообщением. Ничто из того, что настраивает папка, не запускается, пока Вы ей не доверитесь, а текст извне попадает к агенту с пометкой «недоверенный». Диктуйте в редактор и в поле сообщения — распознавание речи может оставаться на Вашем Mac. Dango написан на Rust на настоящих элементах управления AppKit, без Electron, говорит на 35 языках и не содержит телеметрии.

**Еще не выпущен.** Первый выпуск будет образом диска, подписанным Developer ID и нотаризованным Apple, для macOS 14 или новее на Mac с чипом Apple или Intel. До тех пор [соберите Dango из исходного кода](#сборка-из-исходного-кода).

**Нашли ошибку?** [Откройте issue](https://github.com/sventmueller/dango/issues/new) и укажите, с каким агентом и в каком проекте она возникла.

## Возможности вкратце

- **Все агенты в одной ленте.** Claude через собственную команду `claude`, Codex, Antigravity и OpenCode через Agent Client Protocol, другие из реестра ACP, а также агент, встроенный в приложение, для Anthropic, OpenAI, Google Gemini, OpenRouter, Ollama и LM Studio. Ответы, вызовы инструментов, запросы разрешений, планы, списки дел, субагенты и фоновые задачи выглядят одинаково, какой бы агент ни работал.
- **Просмотр и откат.** Перед каждым промптом Dango создает контрольную точку. Изменения агента можно просмотреть и откатить для каждого сообщения, а чат может работать в собственном worktree Git и передавать свою работу через слияние или cherry-pick.
- **Одно окно на папку.** Файлы, терминалы, страницы браузера, ИИ-чаты, просмотры различий и просмотры файлов — это вкладки macOS этого окна. В боковом меню — «Файлы», «Поиск», «Агенты», «Git», «Отладка» и «CI».
- **Настоящий редактор кода.** Подсветка синтаксиса, несколько курсоров, свертывание, `.editorconfig`, языковые серверы для 17 языков с автодополнением, переходом к определению, ссылками, переименованием, быстрыми исправлениями и иерархиями, а также предсказания при наборе от GitHub Copilot или локальной модели.
- **Встроенные отладчик, Git и CI.** Точки останова и пошаговое выполнение для Rust, C, C++, Swift, Go, JavaScript, TypeScript и Python; индексирование отдельных фрагментов, ветки, stash, конфликты и граф коммитов; запуски, задания и журналы из GitHub Actions и GitLab CI.
- **Бережно к Вашим папкам.** Папка, которой Вы не доверились, ничего не запускает: ни процессов Git, ни языковых серверов, ни хуков, ни агентов. Деструктивные команды Git никогда не разрешаются навсегда, а коммиты проверяются на секреты.
- **Диктовка.** Говорите в редактор и в поле сообщения — онлайн через OpenAI или Groq либо локально с Whisper и Parakeet.
- **Нативный до мозга костей.** Окна, вкладки, меню и панели инструментов AppKit, TextKit 2 для редактора, Metal для терминала, WebKit только во вкладке браузера. Темный режим, «Увеличить контраст» и VoiceOver работают как в любом приложении для Mac.
- **На Вашем языке.** Интерфейс доступен на 35 языках: английский, арабский, венгерский, вьетнамский, голландский, греческий, датский, иврит, индонезийский, испанский, итальянский, каталанский, китайский (упрощенное письмо), китайский (традиционное письмо), корейский, малайский, немецкий, норвежский, польский, португальский (Бразилия), португальский (Португалия), румынский, русский, словацкий, словенский, тайский, турецкий, украинский, финский, французский, хинди, хорватский, чешский, шведский и японский.

## Требования

- macOS 14 Sonoma или новее, на Mac с чипом Apple или Intel. Dango разрабатывается и тестируется на macOS 27.
- Для ИИ-чатов — агент, которым Вы хотите пользоваться; см. [ИИ-агенты](#ии-агенты).
- Для языковых серверов и адаптеров отладки, которые Dango устанавливает по Вашему запросу: Go для gopls и `dlv`; Node.js для серверов TypeScript, Python, JSON, YAML, CSS, HTML и shell и отладчика JavaScript; Xcode Command Line Tools для clangd, sourcekit-lsp и `lldb-dap`. rust-analyzer загружается из его выпусков на GitHub.
- Для предсказаний при наборе — подписка GitHub Copilot (подойдет и бесплатная) или модель fill-in-the-middle в Ollama или LM Studio.

## Установка

**Из образа диска.** Каждый выпуск — это образ диска `Dango-<version>.dmg` с одним универсальным приложением для Mac с чипом Apple и Intel, подписанным Developer ID и нотаризованным Apple. Откройте его и перетащите Dango в папку «Программы». Homebrew Cask устанавливает тот же образ. Ни один выпуск еще не опубликован.

**Обновления.** Dango из образа диска сам поддерживает себя в актуальном состоянии через [Sparkle](https://sparkle-project.org). При втором запуске он спрашивает, можно ли ему проверять обновления самостоятельно; пока Вы не согласитесь, он не делает ни одного запроса. **Dango › Проверить наличие обновлений…** проверяет сразу. Обновления подписаны собственным ключом приложения, который Sparkle проверяет перед установкой чего-либо. В собственной сборке механизма обновления нет.

**Из исходного кода.** См. [Сборка из исходного кода](#сборка-из-исходного-кода), затем переместите `target/release/Dango.app` в `/Applications`.

**Команда для терминала.** **Dango › Установить команду «dango»…** записывает небольшой скрипт в `~/.local/bin/dango` без прав администратора; `~/.local/bin` должен быть в Вашем `PATH`. После этого `dango .` открывает текущую папку, а `dango file.rs` — файл. Dango никогда не заменяет там файл, который записал не он сам.

## Начало работы

1. **Откройте папку** с помощью ⌘O или `dango <folder>`. В первый раз Dango спросит, доверяете ли Вы ей (см. [Доверие](#доверие)).
2. **Боковое меню** переключается между разделами «Файлы» (⌘1), «Поиск» (⌘2), «Агенты» (⌘3), «Git» (⌘4), «Отладка» (⌘5) и «CI» (⌘6); щелчок правой кнопкой скрывает те, которыми Вы не пользуетесь, а ⌃⌘S сворачивает боковое меню.
3. **Каждый документ — это вкладка** окна папки, собственные вкладки macOS. «+» в конце панели вкладок и ⌘T предлагают новый файл, терминал, браузер и каждый установленный агент, в том числе в собственном worktree Git; если удерживать «+», то же самое появится в виде меню.
4. **«Быстрое открытие»** по ⌘P находит файлы, а с `#` — символы проекта; ⇧⌘F ищет и заменяет по проекту.
5. **Говорите с агентом** во вкладке ИИ. ⌘Esc переводит фокус клавиатуры в его поле сообщения и обратно.
6. **Настройки** по ⌘, содержат вкладки «Основные», «CI», «Агенты», «Собственный агент», «Языковой сервер», «Диктовка» и «Предсказание».

На панели инструментов — назад и вперед по местам, где Вы вносили правки (⌃- и ⌃⇧-), ветка, «Быстрое открытие» и обзор «Активность», в котором перечислено все, что выполняется. **«Открыть сбоку»** в контекстном меню файла показывает второй документ рядом с первым. После перезапуска или сбоя каждое окно возвращается со своими вкладками, а редакторы с несохраненным текстом — вместе с этим текстом. Изображения, аудио, видео, шрифты и документы Office открываются во вкладке через Quick Look, PDF — через PDFKit.

## ИИ-агенты

| Агент | Как он работает | Что ему нужно |
|---|---|---|
| Claude | команда `claude`, с которой Dango общается напрямую по ее протоколу stream-json | установленный `claude` с выполненным входом; Dango ищет в `PATH` оболочки входа, в `~/.local/bin`, `~/.claude/local`, `/opt/homebrew/bin` и `/usr/local/bin`. Вход выполняется только в самом `claude` |
| Codex | `codex-acp` через Agent Client Protocol (ACP) | Node.js и npm; закрепленный пакет Dango устанавливает по Вашему запросу |
| Antigravity | `agy acp` | Ваш собственный `agy` в `PATH` или загрузка закрепленной версии, устанавливаемая по Вашему запросу |
| OpenCode | `opencode acp` | Ваш собственный `opencode` в `PATH` или загрузка закрепленной версии, устанавливаемая по Вашему запросу |
| Другие ACP-агенты | из реестра ACP, который загружается только по Вашему запросу | то, что указано в записи реестра; записи без контрольной суммы устанавливаются только после Вашего подтверждения |
| Собственный агент | встроен в приложение, с инструментами для файлов, поиска, команд, диагностики и веб-запросов | ключ API для Anthropic, OpenAI, Google Gemini или OpenRouter, хранящийся в связке ключей; Ollama или LM Studio на этом Mac без ключа; любой сервер с API OpenAI или Anthropic |

**Настройки › Агенты** показывает, какие агенты есть на этом Mac, устанавливает остальные и их обновления и открывает реестр ACP. Агенты, которые устанавливает Dango, закреплены на проверенных версиях и сверены по опубликованным контрольным суммам (npm integrity или SHA-256); Dango не запускает пакеты `npx` без указания версии.

### Лента

Каждый агент работает во вкладке ИИ с одинаковой лентой: ответы, вызовы инструментов с их выводом, запросы разрешений, вопросы, планы для одобрения и комментариев (⌥⌘K), списки дел, субагенты и фоновые задачи. Две кнопки в заголовке вкладки показывают работающие субагенты и фоновые процессы. Упомяните файл, `@terminal` или `@browser`, чтобы передать агенту их содержимое. Зеленая точка на вкладке означает работающий сеанс, красная — сеанс, который ждет Вас, а уведомление сообщает, когда сеанс завершится или начнет ждать, пока Вы заняты другим. Для Claude строка состояния показывает контекст и расход.

### Разрешения и режимы

Новые чаты начинаются в режиме «Вручную»: агент спрашивает, прежде чем менять файлы или выполнять команды. Для деструктивных команд Git (`push --force`, `reset --hard`, `clean -fd`) Dango не предлагает «Разрешать всегда». Собственный агент хранит свои правила «Разрешать всегда» для каждого проекта, перечисляет их в **Настройки › Собственный агент** и спрашивает о деструктивных командах Git каждый раз, что бы ни было сохранено; Claude и ACP-агенты хранят такие правила в собственной конфигурации. В режиме «Разрешить все» без песочницы чат показывает постоянное предупреждение.

### Контрольные точки и worktree

Перед каждым промптом Dango создает контрольную точку — коммит в `refs/ide-checkpoints/` в репозитории проекта или в собственной папке для проекта без Git; обычный push или fetch никогда их не переносит. Изменения агента можно просмотреть и откатить для каждого сообщения. Чат может работать в собственном worktree Git: панель Git показывает, что он изменил, и переносит работу через слияние или cherry-pick.

## Редактор

- **Подсветка синтаксиса, номера строк и отметки изменений** относительно последнего коммита, поиск и замена, «Быстрое открытие» (⌘P) и поиск по проекту (⇧⌘F).
- **Отступы** следуют файлу и `.editorconfig`: табуляция или пробелы, автоматические отступы, парные скобки.
- **Несколько курсоров:** ⌥-щелчок, ⌥-перетаскивание для столбца, ⌃⇧↑ и ⌃⇧↓, ⌘D для следующего вхождения.
- **Свертывание** (⌥⌘← и ⌥⌘→, с ⇧ — для всего), переключение комментариев (⌘/), переход к строке (⌃G), видимые пробелы и перенос строк (⌥Z).
- **Файлы сохраняют кодировку**, метку порядка байтов и окончания строк. Файл, измененный на диске, перезагружается, если в редакторе нет несохраненного текста; иначе панель предлагает различия и слияние.
- **Предсказания при наборе.** Пока Вы печатаете, серым цветом появляется предложение, и Tab принимает его. Оно приходит от GitHub Copilot или от локальной модели в Ollama или LM Studio — что Вы выберете в **Настройки › Предсказание**; с локальной моделью Ваш код остается на этом Mac.
- **Миникарта и закрепленная прокрутка** (меню «Редактор»): узкое изображение всего файла рядом с текстом и строки заголовков блоков, в которых находится верхняя строка, закрепленные над ней.
- **Диагностика в конце строки** (меню «Вид»): самое серьезное сообщение каждой строки после секунды покоя, со значком уровня серьезности.
- **Живой просмотр статических страниц:** Редактор › Открыть во вкладке браузера раздает страницы доверенной папки прямо из Dango и перезагружает вкладку, когда файл сохраняется.
- **Prettier** форматирует JavaScript, TypeScript, CSS, HTML, Markdown и другое там, где проект его настраивает, собственным `node_modules/.bin/prettier` проекта; настройка `formatter` выбирает форматировщик для каждого языка.
- **Режим Vim** (Редактор › Режим Vim): режимы Normal, Insert, Visual и Replace, счетчики, операторы с перемещениями и текстовыми объектами, `.`, регистры, отметки и макросы. `u` и ⌃R используют отмену редактора, а один проход вставки — один шаг. `"+` и `"*` — это буфер обмена; настройка `vimClipboard` делает буфером обмена и безымянный регистр. `/`, `?`, `n`, `N`, `*`, `:s` и `:%s` ищут регулярными выражениями Rust, а не шаблонами Vim: нет `\v`, а вместо `\<` и `\>` — `\b`. Команды Ex: `:w`, `:q`, `:wq`, `:x`, `:noh` и `:<line>`. В режиме Normal Vim забирает ⌃G у перехода к строке.
- **Синхронизация настроек** через папку в iCloud Drive (**Настройки › Основные**): Ваши настройки и сочетания клавиш следуют за Вами на другие Ваши Mac; пути, локальные адреса и согласия остаются на каждом из них свои.

## Языковые серверы

Go, Rust, TypeScript и JavaScript, Python, C, C++ и Objective-C, Swift, скрипты shell, JSON, YAML, CSS, HTML, TOML, Markdown и Lua, а также собственные серверы из **Настройки › Языковой сервер**. Dango устанавливает сервер по Вашему запросу в собственную папку инструментов и использует собственный `tsc` проекта TypeScript, если он может работать языковым сервером.

Что они дают: диагностика (⌘' и ⇧⌘' переходят между сообщениями), всплывающие подсказки (⌃⌘I), автодополнение (⌥Esc), справка по сигнатурам, переход к определению (⌃⌘J), определению типа и реализации, ссылки (⌃⇧⌘F), иерархии вызовов и типов (⌃⇧⌘H), переименование (⌃⌘E), форматирование (⌥⇧F), семантическая подсветка, свертывание и структура (⇧⌘O); типы и имена параметров внутри строки; быстрые исправления и рефакторинги за значком лампочки (⌥⌘A); символы проекта по ⌥⌘O.

Помимо собственного сервера файла, ESLint проверяет JavaScript и TypeScript проектов, которые его используют, со своими быстрыми исправлениями, а сокращения Emmet появляются в автодополнении для HTML, CSS и JSX. Dango устанавливает оба по Вашему запросу; в **Настройки › Основные** можно включить исправление проблем ESLint при сохранении.

|---|---|
| Rust, C, C++, Swift | `lldb-dap` из Xcode Command Line Tools |
| Go | `dlv` |
| JavaScript, TypeScript | отладчик JavaScript на Node.js |
| Python | debugpy |

Файл `.vscode/launch.json` проекта считывается. Меню «Отладка» использует сочетания клавиш Xcode: ⌘\\ ставит точку останова, ⌘Y включает или выключает их все, ⌃⌘Y продолжает выполнение, F6, F7 и F8 выполняют шаг с обходом, с заходом и с выходом, ⌘. останавливает.

## Терминал

Терминалы во вкладках (⌃\`) с окружением оболочки входа, отрисовка через Metal. ⌘K очищает экран. Вставленное или перетащенное изображение передается агенту программирования, работающему в терминале, иначе вставляется путь к сохраненной копии. ⌘-щелчок открывает ссылки и имена файлов. Сервер разработки, запущенный из терминала, можно открыть во вкладке браузера.

## Браузер

Вкладка браузера с адресной строкой (⌘L), кнопками «Назад» и «Вперед» (⌘[ и ⌘]), обновлением (⌘R), поиском, загрузками с предварительным вопросом и веб-инспектором. `@browser` передает страницу агенту с пометкой текста извне.

## Git

Панель Git индексирует и отменяет изменения целых файлов или отдельных фрагментов, создает коммиты, делает коммит с push или синхронизацией, переключает и создает ветки, хранит stash, разрешает конфликты слияния и рисует граф последних коммитов. Blame показывает, кто последним изменил строку под курсором, или столбец для всего файла. Кнопка пишет сообщение коммита с помощью ИИ; изменения отправляются только после того, как gitleaks не нашел в них секретов, и каждый коммит тоже проверяется на секреты.

## CI

GitHub Actions и GitLab CI, а также GitHub Enterprise Server и GitLab на собственном сервере:

- запуски, задания и журналы текущей ветки;
- перезапуск неудачных заданий, отдельного задания или, на GitHub, всего запуска; старт ручных заданий или одобрение ожидающих развертываний; старт нового pipeline или workflow, который можно запускать вручную; отмена;
- открытые pull request или merge request и issue, которые открываются во вкладке браузера;
- журнал неудачного задания, переданный агенту с пометкой текста извне.

Токен берется из связки ключей, из `gh` или `glab`, из окружения оболочки входа или вводится Вами в **Настройки › CI**.

## Markdown

- **Просмотр.** Файл Markdown открывается с просмотром рядом; **Вид › Показать/скрыть просмотр сбоку** (⇧⌘V) закрывает и открывает его, а в **Настройки › Основные** можно выключить автоматический просмотр. Просмотр отображает формулы, диаграммы Mermaid, Graphviz и PlantUML и изображения из папки; изображения из интернета загружаются только в доверенной папке или после того, как Вы запросите их в просмотре.
- **Меню «Формат»:** полужирный (⌘B), курсив (⌘I), зачеркнутый (⇧⌘X), код (⌥⇧⌘C), ссылка (⇧⌘K), заголовки 1–3 (⌥⌘1–⌥⌘3), маркированные и нумерованные списки, задачи, цитаты и блоки кода. Каждая команда работает как переключатель — для выделения или строк — и отменяется за один шаг.
- **Вставка.** Текст из Word или с веб-страницы превращается в Markdown, а его изображения — в файлы рядом с документом; ⌥⇧⌘V вставляет простой текст.
- **Экспорт.** **Файл › Экспортировать** сохраняет PDF, один HTML-файл со встроенными изображениями или документ Word. Изображения из интернета попадают в экспорт только из доверенной папки.
- **Открыть в Splat.** Если установлен [Splat](https://github.com/sventmueller/splat), **Файл › Открыть в Splat** и контекстные меню дерева файлов и вкладок открывают документ в нем, предварительно сохранив его.

## Диктовка

Диктуйте в поле сообщения вкладки ИИ или в редактор: кнопкой микрофона рядом, командой **Правка › Начать диктовку** (⌃⌥D) или клавишей fn (удерживайте для записи, нажмите дважды, чтобы запись продолжалась). Распознавание речи — то же, что в [Lowspeak](https://github.com/sventmueller/lowspeak); сам Lowspeak устанавливать не нужно.

- **Настройки › Диктовка** задает режим и модель (онлайн с OpenAI или Groq, локально с Whisper или Parakeet), язык, постобработку, микрофон и Ваш собственный словарь.
- **Локальные модели** загружаются с Hugging Face, когда Вы выбираете одну из них, с индикатором хода и возможностью отмены. Они сохраняются в папки, которые использует Lowspeak, так что каждое из приложений использует то, что загрузило другое. С локальной моделью запись остается на этом Mac.
- **Для онлайн-расшифровки** нужен ключ OpenAI или Groq, который Dango хранит в собственной записи связки ключей.
- **Из Lowspeak.** Если Lowspeak настроен не по умолчанию, вкладка «Диктовка» однократно предлагает перенести его настройки, а по запросу и его ключи; macOS спрашивает, прежде чем Dango прочитает ключ (выберите «Разрешить», а не «Всегда разрешать»).
- **Разрешения.** macOS запрашивает доступ к микрофону при первой диктовке. Клавиша fn работает, пока Dango — активное приложение и Lowspeak не запущен; для нее нужно разрешение «Универсальный доступ», которое Dango запрашивает после первой диктовки, но никогда при запуске.

## Доверие

Папка может заставить программы запуститься, как только в ней что-то запускается: хуки Git и настройки репозитория, такие как `core.fsmonitor`, языковые серверы из `node_modules`, хуки агентов, `.mcp.json`. Когда Вы впервые открываете папку, Dango спрашивает, доверяете ли Вы ей.

- **Доверенная:** Git, языковые серверы, отладчики, агенты и CI работают для этой папки и всего, что в ней находится.
- **С ограничениями:** можно читать и редактировать; отметки изменений в редакторе получаются прямым чтением `.git`. Ничто из того, что настраивает папка, не запускается. Панели Git, CI и ИИ сообщают об этом и предлагают довериться папке.

Текст, который исходит не от Вас, может содержать инструкции, призванные управлять агентом (prompt injection, внедрение промптов). Поэтому вывод терминала (`@terminal`), страница браузера (`@browser`), журнал CI, переданный агенту, файл за пределами проекта и длинный текст, вставленный с веб-страницы, передаются с пометкой: на метке написано «Внешнее содержимое», а агент получает текст с уведомлением, что это недоверенные данные, инструкциям из которых он не должен следовать. Веб-страницы собственного агента приходят с тем же уведомлением. Вставленный текст считается пришедшим с веб-страницы, если браузер указывает это в буфере обмена, как это делают Safari, Chrome и Firefox; текст из других мест, а также короткая фраза из нескольких слов остаются Вашими собственными.

## Песочница

Сам Dango работает без App Sandbox, поскольку ее унаследовала бы каждая запускаемая им программа: терминалы, Git, языковые серверы и агенты не смогли бы работать. Вместо этого в каждом ИИ-чате есть переключатель песочницы, по умолчанию выключенный. Что он ограничивает, зависит от агента, и об этом сообщает подсказка переключателя:

| Агент | При включенной песочнице |
|---|---|
| Claude | команды shell выполняются в собственной песочнице Claude; его инструменты для файлов и веба — нет |
| Codex | команды и изменения записывают только в проект, без сети |
| Собственный агент | файлы, веб-запросы и команды остаются в пределах проекта и разрешенных папок, без сети (`sandbox-exec`) |
| Antigravity, OpenCode | нет песочницы, которую Dango мог бы включить |

## Внешний вид и универсальный доступ

- **Темный режим** следует системе; **«Увеличить контраст»** и **«Уменьшить движение»** учитываются.
- **VoiceOver** называет боковое меню, вкладки, карточки ленты ИИ, строки Git и CI, отладчик и текст терминала. Точки останова никогда не различаются только по цвету.
- **Клавиатура.** У каждой команды есть сочетание клавиш, и все их можно изменить в `keybindings.json`; ⌥⌘\` переходит к следующей панели.
- **Справа налево.** На арабском и иврите окно отражается зеркально, а представления кода остаются слева направо.

Что Dango добавляет поверх AppKit, по областям, описано в [ACCESSIBILITY.md](../../../ACCESSIBILITY.md).

## Конфиденциальность и безопасность

- **Никакой телеметрии,** никакой аналитики, никаких отчетов о сбоях, отправляемых куда-либо. Ошибки попадают в системный журнал (Console.app, под именем приложения).
- **Сеть — только для того, что запускаете Вы:** агенты, которыми Вы пользуетесь, каждый со своим сервисом; реестр ACP и загрузки агентов, языковых серверов, адаптеров отладки и моделей диктовки, когда Вы их запрашиваете; хосты CI, в которые Вы входите; предсказания при наборе от Copilot, если Вы его выбрали; провайдеры собственного агента; онлайн-расшифровка, если Вы ее выбрали; страницы, которые Вы открываете во вкладке браузера; и проверка обновлений, как только Вы ее разрешили.
- **Код покидает Mac** только там, где Вы выбрали для него сервис: агент, предсказания Copilot, сообщение коммита, написанное ИИ. Изменения для сообщения коммита отправляются только после того, как gitleaks не нашел в них секретов.
- **Ключи и токены** остаются в связке ключей macOS, никогда — в файле настроек. Ключи других приложений, например Lowspeak, считываются только с Вашего согласия и только один раз.
- **Закрепленные загрузки.** Агенты, языковые серверы и адаптеры отладки, которые устанавливает Dango, закреплены на проверенных версиях и сверены по контрольным суммам.
- **Подпись кода** с Hardened Runtime; обновления устанавливаются только с собственной подписью приложения.

## Где хранятся данные

`<id>` — это идентификатор пакета (bundle identifier): `local.agentide` для выпуска (`local.agentide.debug` для отладочных сборок). Он не содержит отображаемого имени, поэтому при переименовании все данные сохраняются.

| Место | Что |
|---|---|
| `~/Library/Application Support/<id>/` | `settings.json`, `state.json`, `keybindings.json`, `trust.json`; `threads/` (список панели ИИ), `agent-threads/` (диалоги собственного агента), `layouts/` (вкладки по проектам), `recovery/` (несохраненные редакторы после сбоя), `checkpoints/` (для папок без Git), `worktrees/`, `agents/` и `tools/` (установленные агенты, языковые серверы и адаптеры отладки), `task-output/` |
| `~/Library/Caches/<id>/` | вставленные изображения, скрипты интеграции с оболочкой, реестр ACP; можно удалить |
| `~/Library/Logs/<id>/dictation/` | файлы журнала диктовки |
| `~/Library/Application Support/Lowspeak` и `FluidAudio` | локальные модели диктовки, общие с Lowspeak |
| `~/Library/WebKit/<id>/` | файлы cookie и данные веб-сайтов вкладки браузера |
| `<project>/.dango/settings.json` | собственные настройки проекта |
| репозиторий Git проекта | контрольные точки в виде коммитов в `refs/ide-checkpoints/`; обычный push или fetch никогда их не переносит |
| связка ключей, служба `<id>` | ключи API собственного агента и диктовки, токены CI |
| `~/.local/bin/dango` | команда для терминала, если Вы ее установили |

Claude хранит собственные сеансы в `~/.claude/projects`; Dango читает их, чтобы продолжить сеанс, но не изменяет.

## Известные ограничения

- **Без App Sandbox** для самого приложения, поскольку ее унаследовали бы терминалы, Git, языковые серверы и агенты; папке нужно доверять, прежде чем запустится что-либо, что она настраивает. У Antigravity и OpenCode нет песочницы, которую Dango мог бы включить.
- **Данные о расходе и разбивка контекста Claude** опираются на части его протокола, помеченные как экспериментальные, и скрываются, если их нет.
- **Откат диалога** работает только для Claude; у других агентов откатывается только код.
- **Вход в CI через браузер** отключен; используйте `gh`, `glab`, токен или окружение.
- **Gemini CLI не предлагается:** Google прекратил вход с личной учетной записью и рекомендует Antigravity. Прежние чаты Gemini остаются доступными для чтения.

## Сборка из исходного кода

Вам понадобятся:

- macOS 14 или новее с Xcode Command Line Tools (`xcode-select --install`); сам Xcode не нужен.
- Rust в версии, указанной в `rust-toolchain.toml`. `rust` из Homebrew собирает для процессора этого Mac; для универсальной сборки выпуска нужен rustup с целями `aarch64-apple-darwin` и `x86_64-apple-darwin`.
- Копии [splat](https://github.com/sventmueller/splat) и [lowspeak](https://github.com/sventmueller/lowspeak) рядом с этой (`../splat`, `../lowspeak`), обе на своей ветке `main`; рабочее пространство берет из них crates по пути.
- cmake — для каждой сборки с диктовкой (`make run`, `make build`, `make release`), он собирает whisper.cpp. `make check` собирает без него.

| Команда | Что она делает |
|---|---|
| `make run` | собирает отладочное приложение (`target/debug/Dango Debug.app`) и открывает его |
| `make build` | собирает приложение для выпуска (`target/release/Dango.app`), подписанное локальным сертификатом, который первая сборка создает в связке ключей входа; увеличивает номер сборки в `VERSION` |
| `make lint` | форматирование и clippy; предупреждения приводят к ошибке |
| `make check` | `lint`, затем все тесты; не требует связки ключей, окна или сети |
| `make test` | `check`, затем самотест `probe` и аудит универсального доступа, слева направо и справа налево, в настоящем приложении |
| `make perf` | бюджеты времени в сборке для выпуска; имеет смысл только на Mac, который в остальном простаивает |
| `make release` | пробный прогон выпуска в `target/release-dry-run/`, подписанный локальным сертификатом; ничего никуда не отправляет |
| `make release-notarized` | `check`, затем сам выпуск в `dist/`: подпись Developer ID, нотаризация, лента обновлений, подписанная собственным ключом приложения; увеличивает номер сборки |

Отладочная версия и версия для выпуска — отдельные приложения с собственными настройками и данными. Сборка, тестирование, самотесты, выпуск и правила, которым следует код, описаны в [docs/development.md](../../../docs/development.md), решения, лежащие в их основе, — в [docs/plan.md](../../../docs/plan.md). Примечания к выпуску находятся в [RELEASE_NOTES.md](../../../RELEASE_NOTES.md) и переведены рядом с каждым README в `assets/readme/<language>/`.
