## Безопасность
- Ссылки в ответах, планах и отчетах агента, в просмотре Markdown и в PDF больше не открывают какое-либо приложение
  одним щелчком. Веб-адреса открываются во вкладке браузера, файлы внутри проекта — во вкладке редактора; все остальное,
  например файл в другом месте, сетевой ресурс или ссылка другого приложения, сначала запрашивает подтверждение и
  показывает, куда ведет.
- Адреса для входа и Remote Control, которые передает агент или сервер MCP, открываются, только если это веб-адреса.
- Папкам, которые содержат гораздо больше, чем один проект, например папке пользователя, папкам «Рабочий стол»,
  «Документы», «Загрузки» или корню тома, больше нельзя доверять целиком; доверяйте им по одному проекту. Вопрос о
  доверии теперь сообщает, что оно распространяется и на папки внутри.
- Токены CI и данные входа никогда не отправляются по незащищенному http на сервер, отличный от этого Mac; репозиторий,
  у которого адрес удаленного репозитория начинается с `http://`, опрашивается по https.
- Без gitleaks предсказания при редактировании ждут, прежде чем код уйдет к провайдеру за пределами этого Mac, пока Вы
  не решите отправить его без проверки. Собственные настройки gitleaks в проекте больше не отключают проверку.
- Собственный агент больше нельзя заставить писать за пределами проекта через ссылку, которая появляется после того, как
  его запись была разрешена, а файлы с другими жесткими ссылками получают собственный файл, вместо того чтобы запись шла
  через них.
- Автодополнение языкового сервера больше не может подвесить редактор, а его переименования и удаления файла-ссылки
  затрагивают саму ссылку, а не то, на что она указывает.
- Изображения, которые Вы прикрепляете к промпту, декодирует служба декодирования в песочнице, как и везде.
- Программа в терминале может заменить буфер обмена, только пока ее терминал находится на переднем плане, и терминал
  сообщает об этом.
- rust-analyzer устанавливается из выпуска, закрепленного вместе с контрольной суммой, а не из того, который на тот
  момент был последним.

## Поиск и навигация
- «Быстрое открытие» сообщает, когда ни один файл не подходит, и показывает, ищет ли оно файлы или символы проекта.
- Символы проекта включают TypeScript и JavaScript, даже если ни один их файл не открыт. Сначала идут точные совпадения
  из проекта и на языке, с которым Вы работаете; символы из библиотек и установленных пакетов помечены.
- «Вид › Поиск» переводит фокус в поле поиска.

## Редактор
- Редактор сохраняет фокус, когда файл Markdown открывается с просмотром рядом, поэтому меню «Формат» работает сразу.
  Команды редактора работают и тогда, когда фокус находится в боковом меню.
- Предложение в конце строки или в поле под ней сообщает, что его принимает клавиша Tab.
- Вкладки с одинаковыми названиями в обзоре вкладок теперь различимы, например файл и его просмотр в браузере.
- Меню «Вид» больше не предлагает собственный пункт macOS «Скрыть панель вкладок», который вкладки Dango не используют.

## Языки и отладка
- Сервер JSON теперь проверяет файлы, а серверы, которые регистрируют свою диагностику после запуска, например
  basedpyright и sourcekit-lsp, показывают ее.
- Там, где pip отказывается устанавливать пакеты в Python, как в Python из Homebrew, отладчик предлагает установить
  debugpy в виртуальное окружение проекта.
