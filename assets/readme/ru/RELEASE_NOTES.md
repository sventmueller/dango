Это первый выпуск Dango — нативного редактора для macOS для работы с агентами программирования. Редактор, терминалы,
браузер, Git, CI, отладчик, ИИ-чаты и Software Factory для заказов делят одно окно на каждую папку. Приложение написано
на Rust поверх AppKit; WebKit используется только во вкладке браузера. Интерфейс доступен на 35 языках.

## Требования
- macOS 14 или новее, на Mac с чипом Apple или Intel.
- Для ИИ-чатов — выбранный Вами агент: для Claude нужна команда `claude` с выполненным входом; для Codex нужен Node.js,
  а его закрепленный пакет приложение установит по Вашему запросу; Antigravity и OpenCode используют Ваши `agy` или
  `opencode` либо загрузку закрепленной версии; собственному агенту нужен ключ API либо Ollama или LM Studio на этом
  Mac.
- Языковые серверы и адаптеры отладки устанавливаются по Вашему запросу. Для gopls и `dlv` нужен Go; для серверов
  TypeScript, Python, JSON, YAML, CSS, HTML, ESLint и shell и отладчика JavaScript нужен Node.js; clangd, sourcekit-lsp
  и `lldb-dap` входят в Xcode Command Line Tools.
- Для предсказаний при наборе нужна подписка GitHub Copilot (подойдет и бесплатная) или модель fill-in-the-middle в
  Ollama или LM Studio.

## Окно
- Каждый файл, терминал, страница браузера, ИИ-чат, просмотр различий и просмотр файла — это вкладка macOS в окне папки.
  «+» в конце панели вкладок и ⌘T предлагают новый файл, терминал, браузер и каждый установленный агент, в том числе в
  собственном worktree Git.
- Боковое меню переключается между разделами «Файлы», «Поиск», «Агенты», «Git», «Отладка», «CI», «Тесты», «Контейнеры» и
  Software Factory; щелчок правой кнопкой скрывает те, которыми Вы не пользуетесь. На панели инструментов — назад и
  вперед по местам, где Вы вносили правки (⌃- и ⌃⇧-), ветка, «Быстрое открытие» и обзор «Активность».
- Окно делится на области рядом друг с другом или одну над другой, вложенные сколь угодно глубоко, как в Xcode; каждая
  область держит свои документы один за другим и имеет собственную панель вкладок. «Открыть сбоку» показывает второй
  документ рядом с первым.
- После перезапуска или сбоя каждое окно возвращается со своими вкладками и областями, а редакторы с несохраненным
  текстом — вместе с этим текстом.
- Изображения, аудио, видео, шрифты и документы Office открываются во вкладке через Quick Look, PDF — через PDFKit.

## Редактор
- Подсветка синтаксиса, номера строк, отметки изменений относительно последнего коммита, поиск и замена, «Быстрое
  открытие» (⌘P) и поиск по проекту (⇧⌘F). Подсветка и стили Markdown успевают даже в файлах из многих тысяч строк, не
  задерживая набор.
- Автоматические отступы, табуляция или пробелы по `.editorconfig`, парные скобки, переключение комментариев,
  свертывание, переход к строке, видимые пробелы, перенос строк, миникарта и закрепленные заголовки охватывающих блоков.
- Несколько курсоров: ⌥-щелчок, ⌥-перетаскивание для столбца, ⌘D для следующего вхождения.
- **Режим Vim:** включается в меню «Редактор», с режимами normal, insert и visual, перемещениями и операторами,
  регистрами, метками, макросами, поиском и командами Ex; его сообщения выводятся на языке интерфейса.
- Сокращения Emmet в автодополнении HTML, CSS и JSX, а проблемы ESLint по Вашему желанию исправляются при сохранении.
- Файлы сохраняют кодировку, метку порядка байтов и окончания строк. Файл, измененный на диске, перезагружается, если в
  редакторе нет несохраненного текста; иначе панель предлагает различия и слияние.
- **Предсказания при наборе:** пока Вы печатаете, серым цветом появляется предложение; Tab принимает его. Предложения
  приходят от GitHub Copilot или от локальной модели в Ollama или LM Studio — что Вы выберете в настройках; с локальной
  моделью Ваш код остается на этом Mac.

## Языковые серверы
Go, Rust, TypeScript и JavaScript, Python, C, C++ и Objective-C, Swift, скрипты shell, JSON, YAML, CSS, HTML, TOML,
Markdown и Lua, ESLint рядом с сервером TypeScript, а также собственные серверы из настроек. Диагностика, в том числе в
конце строки, всплывающие подсказки, автодополнение, справка по сигнатурам, переход к определению, определению типа и
реализации, ссылки, иерархии вызовов и типов, переименование, форматирование, семантическая подсветка, свертывание и
структура; типы и имена параметров внутри строки; быстрые исправления и рефакторинги за значком лампочки (⌥⌘A); символы
проекта по ⌥⌘O или `#` в «Быстром открытии». Собственный `tsc` проекта TypeScript используется, если он может работать
языковым сервером.

## Отладчик
Точки останова, в том числе с условиями, пошаговое выполнение, потоки с их стеками вызовов, переменные и отслеживаемые
выражения в инспекторе (⌥⌘I), значения рядом с кодом, пока программа приостановлена, и консоль отладки, которая
вычисляет выражения в приостановленном фрейме. Rust, C, C++ и Swift — через `lldb-dap`, Go — через `dlv`, JavaScript и
TypeScript — через отладчик JavaScript, Python — через debugpy. Файл `.vscode/launch.json` проекта считывается. Меню
«Отладка» использует сочетания клавиш Xcode.

## Тесты и контейнеры
- Панель «Тесты» показывает тесты проектов Rust, Go, Python, Jest, Vitest и Bun еще до первого запуска, запускает один
  тест, файл или все, показывает каждый результат в реальном времени и отмечает его на полях редактора.
- Панель «Контейнеры» показывает контейнеры, образы, тома и проекты Compose в Docker; она запускает, останавливает и
  удаляет их, следит за их журналами и открывает shell во вкладке терминала.

## Терминал
Терминалы во вкладках с окружением оболочки входа, отрисовка через Metal. Вставленное или перетащенное изображение
передается агенту программирования, работающему в терминале, иначе вставляется путь к сохраненной копии. ⌘-щелчок
открывает ссылки и имена файлов. Сервер разработки, запущенный из терминала, можно открыть во вкладке браузера.

## Markdown
Файл Markdown открывается с просмотром рядом (⇧⌘V), с формулами, диаграммами Mermaid, Graphviz и PlantUML и
изображениями из папки. Меню «Формат» для полужирного, курсива, ссылок, заголовков, списков, цитат и блоков кода; текст,
вставленный из Word или с веб-страницы, превращается в Markdown. **Файл › Экспортировать** сохраняет PDF, один HTML-файл
или документ Word. Если установлен Splat, **Файл › Открыть в Splat** открывает документ в нем.

## Браузер
Вкладка браузера с адресной строкой, кнопками «Назад» и «Вперед», поиском, загрузками с предварительным вопросом и
веб-инспектором.

## Git
Панель Git: индексирование и отмена изменений целых файлов или отдельных фрагментов, коммиты, коммит с push или
синхронизацией, ветки, stash, конфликты слияния и граф последних коммитов. Blame показывает, кто последним изменил
строку под курсором, или столбец для всего файла. Кнопка пишет сообщение коммита с помощью ИИ; изменения отправляются
только после того, как gitleaks не нашел в них секретов, и каждый коммит тоже проверяется на секреты. ИИ-чат может
работать в собственном worktree Git; панель показывает, что он изменил, и переносит работу через слияние или
cherry-pick.

## CI
GitHub Actions и GitLab CI, а также GitHub Enterprise Server и GitLab на собственном сервере: запуски, задания и журналы
текущей ветки; перезапуск неудачных заданий, отдельного задания или (на GitHub) всего запуска, старт ручных заданий или
одобрение ожидающих развертываний, старт нового pipeline или workflow, который можно запускать вручную, и отмена.
Открытые merge request или pull request и issue отображаются в той же панели и открываются во вкладке браузера. Журнал
неудачного задания можно передать агенту с пометкой внешнего содержимого. Токен берется из связки ключей, из `gh` или
`glab`, из окружения оболочки входа или вводится Вами.

## ИИ
Каждый агент работает во вкладке ИИ с одинаковой лентой: ответы, вызовы инструментов с их выводом, запросы разрешений,
вопросы, планы для одобрения и комментариев, списки дел, субагенты и фоновые задачи; две кнопки в заголовке вкладки
показывают работающие субагенты и фоновые процессы. Перед каждым промптом приложение создает контрольную точку;
изменения можно просмотреть и откатить для каждого сообщения. Новые чаты начинаются в режиме «Вручную», а деструктивные
команды Git никогда не разрешаются навсегда. Обзор «Активность» показывает все, что выполняется. Зеленая точка на
вкладке означает работающий сеанс, красная — сеанс, который ждет Вас, а уведомление сообщает, когда сеанс завершится или
начнет ждать, пока Вы заняты другим. У ленты, поля сообщения и строки состояния есть собственный размер текста в
настройках.
- **Claude** через неизмененную команду `claude`, с сеансами, субагентами, фоновыми задачами, контекстом, расходом и
  Remote Control с телефона.
- **Codex** через свой app server и **OpenCode** через свой сервер, каждый по собственному протоколу, с их чатами,
  откатом в самом агенте и Remote Control для Codex.
- **ACP-агенты:** Antigravity, а по Вашему запросу — и другие из реестра ACP; установленные агенты закреплены на
  проверенных версиях и сверены по контрольным суммам.
- **Собственный агент:** Anthropic, OpenAI, Google Gemini, OpenRouter, Ollama, LM Studio и серверы с API OpenAI или
  Anthropic, с инструментами для файлов, поиска, команд, диагностики и веб-запросов; ключи остаются в связке ключей.
- Собственные команды агента открываются поверх вкладки, одинаково для каждого агента: статус, экспорт, серверы MCP,
  разрешения, хуки, память, конфигурация, навыки, плагины, модель, учетная запись и отзыв.
- Переключатель песочницы в каждом чате ограничивает, что могут делать команды агента, насколько агент это поддерживает.
- Внешнее содержимое, например вывод терминала, веб-страница или журнал CI, передается агенту с пометкой «недоверенное».

## Software Factory
Заказы вместо отдельных промптов: цель с критериями приемки, написанная вручную или взятая из issue. Каждый заказ
планируется, реализуется и проверяется в собственном worktree Git агентами разных производителей в постоянных ролях:
планировщик пишет спецификацию, исполнитель выполняет работу, а рецензент другого производителя проверяет каждый
критерий. Проверочные команды проекта, например сборка и тесты, выполняются в песочнице, и исполнитель исправляет то,
что они находят.
- Вы решаете в двух точках: Вы утверждаете спецификацию и принимаете результат с его доказательствами — целиком или по
  фрагментам. Без Вашей приемки ничего не переносится.
- Панель и вкладка Software Factory показывают каждый заказ с его этапом, стоимостью и тем, чего он ждет; вкладка заказа
  показывает его ленту, доказательства и следующий шаг и открывает его работающий сеанс как вкладку ИИ.
- Бюджеты на заказ и на день, ограничения числа запросов, пауза при завершении, сне и низком заряде аккумулятора и
  журнал, который записывается перед каждым действием, — поэтому заказы продолжаются после перезапуска.
- Issue с выбранной меткой могут поступать как заказы; принятый заказ по Вашему щелчку может уйти как merge request с
  комментарием в его issue. Заказы с непересекающимися областями путей выполняются параллельно и переносятся один за
  другим.
- Показатели по агентам и производителям, маршрутизация по доле успеха с первого раза, предложения правил для
  `AGENTS.md` и `CLAUDE.md` по повторяющимся замечаниям и повторяющиеся заказы из файла рабочего процесса проекта.
- Файл рабочего процесса папки `.dango/factory.toml` содержит ее шлюзы, классы риска и области путей; измененные
  проверочные команды и все, что ослабляет границы, ждут Вашего подтверждения.

## Диктовка
Диктовка в поле сообщения вкладки ИИ и в редактор через распознавание речи Lowspeak: кнопка микрофона, ⌃⌥D или клавиша
fn, пока Dango — активное приложение. Используются настройки и модели Lowspeak; для онлайн-расшифровки нужен ключ OpenAI
или Groq.

## Обновления
Приложение обновляется само через Sparkle. При втором запуске оно спрашивает, можно ли ему проверять обновления
самостоятельно; пока Вы не согласитесь, оно не делает ни одного запроса. **Dango › Проверить наличие обновлений…**
проверяет сразу.

## Универсальный доступ
Имена VoiceOver для бокового меню, вкладок, карточек ленты ИИ, строк Git и CI, Software Factory, отладчика и текста
терминала; полное управление с клавиатуры с сочетаниями клавиш, которые можно изменить в `keybindings.json`; «Увеличить
контраст» и «Уменьшить движение»; представления кода остаются слева направо в интерфейсах с письмом справа налево.
Подробности — в ACCESSIBILITY.md.

## Конфиденциальность
Никакой телеметрии, аналитики и отчетов о сбоях. Приложение подключается к сети только для того, что запускаете Вы:
агенты, которыми Вы пользуетесь, загрузки, которые Вы запрашиваете, хосты CI, в которые Вы входите, предсказания от
Copilot, если Вы их выбрали, онлайн-расшифровка, если Вы ее выбрали, страницы, которые Вы открываете, и проверка
обновлений, как только Вы ее разрешили. Ключи и токены остаются в связке ключей macOS, и агенты Software Factory их
никогда не видят.

## Известные ограничения
- Вход в CI через браузер отключен; используйте `gh`, `glab`, токен или окружение.
- Приложение работает без App Sandbox, поскольку ее унаследовали бы терминалы, Git, языковые серверы и агенты; папке
  нужно доверять, прежде чем запустится что-либо, что она настраивает. У Antigravity и OpenCode нет песочницы, которую
  приложение могло бы включить.
- В Software Factory исполнитель или рецензент Codex может читать за пределами своего worktree, поскольку в протоколе
  Codex нет границ чтения; запись остается внутри.
- Данные о расходе и разбивка контекста Claude опираются на части его протокола, помеченные как экспериментальные, и
  скрываются, если их нет. Откат диалога работает для Claude, Codex и OpenCode; у других агентов откатывается только
  код.
- Gemini CLI не предлагается: Google прекратил вход с личной учетной записью и рекомендует Antigravity. Прежние чаты
  Gemini остаются доступными для чтения.
