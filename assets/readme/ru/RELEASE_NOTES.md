## Дерево файлов
- В дереве файлов можно выбрать несколько строк, нажимая с ⇧ и ⌘, и контекстное меню на одной из них действует на все: «Скопировать путь» и «Скопировать относительный путь» копируют по одному пути в строке, «Показать в Finder» выбирает их вместе в Finder, а «Переместить в Корзину» перемещает их все. «Переименовать…» и команды, открывающие один файл, в этом случае недоступны; меню на строке вне выбора действует только на эту строку.
