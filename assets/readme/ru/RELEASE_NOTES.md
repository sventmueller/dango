## Вкладки ИИ
- «Показать вывод» у фоновой команды открывает вкладку, которая следит за выводом, пока команда выполняется, а не его
  копию на момент нажатия. Вкладка открывается в конце вывода и остается там по мере появления новых строк, пока Вы не
  прокрутите вверх; если прокрутить обратно к концу, она снова следит за выводом. «Показать вывод» для уже открытой
  вкладки переносит ее на передний план и прокручивает к концу.
  - Команда, которая сама пишет свой вывод в файл, например `make > build.log 2>&1`, показывает этот файл по мере его
    роста.
  - Когда команда завершается, вкладка показывает весь ее вывод; «Открыть в редакторе» открывает файл, стоящий за ней.
  - Вкладка читает вывод, только пока находится на переднем плане.
