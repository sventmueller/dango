## Вкладки ИИ
- Вкладка ИИ, которая три минуты остается вне поля зрения, завершает свой процесс Claude, пока сеанс простаивает. Диалог
  и введенный текст остаются во вкладке, а следующий промпт возобновляет сеанс. Вкладка сохраняет свой процесс, пока
  Claude работает, промпт ждет, вопрос открыт, субагент, фоновая задача или команда еще выполняется либо Remote Control
  включен.
- Завершение агента также завершает команды, которые он запустил в собственной группе процессов или сеансе; раньше они
  могли его пережить.
- Хронология добавляет новые записи в конец, а не индексирует заново все прежние строки.

## Скорость
- Восстановленные окна открываются быстрее: вкладка файла без несохраненных изменений загружает свой файл, только когда
  оказывается на переднем плане.
- Поиск по проекту, панель которого скрыта, приостанавливается и продолжается, когда панель появляется.
- Git-метки изменений в редакторе выполняют для каждого файла не больше одного сравнения за раз; правки, сделанные за
  это время, объединяются в одно последующее сравнение, а закоммиченный текст файла перечитывается, только когда
  изменился коммит.
- Миникарта файла со свернутым кодом хранит по одной записи на каждый развернутый участок, а не на каждую строку.

## Поиск
- Стрелка фильтров теперь выровнена со стрелкой «Заменить» над ней.
