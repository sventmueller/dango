## Вкладка ИИ
- `/resume` открывает обзор прошлых сеансов агента в этой папке; выбранный сеанс продолжается в отдельной вкладке.
- Агенты и Copilot теперь получают настоящую версию Dango вместо 0.0.0.

## Терминал
- Терминал работает на новом экранном движке: он перерисовывает только изменившиеся строки, а его история занимает меньше памяти, пока программа в нём простаивает.

## Вкладки
- Вкладка, открытая из меню + или с помощью ⌘T, появляется в конце панели вкладок, а не рядом с передней.
