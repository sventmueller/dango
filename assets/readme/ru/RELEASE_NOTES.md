## Память
- Длинным сеансам агентов нужно гораздо меньше памяти:
  - При открытии прошлого сеанса его транскрипт читается построчно; сеанс с транскриптом в 100 MB теперь занимает в пике
    около 20 MB вместо 65 MB.
  - Завершенный вызов инструмента хранит только то, что показывает его карточка: первые 400 строк вывода, а исходные
    входные данные больше не хранит, как только карточка показывает свои поля. «Еще строк: N» по-прежнему учитывает
    каждую строку.
  - Вкладка ИИ, которая 30 секунд остается вне поля зрения, освобождает свои карточки, а когда снова появляется, строит
    видимые — на том же месте, где была.
  - После закрытия вкладки или открытия прошлого сеанса Dango возвращает освобожденную память macOS.
- Списки больше не растут в памяти при обновлении. В macOS 27 каждое обновление списка с раскрывающимися строками
  навсегда оставляло за собой треугольник раскрытия, а каждое обновление оставляло понемногу от каждой строки:
  - Списки CI, Контейнеры, Software Factory, Тесты, Отладка, Git и Поиск, а также иерархия вызовов сами рисуют свои
    стрелки.
  - Невидимые списки больше не обновляются; они наверстывают, когда появляются.
  - Списки Сеансы, CI, Software Factory и Контейнеры сохраняют строки, которые не изменились, а Git обновляет только
    строки файлов, состояние которых изменилось.
- Панели закрытого окна освобождаются вместе с ним.

## Вкладки ИИ
- «Показать вывод» для фоновой команды, которая сама пишет свой вывод в файл, например `make > build.log 2>&1`,
  показывает этот файл, когда у CLI нет ничего из вывода.
