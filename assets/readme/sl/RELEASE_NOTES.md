## Terminal
- Terminal deluje na novem zaslonskem pogonu: znova izriše le spremenjene vrstice, njegova zgodovina pa porabi manj pomnilnika, dokler program v njem miruje.

## Zavihki
- Zavihek, odprt iz menija + ali s ⌘T, se prikaže na koncu vrstice z zavihki namesto ob sprednjem.
