## Dateibaum
- Im Dateibaum lassen sich mehrere Zeilen mit ⇧-Klick und ⌘-Klick auswählen, und das Kontextmenü auf einer davon wirkt
  auf alle: „Pfad kopieren“ und „Relativen Pfad kopieren“ kopieren einen Pfad je Zeile, „Im Finder zeigen“ wählt sie
  zusammen im Finder aus, und „In den Papierkorb legen“ legt sie alle hinein. „Umbenennen …“ und die Befehle, die
  eine einzelne Datei öffnen, gibt es dann nicht; auf einer Zeile außerhalb der Auswahl wirkt das Menü nur auf diese.
