## כרטיסיות AI
- ״הצגת הפלט״ של פקודה ברקע פותחת כרטיסיה שעוקבת אחר הפלט כל עוד הפקודה רצה, במקום עותק שלו מאותו רגע. הכרטיסיה נפתחת
  בסוף הפלט ונשארת שם כשמגיעות שורות חדשות, עד לגלילה למעלה; גלילה חזרה לסוף מחדשת את המעקב. ״הצגת הפלט״ עבור כרטיסיה
  שכבר פתוחה מביאה אותה לחזית, בסוף הפלט.
  - פקודה שכותבת בעצמה את הפלט שלה לקובץ, כמו `make > build.log 2>&1`, מציגה את הקובץ הזה בזמן שהוא גדל.
  - כשהפקודה מסתיימת, הכרטיסיה מציגה את כל הפלט שלה; ״פתיחה בעורך״ פותחת את הקובץ שמאחוריה.
  - כרטיסיה קוראת את הפלט רק כל עוד היא בחזית.
