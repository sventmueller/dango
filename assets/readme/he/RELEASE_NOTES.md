זוהי הגרסה הראשונה של Dango, עורך מקורי ל-macOS לעבודה עם סוכני קוד. עורך, מסופים, דפדפן, Git, ‏CI, מנפה באגים, שרשורי
AI ו-Software Factory להזמנות עבודה חולקים חלון אחד לכל תיקיה. היישום כתוב ב-Rust על גבי AppKit; ‏WebKit מופיע רק
בכרטיסיית הדפדפן. הממשק זמין ב-35 שפות.

## דרישות
- נדרש macOS 14 ואילך, ב-Mac עם Apple silicon או Intel.
- לשרשורי ה-AI נדרש הסוכן שנבחר: Claude דורש את הפקודה `claude` עם התחברות; Codex דורש Node.js, והיישום מתקין לפי בקשה
  את החבילה שלו בגרסה קבועה; Antigravity ו-OpenCode משתמשים ב-`agy` או ב-`opencode` הקיימים במחשב, או בהורדה בגרסה
  קבועה; הסוכן המובנה דורש מפתח API, או Ollama או LM Studio ב-Mac זה.
- שרתי שפה ומתאמי ניפוי באגים מותקנים לפי בקשה. gopls ו-`dlv` דורשים Go; שרתי TypeScript, ‏Python, ‏JSON, ‏YAML, ‏CSS,
  ‏HTML, ‏ESLint וה-shell ומנפה הבאגים של JavaScript דורשים Node.js; ‏clangd, ‏sourcekit-lsp ו-`lldb-dap` מגיעים עם
  Xcode Command Line Tools.
- חיזויי עריכה דורשים מינוי GitHub Copilot (גם המינוי החינמי מספיק), או מודל fill-in-the-middle ב-Ollama או ב-LM Studio.

## חלון
- כל קובץ, מסוף, דף דפדפן, שרשור AI, תצוגת הבדלים ותצוגה מקדימה הם כרטיסיית macOS בחלון של התיקיה. ה-״+״ בסוף סרגל
  הכרטיסיות ו-⌘T מציעים קובץ חדש, מסוף, את הדפדפן וכל סוכן מותקן, גם ב-Worktree נפרד של Git.
- סרגל הצד עובר בין קבצים, חיפוש, סוכנים, ‏Git, ניפוי באגים, ‏CI, בדיקות, ‏Containers ו-Software Factory; לחיצה ימנית
  מסתירה את אלה שאינם בשימוש. בסרגל הכלים נמצאים אחורה וקדימה בין המקומות שנערכו (⌃-‎ ו-⌃⇧-‎), ה-Branch, ״פתיחה מהירה״
  וסקירת ה״פעילות״.
- חלון מתפצל לאזורים זה לצד זה או זה מעל זה, מקוננים לכל עומק, כמו ב-Xcode; כל אזור מחזיק את המסמכים שלו זה מאחורי זה,
  עם סרגל כרטיסיות משלו. ״פתיחה לצד״ מציגה מסמך שני לצד הראשון.
- לאחר הפעלה מחדש, או קריסה, כל חלון חוזר עם הכרטיסיות והאזורים שלו, ועורכים עם טקסט שלא נשמר חוזרים עם הטקסט הזה.
- תמונות, שמע, וידאו, גופנים ומסמכי Office נפתחים בכרטיסיה דרך Quick Look, וקובצי PDF דרך PDFKit.

  הצבעים וסגנונות ה-Markdown מתעדכנים גם בקבצים של אלפי שורות רבות, בלי לעכב את ההקלדה.

## מנפה באגים
נקודות עצירה, גם עם תנאים, הרצה צעד אחר צעד, תהליכונים עם מחסניות הקריאות שלהם, משתנים וביטויים במעקב בחוקר (⌥⌘I), ערכים
לצד הקוד כשהתוכנית מושהית, ומסוף ניפוי באגים שמחשב ביטויים ב-Frame המושהה. ‏Rust, ‏C, ‏C++ ו-Swift דרך `lldb-dap`, ‏Go
דרך `dlv`, ‏JavaScript ו-TypeScript דרך מנפה הבאגים של JavaScript, ו-Python דרך debugpy. הקובץ `.vscode/launch.json` של
הפרויקט נקרא. התפריט ״ניפוי באגים״ משתמש בקיצורי המקשים של Xcode.

## בדיקות ו-Containers
- החלונית ״בדיקות״ מציגה את הבדיקות של פרויקטי Rust, ‏Go, ‏Python, ‏Jest, ‏Vitest ו-Bun עוד לפני ההרצה הראשונה, מריצה
  בדיקה אחת, קובץ או את כולן, מציגה כל תוצאה בזמן אמת ומסמנת אותה בשוליים של העורך.
- החלונית ״Containers״ מציגה את ה-Containers, ה-Images, ה-Volumes ופרויקטי ה-Compose של Docker; היא מפעילה, עוצרת ומסירה
  אותם, עוקבת אחר היומנים שלהם ופותחת מעטפת בכרטיסיית מסוף.

## מסוף
מסופים בכרטיסיות עם הסביבה של מעטפת ההתחברות, מצוירים באמצעות Metal. הדבקה או גרירה של תמונה מעבירה אותה לסוכן קוד שרץ
במסוף, או מדביקה את הנתיב של עותק שמור. ⌘-לחיצה פותחת קישורים ושמות קבצים. ניתן לפתוח בכרטיסיית הדפדפן שרת פיתוח שהמסוף
מפעיל.

## Markdown
קובץ Markdown נפתח עם התצוגה המקדימה שלו לצידו (⇧⌘V), עם נוסחאות, דיאגרמות Mermaid, ‏Graphviz ו-PlantUML והתמונות
שבתיקיה. תפריט ״עיצוב״ להדגשה, נטוי, קישורים, כותרות, רשימות, ציטוטים ובלוקי קוד; טקסט שמודבק מ-Word או מדף אינטרנט מגיע
כ-Markdown. **קובץ › ייצוא** כותב PDF, קובץ HTML יחיד או מסמך Word. כאשר Splat מותקן, **קובץ › פתיחה ב-Splat** פותח בו
את המסמך.

## דפדפן
כרטיסיית דפדפן עם שדה כתובת, אחורה וקדימה, חיפוש, הורדות עם שאלה מראש, ו-Web Inspector.

## Git
חלונית Git עם סימון ל-Commit וביטול שינויים של קבצים או של קטעים בודדים, Commits, ‏Commit ו-Push או סנכרון, Branches,
‏Stashes, התנגשויות מיזוג וגרף של ה-Commits האחרונים. ‏Blame מציג מי שינה לאחרונה את השורה שבה נמצא הסמן, או עמודה לכל
הקובץ. כפתור כותב את הודעת ה-Commit בעזרת AI; ההבדלים נשלחים רק אחרי ש-gitleaks לא מצא בהם סוד, וכל Commit נבדק גם הוא
לאיתור סודות. שרשור AI יכול לעבוד ב-Worktree נפרד של Git; החלונית מציגה מה הוא שינה ומשלבת את העבודה באמצעות מיזוג או
Cherry-Pick.

## CI
‏GitHub Actions ו-GitLab CI, גם GitHub Enterprise Server ו-GitLab באירוח עצמי: הרצות, Jobs ויומנים של ה-Branch הנוכחי;
הרצה מחדש של Jobs שנכשלו, של Job בודד או (ב-GitHub) של הרצה שלמה, הפעלת Jobs ידניים או אישור פריסות ממתינות, הפעלת
Pipeline חדש או Workflow שניתן להפעיל ידנית, וביטול. ה-Merge Requests או ה-Pull Requests הפתוחים וה-Issues מופיעים באותה
חלונית ונפתחים בכרטיסיית הדפדפן. ניתן להעביר יומן של Job שנכשל לסוכן, מסומן כטקסט חיצוני. הטוקן מגיע מצרור המפתחות,
מ-`gh` או מ-`glab`, מהסביבה של מעטפת ההתחברות, או מהזנה ידנית.

## AI
כל סוכן עובד בכרטיסיית AI עם אותו ציר זמן: תשובות, קריאות לכלים עם הפלט שלהן, בקשות הרשאה, שאלות, תוכניות לאישור
ולהערות, משימות לביצוע, סוכני משנה ומשימות ברקע; שני כפתורים בכותרת הכרטיסיה מציגים את סוכני המשנה והתהליכים ברקע
שפועלים. לפני כל הנחיה היישום שומר נקודת שחזור; ניתן לבדוק שינויים ולחזור לאחור לפי הודעה. שרשורים חדשים מתחילים במצב
״ידני״, ופקודות Git הרסניות לעולם אינן מקבלות הרשאה קבועה. סקירת ה״פעילות״ מציגה את כל מה שרץ. נקודה ירוקה על הכרטיסיה
מציינת סשן בעבודה, ונקודה אדומה – סשן שממתין לתגובה, והתראה מודיעה כשסשן מסיים או ממתין בזמן שהעבודה מתבצעת במקום אחר.
לציר הזמן, לשדה ההודעה ולשורת המצב יש גודל טקסט משלהם בהגדרות.
- ‏**Claude** דרך הפקודה `claude`, ללא שינוי, עם סשנים, סוכני משנה, משימות ברקע, הקשר, נתוני שימוש ו-Remote Control
  מהטלפון.
- ‏**Codex** דרך ה-App Server שלו ו-**OpenCode** דרך השרת שלו, כל אחד בפרוטוקול משלו, עם השרשורים שלהם, חזרה לאחור בתוך
  הסוכן עצמו, ו-Remote Control עבור Codex.
- **סוכני ACP:** ‏Antigravity, ועוד מהמרשם של ACP לפי בקשה; סוכנים מותקנים נעולים על גרסאות שנבדקו ומאומתים מול סכומי
  הביקורת שלהם.
- **סוכן מובנה:** ‏Anthropic, ‏OpenAI, ‏Google Gemini, ‏OpenRouter, ‏Ollama, ‏LM Studio ושרתים שמדברים ב-API של OpenAI
  או של Anthropic, עם כלים לקבצים, חיפוש, פקודות, אבחונים ובקשות רשת; המפתחות נשמרים בצרור המפתחות.
- הפקודות של הסוכן עצמו נפתחות כשכבות מעל הכרטיסיה, באופן זהה לכל סוכן: מצב, ייצוא, שרתי MCP, הרשאות, ‏Hooks, זיכרון,
  תצורה, מיומנויות, תוספים, מודל, חשבון ומשוב.
- מתג ארגז חול לכל שרשור מגביל את מה שהפקודות של סוכן רשאיות לעשות, ככל שהסוכן תומך בכך.
- תוכן חיצוני, כגון פלט מסוף, דף אינטרנט או יומן CI, מגיע לסוכן כשהוא מסומן כלא מהימן.

## Software Factory
הזמנות עבודה במקום הנחיות בודדות: מטרה עם קריטריוני קבלה, שנכתבת ידנית או נלקחת מ-Issue. כל הזמנה מתוכננת, נבנית ונבדקת
ב-Worktree נפרד של Git, על ידי סוכנים של יצרנים שונים בתפקידים קבועים: מתכנן כותב את המפרט, בונה מבצע את העבודה, וסוקר
של יצרן אחר בודק כל קריטריון. פקודות השער של הפרויקט, כגון בנייה ובדיקות, רצות בארגז חול, והבונה מתקן את מה שהן מוצאות.
- ההחלטה נדרשת בשתי נקודות: אישור המפרט, וקבלת התוצאה עם ההוכחה שלה, במלואה או קטע אחר קטע. דבר אינו משולב ללא קבלה.
- החלונית והכרטיסיה של Software Factory מציגות כל הזמנה עם התחנה שלה, העלות שלה ומה שהיא ממתינה לו; הכרטיסיה של הזמנה
  מציגה את ציר הזמן שלה, ההוכחה והצעד הבא, ופותחת את הסשן הפעיל שלה ככרטיסיית AI.
- תקציבים לכל הזמנה ולכל יום, מגבלות על מספר הסבבים, השהיה ביציאה, בשינה ובסוללה חלשה, ויומן שנכתב לפני כל פעולה, כך
  שהזמנות ממשיכות לאחר הפעלה מחדש.
- ‏Issues עם תווית נבחרת יכולים להיכנס כהזמנות; הזמנה שהתקבלה יכולה לצאת כ-Merge Request עם הערה ב-Issue שלה, בלחיצה.
  הזמנות עם טווחי נתיבים נפרדים רצות זו לצד זו ומשולבות זו אחר זו.
- מדדים לפי סוכן ויצרן, ניתוב לפי שיעור המעבר בסבב הראשון, הצעות כללים ל-`AGENTS.md` ול-`CLAUDE.md` מממצאים חוזרים,
  והזמנות עבודה חוזרות מקובץ תהליך העבודה של הפרויקט.
- קובץ תהליך העבודה של תיקיה, `.dango/factory.toml`, מחזיק את השערים, דרגות הסיכון וטווחי הנתיבים שלה; פקודות שער שהשתנו
  וכל מה שמרפה את הגבולות ממתינים לאישור.

ללא טלמטריה, ללא ניתוח נתונים וללא דוחות קריסה. היישום מתחבר רק עבור מה שהמשתמש מפעיל: הסוכנים שבשימוש, ההורדות שהתבקשו,
מארחי ה-CI שאליהם בוצעה התחברות, חיזויים מ-Copilot אם נבחרו, תמלול מקוון אם נבחר, הדפים שנפתחים, ובדיקת העדכונים לאחר
שהותרה. מפתחות וטוקנים נשמרים בצרור המפתחות של macOS, והסוכנים של Software Factory לעולם אינם רואים אותם.

## מגבלות ידועות
- התחברות ל-CI דרך הדפדפן כבויה; יש להשתמש ב-`gh`, ב-`glab`, בטוקן או בסביבה.
- היישום פועל ללא App Sandbox, מאחר שמסופים, Git, שרתי שפה וסוכנים היו יורשים אותו; יש לתת אמון בתיקיה לפני שמשהו שהיא
  מגדירה רץ. ל-Antigravity ול-OpenCode אין ארגז חול שהיישום יכול להפעיל.
- ב-Software Factory, בונה או סוקר של Codex יכול לקרוא מחוץ ל-Worktree שלו, מאחר שבפרוטוקול של Codex אין גבולות קריאה;
  הכתיבה שלו נשארת בפנים.
- נתוני השימוש של Claude ופירוט ההקשר שלו מסתמכים על חלקים בפרוטוקול שלו שמסומנים כניסיוניים, ומוסתרים כשהם חסרים. חזרה
  לאחור בשיחה פועלת עבור Claude, ‏Codex ו-OpenCode; בסוכנים האחרים רק הקוד חוזר לאחור.
- ‏Gemini CLI אינו מוצע: Google הפסיקה את ההתחברות עם חשבון אישי ומפנה ל-Antigravity. שרשורי Gemini קודמים נשארים
  קריאים.
