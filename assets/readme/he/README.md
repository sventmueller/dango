# Dango

**העורך המקורי ל-macOS לעבודה עם סוכני קוד.**

‏Dango מאגד את הקוד, את הסוכנים שמשנים אותו ואת כל מה שסביבם בחלון אחד לכל תיקיה: עורך עם שרתי שפה וחיזויי עריכה, מסופים, דפדפן, ‏Git, ‏CI, מנפה באגים ושרשורי AI עם Claude, ‏Codex, ‏Antigravity, ‏OpenCode או סוכן שמובנה ביישום. כל סוכן עובד באותו ציר זמן, שואל לפני שהוא משנה קבצים או מריץ פקודות, ומשאיר נקודת שחזור לפני כל הנחיה, כך שניתן לבדוק את מה שעשה ולהחזיר אותו לאחור, הודעה אחר הודעה. שום דבר שתיקיה מגדירה אינו רץ לפני שניתן לה אמון, וטקסט שמגיע מבחוץ מגיע לסוכן כשהוא מסומן כלא מהימן. ניתן להכתיב לעורך ולשדה ההודעה, וזיהוי הדיבור יכול להישאר ב-Mac. Dango כתוב ב-Rust על גבי פקדי AppKit אמיתיים, ללא Electron, מדבר 35 שפות ואין בו טלמטריה.

**עדיין לא שוחרר.** הגרסה הראשונה תהיה תמונת דיסק חתומה עם Developer ID ומאושרת (notarized) על ידי Apple, ל-macOS 14 ואילך ב-Apple Silicon וב-Intel. עד אז ניתן [לבנות את Dango מקוד המקור](#בנייה-מקוד-המקור).

**נמצא באג?** [אפשר לפתוח Issue](https://github.com/sventmueller/dango/issues/new) ולציין עם איזה סוכן ובאיזה סוג פרויקט הוא קרה.

## תכונות במבט חטוף

- **כל הסוכנים בציר זמן אחד.** Claude דרך הפקודה `claude` שלו, ‏Codex, ‏Antigravity ו-OpenCode דרך Agent Client Protocol, סוכנים נוספים מהמרשם של ACP, וסוכן שמובנה ביישום עבור Anthropic, ‏OpenAI, ‏Google Gemini, ‏OpenRouter, ‏Ollama ו-LM Studio. תשובות, קריאות לכלים, בקשות הרשאה, תוכניות, משימות לביצוע, סוכני משנה ומשימות ברקע נראים אותו דבר, לא משנה איזה סוכן רץ.
- **בדיקה וחזרה לאחור.** לפני כל הנחיה Dango שומר נקודת שחזור. ניתן לבדוק את מה שסוכן שינה ולהחזיר אותו לאחור לפי הודעה, ושרשור יכול לעבוד ב-Worktree נפרד של Git ולמסור את עבודתו באמצעות מיזוג או Cherry-Pick.
- **חלון אחד לכל תיקיה.** קבצים, מסופים, דפי דפדפן, שרשורי AI, תצוגות הבדלים ותצוגות מקדימות הם כרטיסיות macOS של החלון הזה. בסרגל הצד נמצאים קבצים, חיפוש, סוכנים, ‏Git, ניפוי באגים ו-CI.
- **עורך קוד אמיתי.** צביעת תחביר, כמה סמנים, קיפול, ‎`.editorconfig`, שרתי שפה ל-17 שפות עם השלמה, מעבר להגדרה, הפניות, שינוי שם, תיקונים מהירים והיררכיות, וחיזויי עריכה מ-GitHub Copilot או ממודל מקומי.
- **מנפה באגים, ‏Git ו-CI מובנים.** נקודות עצירה והרצה צעד אחר צעד ל-Rust, ‏C, ‏C++‎, ‏Swift, ‏Go, ‏JavaScript, ‏TypeScript ו-Python; סימון קטעים בודדים ל-Commit, ‏Branches, ‏Stashes, התנגשויות וגרף Commits; הרצות, ‏Jobs ויומנים מ-GitHub Actions ומ-GitLab CI.
- **זהיר עם התיקיות.** תיקיה שלא ניתן לה אמון אינה מפעילה דבר: לא תהליכי Git, לא שרתי שפה, לא Hooks ולא סוכנים. פקודות Git הרסניות לעולם אינן מקבלות הרשאה קבועה, ו-Commits נבדקים לאיתור סודות.
- **הכתבה.** דיבור אל העורך ואל שדה ההודעה, באופן מקוון דרך OpenAI או Groq או מקומית עם Whisper ו-Parakeet.
- **מקורי עד העצם.** חלונות, כרטיסיות, תפריטים וסרגלי כלים של AppKit, ‏TextKit 2 לעורך, ‏Metal למסוף, ‏WebKit רק בכרטיסיית הדפדפן. מצב כהה, ״הגברת ניגודיות״ ו-VoiceOver עובדים כמו בכל יישום Mac.
- **בשפה שלך.** הממשק זמין ב-35 שפות: ערבית, קטלאנית, סינית (מפושטת), סינית (מסורתית), קרואטית, צ׳כית, דנית, הולנדית, אנגלית, פינית, צרפתית, גרמנית, יוונית, עברית, הינדי, הונגרית, אינדונזית, איטלקית, יפנית, קוריאנית, מלאית, נורווגית, פולנית, פורטוגזית (ברזיל), פורטוגזית (פורטוגל), רומנית, רוסית, סלובקית, סלובנית, ספרדית, שוודית, תאילנדית, טורקית, אוקראינית ווייטנאמית.

## דרישות

- ‏macOS 14 Sonoma ואילך, ב-Apple Silicon או ב-Intel. Dango מפותח ונבדק ב-macOS 27.
- לשרשורי ה-AI, הסוכן שבו רוצים להשתמש; פרטים בסעיף [סוכני AI](#סוכני-ai).
- לשרתי שפה ולמתאמי ניפוי באגים, ש-Dango מתקין לפי בקשה: Go עבור gopls ו-`dlv`; ‏Node.js עבור שרתי TypeScript, ‏Python, ‏JSON, ‏YAML, ‏CSS, ‏HTML וה-shell ועבור מנפה הבאגים של JavaScript; ‏Xcode Command Line Tools עבור clangd, ‏sourcekit-lsp ו-`lldb-dap`. rust-analyzer מורד מדף ה-Releases שלו ב-GitHub.
- לחיזויי עריכה, מינוי GitHub Copilot (גם המינוי החינמי מספיק), או מודל fill-in-the-middle ב-Ollama או ב-LM Studio.

## התקנה

**מתמונת הדיסק.** כל גרסה היא תמונת דיסק, `Dango-<version>.dmg`, עם יישום אוניברסלי אחד ל-Apple Silicon ול-Intel, חתום עם Developer ID ומאושר (notarized) על ידי Apple. יש לפתוח אותה ולגרור את Dango אל התיקיה ״יישומים״. Homebrew Cask מתקין את אותה תמונה. עדיין לא פורסמה אף גרסה.

**עדכונים.** Dango שהותקן מתמונת הדיסק מתעדכן בעצמו באמצעות [Sparkle](https://sparkle-project.org). בהפעלה השנייה הוא שואל אם מותר לו לחפש עדכונים בעצמו; עד למתן הסכמה, הוא אינו שולח אף בקשה. **Dango › חיפוש עדכונים…** בודק מיד. העדכונים חתומים במפתח של היישום עצמו, ש-Sparkle בודק לפני שהוא מתקין משהו. לגרסה שנבנתה באופן עצמאי אין מנגנון עדכון.

**מקוד המקור.** פרטים בסעיף [בנייה מקוד המקור](#בנייה-מקוד-המקור); לאחר מכן יש להעביר את `target/release/Dango.app` אל ‎`/Applications`.

**פקודת המסוף.** **Dango › התקנת הפקודה ״dango״…** כותב סקריפט קטן אל ‎`~/.local/bin/dango`, ללא הרשאות מנהל; ‎`~/.local/bin` חייב להופיע ב-`PATH`. אחר כך `dango .`‎ פותח את התיקיה הנוכחית ו-`dango file.rs` פותח קובץ. Dango לעולם אינו מחליף שם קובץ שלא הוא עצמו כתב.

## צעדים ראשונים

1. **פתיחת תיקיה** עם ‎⌘O‎ או `dango <folder>`‎. בפעם הראשונה Dango שואל אם לתת בה אמון (פרטים בסעיף [אמון](#אמון)).
2. **סרגל הצד** עובר בין קבצים (‎⌘1‎), חיפוש (‎⌘2‎), סוכנים (‎⌘3‎), ‏Git (‎⌘4‎), ניפוי באגים (‎⌘5‎) ו-CI (‎⌘6‎); לחיצה ימנית מסתירה את אלה שאינם בשימוש, ו-‎⌃⌘S‎ מקפל את סרגל הצד.
3. **כל מסמך הוא כרטיסיה** בחלון של התיקיה, הכרטיסיות של macOS עצמו. ה-״+״ בסוף סרגל הכרטיסיות ו-‎⌘T‎ מציעים קובץ חדש, מסוף, את הדפדפן וכל סוכן מותקן, גם ב-Worktree נפרד של Git; לחיצה ממושכת על ה-״+״ מציגה את אותן אפשרויות כתפריט.
4. **פתיחה מהירה** עם ‎⌘P‎ מוצאת קבצים, ועם ‎`#`‎ את הסמלים של הפרויקט; ‎⇧⌘F‎ מחפש ומחליף בפרויקט.
5. **שיחה עם סוכן** בכרטיסיית AI. ‎⌘Esc‎ מעביר את מיקוד המקלדת אל שדה ההודעה שלו ובחזרה.
6. **הגדרות** עם ‎⌘,‎ מכילות את הכרטיסיות כללי, ‏CI, סוכנים, סוכן מובנה, שרת שפה, הכתבה וחיזוי.

בסרגל הכלים נמצאים אחורה וקדימה בין המקומות שנערכו (‎⌃-‎ ו-‎⌃⇧-‎), ה-Branch, ״פתיחה מהירה״ וסקירת ה״פעילות״, שמפרטת את כל מה שרץ. **פתיחה לצד** בתפריט ההקשר של קובץ מציגה מסמך שני לצד הראשון. לאחר הפעלה מחדש, או קריסה, כל חלון חוזר עם הכרטיסיות שלו, ועורכים עם טקסט שלא נשמר חוזרים עם הטקסט הזה. תמונות, שמע, וידאו, גופנים ומסמכי Office נפתחים בכרטיסיה דרך Quick Look, וקובצי PDF דרך PDFKit.

## סוכני AI

| סוכן | אופן הפעולה | מה נדרש |
|---|---|---|
| Claude | הפקודה `claude`, בתקשורת ישירה דרך פרוטוקול ה-stream-json שלה | ‏`claude` מותקן ומחובר; ‏Dango מחפש ב-`PATH` של מעטפת ההתחברות, ב-‎`~/.local/bin`, ב-‎`~/.claude/local`, ב-‎`/opt/homebrew/bin` וב-‎`/usr/local/bin`. ההתחברות מתבצעת רק ב-`claude` עצמו |
| Codex | ‏`codex-acp` דרך Agent Client Protocol (ACP) | ‏Node.js ו-npm; ‏Dango מתקין את החבילה בגרסה הקבועה לפי בקשה |
| Antigravity | `agy acp` | ‏`agy` שכבר נמצא ב-`PATH`, או ההורדה בגרסה הקבועה, שמותקנת לפי בקשה |
| OpenCode | `opencode acp` | ‏`opencode` שכבר נמצא ב-`PATH`, או ההורדה בגרסה הקבועה, שמותקנת לפי בקשה |
| סוכני ACP אחרים | מהמרשם של ACP, שנטען רק לפי בקשה | מה שהרשומה במרשם מציינת; רשומות ללא סכום ביקורת מותקנות רק אחרי אישור |
| סוכן מובנה | מובנה ביישום, עם כלים לקבצים, חיפוש, פקודות, אבחונים ובקשות רשת | מפתח API של Anthropic, ‏OpenAI, ‏Google Gemini או OpenRouter, שנשמר בצרור המפתחות; ‏Ollama או LM Studio ב-Mac זה ללא מפתח; כל שרת שמדבר ב-API של OpenAI או של Anthropic |

**הגדרות › סוכנים** מציג אילו סוכנים יש ב-Mac זה, מתקין את האחרים ואת העדכונים שלהם, ופותח את המרשם של ACP. סוכנים ש-Dango מתקין נעולים על גרסאות שנבדקו ומאומתים מול סכומי הביקורת שפורסמו עבורם (npm integrity או SHA-256); ‏Dango אינו מריץ חבילות `npx` ללא גרסה.

### ציר הזמן

כל סוכן עובד בכרטיסיית AI עם אותו ציר זמן: תשובות, קריאות לכלים עם הפלט שלהן, בקשות הרשאה, שאלות, תוכניות לאישור ולהערות (‎⌥⌘K‎), משימות לביצוע, סוכני משנה ומשימות ברקע. שני כפתורים בכותרת הכרטיסיה מציגים את סוכני המשנה ואת התהליכים ברקע שפועלים. אזכור של קובץ, של ‎`@terminal` או של ‎`@browser` מעביר את התוכן שלהם לסוכן. נקודה ירוקה על הכרטיסיה מציינת סשן בעבודה, נקודה אדומה – סשן שממתין לתגובה, והתראה מודיעה כשהוא מסיים או ממתין בזמן שמסתכלים במקום אחר. עבור Claude, שורת המצב מציגה את ההקשר ואת השימוש.

### הרשאות ומצבים

שרשורים חדשים מתחילים במצב ״ידני״: הסוכן שואל לפני שהוא משנה קבצים או מריץ פקודות. לפקודות Git הרסניות (`push --force`, `reset --hard`, `clean -fd`) Dango אינו מציע ״הרשאה קבועה״. הסוכן המובנה שומר את כללי ה״הרשאה הקבועה״ שלו לכל פרויקט, מציג אותם ב-**הגדרות › סוכן מובנה** ושואל על פקודות Git הרסניות בכל פעם, לא משנה מה נשמר; ‏Claude וסוכני ACP שומרים כללים כאלה בתצורה שלהם. במצב ״הכול מותר״ וללא ארגז חול, השרשור מציג אזהרה קבועה.

### נקודות שחזור ו-Worktrees

לפני כל הנחיה Dango שומר נקודת שחזור, כ-Commit תחת `refs/ide-checkpoints/`‎ במאגר של הפרויקט, או בתיקיה משלו לפרויקט ללא Git; ‏Push או Fetch רגילים לעולם אינם לוקחים אותן איתם. ניתן לבדוק את מה שסוכן שינה ולהחזיר אותו לאחור לפי הודעה. שרשור יכול לעבוד ב-Worktree נפרד של Git: חלונית Git מציגה מה הוא שינה ומשלבת את העבודה באמצעות מיזוג או Cherry-Pick.

## עורך

- **צביעת תחביר, מספרי שורות וסימוני שינויים** ביחס ל-Commit האחרון, חיפוש והחלפה, פתיחה מהירה (‎⌘P‎) וחיפוש בפרויקט (‎⇧⌘F‎).
- **ההזחה** עוקבת אחרי הקובץ ואחרי ‎`.editorconfig`: טאבים או רווחים, הזחה אוטומטית, זוגות סוגריים.
- **כמה סמנים:** ‎⌥-‎לחיצה, ‎⌥-‎גרירה לעמודה, ‎⌃⇧↑‎ ו-‎⌃⇧↓‎, ‎⌘D‎ למופע הבא.
- **קיפול** (‎⌥⌘←‎ ו-‎⌥⌘→‎, עם ‎⇧‎ לכל הקוד), החלפת מצב הערה (‎⌘/‎), מעבר לשורה (‎⌃G‎), תווי רווח גלויים וגלישת שורות (‎⌥Z‎).
- **קבצים שומרים על הקידוד שלהם**, על סימן סדר הבתים ועל סופי השורות. קובץ שהשתנה בדיסק נטען מחדש כשאין בעורך טקסט שלא נשמר; אחרת סרגל מציע את ההבדלים ומיזוג.
- **חיזויי עריכה.** בזמן ההקלדה מופיעה הצעה באפור, ו-Tab מקבל אותה. היא מגיעה מ-GitHub Copilot או ממודל מקומי ב-Ollama או ב-LM Studio, לפי הבחירה ב-**הגדרות › חיזוי**; מודל מקומי משאיר את הקוד ב-Mac זה.

## שרתי שפה

‏Go, ‏Rust, ‏TypeScript ו-JavaScript, ‏Python, ‏C, ‏C++‎ ו-Objective-C, ‏Swift, סקריפטים של shell, ‏JSON, ‏YAML, ‏CSS, ‏HTML, ‏TOML, ‏Markdown ו-Lua, ושרתים נוספים שמגדירים ב-**הגדרות › שרת שפה**. Dango מתקין שרת לפי בקשה, בתיקיית הכלים שלו, ומשתמש ב-`tsc` של פרויקט TypeScript כשהוא יכול לשמש כשרת שפה.

מה הם מספקים: אבחונים (‎⌘'‎ ו-‎⇧⌘'‎ עוברים ביניהם), ריחוף (‎⌃⌘I‎), השלמה (‎⌥Esc‎), עזרה בחתימות, מעבר להגדרה (‎⌃⌘J‎), להגדרת טיפוס ולמימוש, הפניות (‎⌃⇧⌘F‎), היררכיית קריאות והיררכיית טיפוסים (‎⌃⇧⌘H‎), שינוי שם (‎⌃⌘E‎), עיצוב קוד (‎⌥⇧F‎), צבעים סמנטיים, קיפול והמתאר (‎⇧⌘O‎); טיפוסים ושמות פרמטרים בתוך השורה; תיקונים מהירים וריפקטורינג מאחורי נורה (‎⌥⌘A‎); הסמלים של הפרויקט עם ‎⌥⌘O‎.

## מסוף

מסופים בכרטיסיות (‎⌃\`‎) עם הסביבה של מעטפת ההתחברות, מצוירים באמצעות Metal. ‎⌘K‎ מנקה את המסך. הדבקה או גרירה של תמונה מעבירה אותה לסוכן קוד שרץ במסוף, או מדביקה את הנתיב של עותק שמור. ‎⌘-‎לחיצה פותחת קישורים ושמות קבצים. ניתן לפתוח בכרטיסיית הדפדפן שרת פיתוח שהמסוף מפעיל.

## דפדפן

כרטיסיית דפדפן עם שדה כתובת (‎⌘L‎), אחורה וקדימה (‎⌘[‎ ו-‎⌘]‎), טעינה מחדש (‎⌘R‎), חיפוש, הורדות ששואלות קודם, ו-Web Inspector. ‎`@browser` מעביר את הדף לסוכן, מסומן כטקסט מבחוץ.

## Git

חלונית Git מסמנת ל-Commit ומבטלת שינויים בקבצים או בקטעים בודדים, יוצרת Commits, מבצעת Commit ו-Push או סנכרון, עוברת בין Branches ויוצרת אותם, שומרת Stashes, פותרת התנגשויות מיזוג ומציירת גרף של ה-Commits האחרונים. Blame מציג מי שינה לאחרונה את השורה שבה נמצא הסמן, או עמודה לכל הקובץ. כפתור כותב את הודעת ה-Commit בעזרת AI; ההבדלים נשלחים רק אחרי ש-gitleaks לא מצא בהם סוד, וכל Commit נבדק גם הוא לאיתור סודות.

## CI

‏GitHub Actions ו-GitLab CI, גם GitHub Enterprise Server ו-GitLab באירוח עצמי:

- הרצות, ‏Jobs ויומנים של ה-Branch הנוכחי;
- הרצה מחדש של Jobs שנכשלו, של Job בודד או, ב-GitHub, של הרצה שלמה; הפעלת Jobs ידניים או אישור פריסות ממתינות; הפעלת Pipeline חדש או Workflow שניתן להפעיל ידנית; ביטול;
- ה-Pull Requests או ה-Merge Requests הפתוחים וה-Issues, שנפתחים בכרטיסיית הדפדפן;
- יומן של Job שנכשל שמועבר לסוכן, מסומן כטקסט מבחוץ.

הטוקן מגיע מצרור המפתחות, מ-`gh` או מ-`glab`, מהסביבה של מעטפת ההתחברות, או מטוקן שמוזן ב-**הגדרות › CI**.

## Markdown

- **תצוגה מקדימה.** קובץ Markdown נפתח עם התצוגה המקדימה שלו לצידו; **תצוגה › הצגה/הסתרה של התצוגה המקדימה לצד** (‎⇧⌘V‎) סוגר ופותח אותה, ו-**הגדרות › כללי** מכבה את התצוגה המקדימה האוטומטית. התצוגה המקדימה מציירת נוסחאות, דיאגרמות Mermaid, ‏Graphviz ו-PlantUML ואת התמונות שבתיקיה; תמונות מהאינטרנט נטענות רק בתיקיה מהימנה או לאחר בקשה מפורשת בתצוגה המקדימה.
- **התפריט ״עיצוב״:** מודגש (‎⌘B‎), נטוי (‎⌘I‎), קו חוצה (‎⇧⌘X‎), קוד (‎⌥⇧⌘C‎), קישור (‎⇧⌘K‎), כותרות 1–3 (‎⌥⌘1‎–‎⌥⌘3‎), רשימות תבליטים וממוספרות, משימות, ציטוטים ובלוקי קוד. כל פקודה מחליפה מצב, על הבחירה או על השורות, ומהווה צעד ביטול אחד.
- **הדבקה.** טקסט מ-Word או מדף אינטרנט מגיע כ-Markdown, והתמונות שלו כקבצים לצד המסמך; ‎⌥⇧⌘V‎ מדביק טקסט פשוט.
- **ייצוא.** **קובץ › ייצוא** כותב PDF, קובץ HTML יחיד שהתמונות שלו בתוכו, או מסמך Word. תמונות מהאינטרנט נכללות רק מתיקיה מהימנה.
- **פתיחה ב-Splat.** כאשר [Splat](https://github.com/sventmueller/splat) מותקן, **קובץ › פתיחה ב-Splat** ותפריטי ההקשר של עץ הקבצים ושל הכרטיסיות פותחים בו את המסמך, אחרי שמירתו.

## הכתבה

הכתבה לשדה ההודעה של כרטיסיית AI או לעורך: כפתור המיקרופון שם, **עריכה › התחלת הכתבה** (‎⌃⌥D‎), או מקש fn (החזקה להקלטה, הקשה כפולה להמשך ההקלטה). זיהוי הדיבור הוא זה של [Lowspeak](https://github.com/sventmueller/lowspeak); אין צורך להתקין את Lowspeak עצמו.

- **הגדרות › הכתבה** קובע את המצב והמודל (מקוון עם OpenAI או Groq, מקומי עם Whisper או Parakeet), את השפה, את העיבוד שלאחר ההכתבה, את המיקרופון ואת אוצר המילים האישי.
- **מודלים מקומיים** מורדים מ-Hugging Face כשבוחרים אחד, עם תצוגת התקדמות ואפשרות ביטול. הם נשמרים בתיקיות ש-Lowspeak משתמש בהן, כך שכל אחד מהיישומים משתמש במה שהשני הוריד. מודל מקומי משאיר את ההקלטה ב-Mac זה.
- **תמלול מקוון** דורש מפתח של OpenAI או של Groq, ש-Dango שומר בפריט משלו בצרור המפתחות.
- **מ-Lowspeak.** אם Lowspeak מוגדר אחרת מברירות המחדל, הכרטיסיה ״הכתבה״ מציעה פעם אחת לאמץ את ההגדרות שלו, ואת המפתחות שלו לפי בקשה; ‏macOS מבקש אישור לפני ש-Dango קורא מפתח (יש לבחור ״אישור״, לא ״הרשאה קבועה״).
- **הרשאות.** macOS מבקש גישה למיקרופון בהכתבה הראשונה. מקש fn פועל כל עוד Dango הוא היישום הפעיל ו-Lowspeak אינו רץ; הוא דורש את הרשאת הנגישות, ש-Dango מבקש אחרי ההכתבה הראשונה, לעולם לא בהפעלה.

## אמון

תיקיה יכולה לגרום להרצת תוכניות ברגע שמשהו מופעל בה: Hooks של Git והגדרות מאגר כמו `core.fsmonitor`, שרתי שפה מ-`node_modules`, ‏Hooks של סוכנים, ‎`.mcp.json`. בפעם הראשונה שתיקיה נפתחת, ‏Dango שואל אם לתת בה אמון.

- **מהימנה:** Git, שרתי שפה, מנפי באגים, סוכנים ו-CI רצים עבור התיקיה הזו וכל מה שמתחתיה.
- **מוגבלת:** ניתן לקרוא ולערוך; סימוני השינויים בעורך מגיעים מקריאה ישירה של ‎`.git`. שום דבר שהתיקיה מגדירה אינו מופעל. החלוניות Git, ‏CI ו-AI מציינות זאת ומציעות לתת אמון בתיקיה.

טקסט שאינו מגיע מהמשתמש יכול להכיל הוראות שנועדו להטות סוכן (הזרקת הנחיות). לכן הפלט של מסוף (‎`@terminal`), דף דפדפן (‎`@browser`), יומן CI שמועבר לסוכן, קובץ מחוץ לפרויקט וטקסט ארוך יותר שהודבק מדף אינטרנט מועברים כשהם מסומנים: התווית מציגה ״תוכן חיצוני״, והסוכן מקבל את הטקסט עם הודעה שמדובר בנתונים לא מהימנים שאסור לו לבצע את ההוראות שבהם. דפי האינטרנט של הסוכן המובנה מגיעים עם אותה הודעה. טקסט מודבק נחשב כמגיע מדף אינטרנט כשהדפדפן מציין זאת בלוח העריכה, כפי ש-Safari, ‏Chrome ו-Firefox עושים; טקסט ממקור אחר, וביטוי קצר של מילים ספורות, נשאר טקסט של המשתמש.

## ארגז חול

‏Dango עצמו רץ ללא App Sandbox, כי כל תוכנית שהוא מפעיל הייתה יורשת אותו: מסופים, ‏Git, שרתי שפה וסוכנים לא היו יכולים לעבוד. במקום זאת, לכל שרשור AI יש מתג ארגז חול, כבוי כברירת מחדל. מה שהוא מגביל תלוי בסוכן, ותיבת העזרה של המתג מציינת זאת:

| סוכן | כשארגז החול פועל |
|---|---|
| Claude | פקודות shell רצות בארגז החול של Claude עצמו; כלי הקבצים והרשת שלו לא |
| Codex | פקודות ושינויים כותבים רק בתוך הפרויקט, ללא רשת |
| סוכן מובנה | קבצים, בקשות רשת ופקודות נשארים בתוך הפרויקט ובתיקיות המותרות, ללא רשת (`sandbox-exec`) |
| Antigravity, OpenCode | אין ארגז חול ש-Dango יכול להפעיל |

## מראה ונגישות

- **מצב כהה** עוקב אחרי המערכת; **הגברת ניגודיות** ו-**הפחתת תנועה** נלקחות בחשבון.
- ‏**VoiceOver** נותן שמות לסרגל הצד, לכרטיסיות, לכרטיסים של ציר הזמן של ה-AI, לשורות Git ו-CI, למנפה הבאגים ולטקסט של המסוף. נקודות עצירה לעולם אינן מובחנות זו מזו על ידי צבע בלבד.

- **מימין לשמאל.** בערבית ובעברית החלון משתקף, ואילו תצוגות קוד נשארות משמאל לימין.

הממשק מתורגם ל-35 שפות: ערבית, קטלאנית, סינית (מפושטת), סינית (מסורתית), קרואטית, צ׳כית, דנית, הולנדית, אנגלית, פינית, צרפתית, גרמנית, יוונית, עברית, הינדי, הונגרית, אינדונזית, איטלקית, יפנית, קוריאנית, מלאית, נורווגית, פולנית, פורטוגזית (ברזיל), פורטוגזית (פורטוגל), רומנית, רוסית, סלובקית, סלובנית, ספרדית, שוודית, תאילנדית, טורקית, אוקראינית ווייטנאמית.

‏Dango עוקב אחרי סדר השפות ב-**הגדרות המערכת › כללי › שפה ואזור**; שם אפשר גם לבחור שפה ל-Dango בלבד תחת **יישומים**. אם אין תרגום לשפת המשתמש, הוא משתמש באנגלית. המונחים עוקבים אחרי מילון מונחים אחד, [docs/glossary.md](../../../docs/glossary.md), ואחרי התרגומים של Apple עצמה, כך ש-Dango נקרא כמו שאר ה-Mac.

## פרטיות ואבטחה

- **ללא טלמטריה,** ללא ניתוח נתונים, ללא דוחות קריסה שנשלחים לאנשהו. שגיאות נכתבות ליומן המערכת (Console.app, תחת שם היישום).
- **רשת רק עבור מה שמופעל ביוזמת המשתמש:** הסוכנים שבשימוש, כל אחד מול השירות שלו; המרשם של ACP וההורדות של סוכנים, שרתי שפה, מתאמי ניפוי באגים ומודלי הכתבה לפי בקשה; מארחי ה-CI שאליהם בוצעה התחברות; חיזויי עריכה מ-Copilot אם נבחרו; הספקים של הסוכן המובנה; תמלול מקוון אם נבחר; הדפים שנפתחים בכרטיסיית הדפדפן; ובדיקת העדכונים לאחר שהותרה.
- **קוד שיוצא מה-Mac** יוצא רק לשירות שנבחר לכך: סוכן, חיזויי Copilot, הודעת Commit שנכתבה בעזרת AI. ההבדלים להודעת Commit נשלחים רק אחרי ש-gitleaks לא מצא בהם סוד.
- **מפתחות וטוקנים** נשארים בצרור המפתחות של macOS, לעולם לא בקובץ הגדרות. מפתחות של יישומים אחרים, כמו אלה של Lowspeak, נקראים רק בהסכמה, ורק פעם אחת.
- **הורדות בגרסה קבועה.** סוכנים, שרתי שפה ומתאמי ניפוי באגים ש-Dango מתקין נעולים על גרסאות שנבדקו ומאומתים מול סכומי הביקורת שלהם.
- **חתימת קוד** עם Hardened Runtime; עדכונים מותקנים רק עם החתימה של היישום עצמו.

## היכן נשמרים הנתונים

‏‎`<id>`‎ הוא מזהה ה-Bundle, `local.agentide` לגרסה המשוחררת (`local.agentide.debug` לבניות ניפוי באגים). הוא אינו מכיל את השם המוצג, כך ששינוי שם שומר על כל הנתונים.

| מקום | מה |
|---|---|
| `~/Library/Application Support/<id>/` | ‏`settings.json`, `state.json`, `keybindings.json`, `trust.json`; `threads/`‎ (הרשימה של חלונית ה-AI), `agent-threads/`‎ (שיחות של הסוכן המובנה), `layouts/`‎ (כרטיסיות לכל פרויקט), `recovery/`‎ (עורכים שלא נשמרו לאחר קריסה), `checkpoints/`‎ (לתיקיות ללא Git), `worktrees/`‎, `agents/`‎ ו-`tools/`‎ (סוכנים, שרתי שפה ומתאמי ניפוי באגים מותקנים), `task-output/`‎ |
| `~/Library/Caches/<id>/` | תמונות שהודבקו, סקריפטים לשילוב עם ה-shell, המרשם של ACP; ניתן למחוק |
| `~/Library/Logs/<id>/dictation/` | קובצי היומן של ההכתבה |
| ‏‎`~/Library/Application Support/Lowspeak` ו-`FluidAudio` | מודלי הכתבה מקומיים, משותפים עם Lowspeak |
| `~/Library/WebKit/<id>/` | עוגיות ונתוני אתרים של כרטיסיית הדפדפן |
| `<project>/.dango/settings.json` | ההגדרות של הפרויקט עצמו |
| מאגר ה-Git של הפרויקט | נקודות שחזור, כ-Commits תחת `refs/ide-checkpoints/`‎; ‏Push או Fetch רגילים לעולם אינם לוקחים אותן איתם |
| צרור המפתחות, שירות ‎`<id>`‎ | מפתחות API של הסוכן המובנה ושל ההכתבה, טוקנים של CI |
| `~/.local/bin/dango` | פקודת המסוף, אם הותקנה |

‏Claude שומר את הסשנים שלו תחת ‎`~/.claude/projects`; ‏Dango קורא אותם כדי להמשיך סשן אבל אינו משנה אותם.

## מגבלות ידועות

- **ללא App Sandbox** ליישום עצמו, מאחר שמסופים, ‏Git, שרתי שפה וסוכנים היו יורשים אותו; יש לתת אמון בתיקיה לפני שמשהו שהיא מגדירה רץ. ל-Antigravity ול-OpenCode אין ארגז חול ש-Dango יכול להפעיל.
- **נתוני השימוש של Claude ופירוט ההקשר שלו** מסתמכים על חלקים בפרוטוקול שלו שמסומנים כניסיוניים, ומוסתרים כשהם חסרים.
- **חזרה לאחור בשיחה** פועלת רק עבור Claude; בסוכנים האחרים רק הקוד חוזר לאחור.
- **התחברות ל-CI דרך הדפדפן** כבויה; יש להשתמש ב-`gh`, ב-`glab`, בטוקן או בסביבה.
- ‏**Gemini CLI אינו מוצע:** Google הפסיקה את ההתחברות עם חשבון אישי ומפנה ל-Antigravity. שרשורי Gemini קודמים נשארים קריאים.

## בנייה מקוד המקור

נדרשים:

- ‏macOS 14 ואילך עם Xcode Command Line Tools (`xcode-select --install`); אין צורך ב-Xcode עצמו.
- ‏Rust כפי ש-`rust-toolchain.toml` מציין. ה-`rust` של Homebrew בונה למעבד של Mac זה; הבנייה האוניברסלית של גרסה דורשת rustup עם היעדים `aarch64-apple-darwin` ו-`x86_64-apple-darwin`.
- עותקים של [splat](https://github.com/sventmueller/splat) ושל [lowspeak](https://github.com/sventmueller/lowspeak) לצד העותק הזה (‎`../splat`, ‎`../lowspeak`), שניהם ב-Branch `main` שלהם; ה-Workspace לוקח מהם Crates לפי נתיב.
- ‏cmake, לכל בנייה עם הכתבה (`make run`, `make build`, `make release`), שבונה את whisper.cpp. `make check` בונה בלעדיו.

| פקודה | מה היא עושה |
|---|---|
| `make run` | בונה את יישום ניפוי הבאגים (`target/debug/Dango Debug.app`) ופותח אותו |
| `make build` | בונה את יישום השחרור (`target/release/Dango.app`), חתום בתעודה מקומית שהבנייה הראשונה יוצרת בצרור המפתחות של ההתחברות; מעלה את מספר הבנייה ב-`VERSION` |
| `make lint` | עיצוב קוד ו-clippy; אזהרות גורמות לכישלון |
| `make check` | ‏`lint`, ואחר כך כל הבדיקות; אינו דורש צרור מפתחות, חלון או רשת |
| `make test` | ‏`check`, ואחר כך הבדיקה העצמית `probe` וביקורת הנגישות, משמאל לימין ומימין לשמאל, ביישום האמיתי |
| `make perf` | תקציבי הזמן, בבניית שחרור; בעל משמעות רק ב-Mac שאינו עסוק בדבר אחר |
| `make release` | הרצת ניסיון של השחרור אל `target/release-dry-run/`‎, חתומה בתעודה המקומית; אינה שולחת דבר לשום מקום |
| `make release-notarized` | ‏`check`, ואחר כך השחרור עצמו אל `dist/`‎: חתימת Developer ID, אישור (notarization), פיד העדכונים חתום במפתח של היישום עצמו; מעלה את מספר הבנייה |

גרסאות ניפוי הבאגים והשחרור הן יישומים נפרדים עם הגדרות ונתונים משלהם. הבנייה, הבדיקות, הבדיקות העצמיות, השחרור והכללים שהקוד עוקב אחריהם מתוארים ב-[docs/development.md](../../../docs/development.md), וההחלטות שמאחוריהם ב-[docs/plan.md](../../../docs/plan.md). הערות הגרסה נמצאות ב-[RELEASE_NOTES.md](../../../RELEASE_NOTES.md), ומתורגמות לצד כל README ב-`assets/readme/<language>/`‎.
